# Video Workflow Routing

## 先路由问题，再路由工具

同一个镜头可能包含内容、构图、运动、文字、音频和交付六类问题。先判断问题 owner，再选择 Skill 或引擎。

| 需求 | 默认 owner / 路线 | 不应做 |
|---|---|---|
| 事实、学习目标、讲解边界 | 内容开发 / 教材证据 / 专业审核 | 让视频模型决定知识结论 |
| 系列人物、世界观、语气、视觉语法 | series/visual bible | 每集临时重做角色设定 |
| 构图、角色姿态、场景状态 | storyboard + 图像/设计能力 | 用长动作提示词弥补错误起始画面 |
| 角色运动、镜头运动、环境变化 | 视频 renderer adapter | 在单镜头塞入多个难以控制的复杂动作 |
| 中文、公式、图表、时间轴、字幕 | 确定性图形/后期 | 要求生成模型稳定绘制精确文字 |
| 配音、音乐、音效与混音 | 音频/后期能力 | 在画面未锁定前完成最终混音 |
| 文件规格、编码、拼接、抽帧 | media pipeline / ffmpeg 类工具 | 以肉眼播放替代技术检查 |
| 视觉、内容、连续性判断 | 独立 reviewer / 人工 Gate | 用远程任务 `completed` 当作验收通过 |

## 镜头生成路线

### A. 确定性后期

优先用于：

- 精确中文与字幕；
- 公式、表格、坐标轴、流程图、时间轴；
- 品牌标识、页码、UI 和需要逐字准确的信息；
- 简单平移、缩放、遮罩和图形动画。

### B. 文生图 / 图像编辑

优先用于：

- 角色、风格、场景和道具定稿；
- 镜头起始/结束关键帧；
- 修复歧义构图、移除高风险元素；
- 创建跨镜头复用的 reference assets。

当前环境可按需调用 `$imagegen`；它是图像执行能力，不是本 workflow 的必选依赖。

### C. 单关键帧图生视频

适合：

- 构图基本不变；
- 一项主要动作；
- 角色身份和场景需要锁定；
- 结尾状态不要求精确。

### D. 首尾关键帧视频

适合：

- 结尾姿态或空间状态必须准确；
- 明确的状态转换、转场、失败/成功动作；
- 单关键帧反复生成错误结局。

### E. 文生视频

只在角色连续性要求低、无需精确构图的氛围/B-roll/抽象镜头中优先考虑。系列主角表演镜头默认不走这一路线。

## 复杂动作降级梯

```text
复杂一镜到底
-> 减少同时动作
-> 冻结次要角色和背景
-> 拆成两个镜头
-> 增加结束关键帧
-> 改为确定性后期或静态镜头
```

若出现真人化、动漫化、多肢体、意外文字或身份漂移：

1. 先确认问题是否已经存在于关键帧；
2. 若是构图歧义，重做关键帧或移除触发元素；
3. 若是动作过载，冻结非必要运动；
4. 最后才是更换 prompt、seed 或 renderer。

## 项目治理路由

项目已有任务体系时：

```text
workflow-video 阶段/Gate
-> 映射到项目 README / Roadmap / TASK
-> 项目目录保存输入、输出和证据
-> workflow 只保存可迁移协议和 case 指针
```

当前已知可组合能力：

- `task-driven-project-manager`：建立和维护项目 TASK、台账、日志、UAT；
- `roadmap`：跨阶段可点击导航与 Gate；
- `$imagegen`：角色、风格、场景和关键帧图像；
- `aliyun-server`：仅在 renderer 要求公网 URL 且项目已授权发布时提供当前托管 adapter；
- Agnes：当前案例的视频 renderer；其请求格式、限流和轮询逻辑留在项目或未来 Agnes adapter。

这些能力可替换。父 workflow 依赖的是语义接口，不是供应商名称。

## 平台 adapter 拆分门槛

仅在下列内容稳定且会复用时新增 adapter/subworkflow：

- 独特的请求/响应 schema；
- 独特的认证、托管或 URL 要求；
- 独特的任务状态、限流、轮询、重试和下载逻辑；
- 独特的时长/分辨率/帧数约束；
- 独特的失败模式和 QC 规则；
- 至少有一个 executed-capability 证据和一个 forward-test 计划。

## Review 路由

| 发现 | 修复 owner |
|---|---|
| 编码/容器/帧率/时长错误 | media pipeline |
| 角色漂移、畸变、意外文字 | 资产或 renderer 路线 |
| 画面隐喻误导、旁白不匹配 | script/storyboard |
| 跨镜头服装、道具、空间不连续 | continuity / asset registry |
| 字幕、音频、片头尾或平台规格不合格 | post/delivery |

reviewer 应写“证据 + 严重度 + 修复路线”，不能只写“效果不好”。
