# 从八股模块到“凭什么链”

## Trigger

在协同阅读 Fang, Peress, and Zheng 的 `Does Media Coverage of Stocks Affect Mutual Funds' Trading and Performance?` 时，我们先把一句话核心发现还原成形式逻辑意义上的作者断言：

```text
基金经理受有限注意力影响；
并且，如果基金经理受有限注意力影响越大，那么其投资表现越差。
```

随后进入下一步问题：

```text
凭什么？
```

用户指出，文献综述、理论构建、变量构造、实验设计、替代解释、稳健性和项目迁移等传统模块，本质上都应该服务于回答这个“凭什么”。如果只是按论文八股顺序罗列模块，容易得到形式化摘要，而不是实质论证线。

## Core Insight

论文阅读的主线不应是：

```text
文献综述 -> 理论 -> 数据 -> 变量 -> 识别 -> 结果 -> 稳健性
```

而应是：

```text
作者断言 C
-> 凭什么 C 值得问
-> 凭什么 X 会影响 Y
-> 凭什么 proxy 能代表理论对象
-> 凭什么实验 / 识别能支持结论
-> 凭什么不是竞争性解释
-> 凭什么结果稳健可信
-> 凭什么能迁移到当前项目
```

传统模块是论文呈现的形式秩序；“凭什么链”才是论文成立的实质论证秩序。

## Mapping

模块可以保留，但必须被重新解释为 warrant chain 的不同环节：

| 传统模块 | 实质问题 |
|---|---|
| 文献综述 | 凭什么这个问题值得问？它卡在哪些文献缺口或文献交汇点？ |
| 理论构建 | 凭什么 X 会影响 Y？中间机制是什么？ |
| 变量构造 | 凭什么这个 proxy 能代表理论对象？ |
| 实验 / 识别设计 | 凭什么这个设计或估计能支持因果、机制或核心经验结论？ |
| 替代解释 | 凭什么不是其他机制、选择效应、迎合行为或共同冲击？ |
| 稳健性 | 凭什么结果不是口径、样本、模型或测度偶然造成的？ |
| 项目迁移 | 凭什么这篇文献的设计骨架能搬到当前项目？ |

## Reading Discipline

`research-literature-reader` 后续应避免把文献阅读降成“模块摘要”。推荐阅读 spine：

```text
1. 作者断言是什么？
2. 作者凭什么让这个断言值得被相信？
3. 凭什么链中哪些环节最强？
4. 哪些环节最容易被反驳？
5. 哪些凭什么环节可以迁移到当前项目？
```

协同阅读中：

```text
Paper Orientation Card -> 先固定作者断言；
Discussion Agenda -> 逐项拆凭什么；
discussion-outline.md -> 记录每个凭什么环节的共识、缺口和是否可提升为项目资产。
```

自动摘要中也应至少输出一版：

```text
claim-warrant map
```

而不是只输出模块化 summary。

## CASE-260521 Example

对 Fang, Peress, and Zheng 这篇论文：

```text
作者断言：
基金经理受有限注意力影响；且受影响越大，表现越差。

凭什么值得问：
它位于 limited attention / media attention 与 professional investors / mutual fund trading and performance 两支文献的交汇点。

凭什么有限注意力可观察：
作者把股票层媒体覆盖转成基金层 `PROPENSITY_BUY_MEDIA`。

凭什么不是偶然交易噪音：
`PROPENSITY_BUY_MEDIA` 具有持久性。

凭什么表现更差：
高 `PROPENSITY_BUY_MEDIA` 基金未来 alpha 更低，且买入端强、卖出端弱。

凭什么不是别的机制：
作者检验 flow-catering、RPI、新闻 tone/content、manager turnover 等替代解释。

凭什么能迁移到当前项目：
可以把“媒体覆盖 -> 买入倾向 -> 业绩”迁移成“投资者互动 / 问答暴露 -> 回应或迎合倾向 -> 投资策略、资金流或业绩后果”。
```

## Lesson

八股模块不是错，错的是让模块替代论证。真正可迁移的文献阅读能力，是从模块中抽出作者如何让读者相信核心断言的“凭什么链”。

## 2026-07-06 UAT Anti-Cheating And A01 Proxy Guardrail

用户指出：如果 UAT prompt 直接要求 subAgent 输出 `A01 / P1 / P2 / Bx / By / proxy bridge`，这属于泄题，不能检验 Skill 是否自然生效。

因此新增独立 Skill：

```text
skills/miy-uat/SKILL.md
```

核心规则：

```text
测 Skill，就不要把 Skill 应该产出的关键结构写进测试 prompt。
测修复，就不要把 bug、fix、预期输出和主 Agent 结论泄露给验证者。
验收标准应由主 Agent 在 subAgent 返回后隐藏使用。
```

随后用更干净的 black-box UAT 重看 `collaborative-reading`。结论是 mixed pass：

```text
PASS:
  Agenda 已经自然生成 Claim decomposition 和 Operationalization / proxy bridge，
  不再机械回到单组 Main X / Main Y。

PARTIAL FAIL:
  A01 仍可能把 proxy 层句子当成核心发现，
  例如把“买入媒体报道股票的倾向越强，未来表现越差”
  写成核心句，而不是还原为“受有限注意力影响越大，表现越差”。
```

据此追加 guardrail：

```text
A01 应优先使用理论对象 / 抽象构念；
若摘要或结果段用 proxy 表达发现，必须向上还原为理论命题；
proxy 放到 A03 的 operationalization / proxy bridge 中；
只有当论文的核心 claim 本身就是 measurement / proxy claim 时，
才把 proxy 放进 A01，并显式标注。
```

进一步校准：

```text
更根本的问题不是“A01 是否用了 proxy”本身，
而是后续有没有沿着“作者如何论证断言”往下走。

X、Y、proxy、warrant、evidence 都必须放回作者的论证任务中理解。
如果作者断言是复合命题，就不能预设全篇只有一组 X/Y；
每个命题支都可能对应自己的待证对象、可观察对象和 X/Y 关系。
```

## 2026-07-06 Orientation Card De-Assumption

用户进一步指出：`Paper Orientation Card` 的固定清单若直接写成“主 X / X 的操作化 / 主 Y / Y 的操作化”，本身就会暗示过强，诱导 Agent 在第一轮把论文压成单一 X/Y 框架。

修正原则：

```text
Orientation Card 也必须低假设。
入口不是“本文 X/Y 是什么”，而是：
  A01 是什么？
  A01 的形式逻辑结构是什么？
  若是复合命题，有哪些命题支？
  每个命题支分别需要作者证明什么？
  每个命题支中有哪些可观察对象 / proxy / X-Y 关系？
```

X/Y 不是默认栏目，而是可选标注；只有在它帮助理解某个命题支的论证时才出现，并且必须说明归属哪个命题支。

## 2026-07-06 UAT Follow-up: Core Branches Vs Support Branches

干净 UAT 通过了低假设 Orientation Card 和命题拆解方向，但暴露出一个新的轻微偏差：subAgent 会把买入 / 卖出边界、替代解释排除也写成并列 P3 / P4。

这说明仅仅要求“拆命题支”还不够，还要要求分清分支角色：

```text
core proposition branches:
  A01 本身需要读者相信的核心命题支。

supporting / boundary / exclusion branches:
  mechanism / warrant；
  boundary condition；
  alternative explanation exclusion；
  robustness / design support。
```

边界条件和替代解释很重要，但它们通常服务于论证核心命题，不应自动升级为 A01 的并列核心命题。

已修补：

```text
collaborative-reading/SKILL.md
discussion-outline-template.md
```

## 2026-07-06 UAT Follow-up: Proxy Bridge Must Not Enter A01 Core Form

第二轮干净 UAT 基本通过，但仍出现轻微残留：subAgent 在 A01 logical structure 中写出类似：

```text
这种有限注意力会通过买入媒体报道股票的倾向表现出来。
```

这句话重要，但它不是 A01 的 core proposition branch，而是 operationalization / proxy bridge。它回答的是“凭什么可观察”，应进入 A03。

新增硬规则：

```text
operationalization / proxy bridge 不得写入 A01 的 core logical form。
凡是“A 通过 proxy 表现出来”“变量 X 测量 A”“指标 M 代表理论对象 A”，
默认属于 A03，而不是 A01 的核心命题支。

只有当论文本身的核心贡献就是提出或验证一个 measurement construct 时，
才可把 measurement claim 写入 A01，并显式标注。
```

## 2026-07-06 A03 Cardinality Rule

用户进一步追问：如果 A01 有 P1 和 P2，A03 应该怎么做？如果只有 P1 呢？如果以后有 P1/P2/P3 呢？

规则化为：

```text
A03 的数量跟随 A01 的 core proposition branches。

如果 A01 = P1：
  A03 = A03-P1。

如果 A01 = P1 且 P2：
  A03 = A03-P1 + A03-P2。

如果 A01 = P1 且 P2 且 P3：
  A03 = A03-P1 + A03-P2 + A03-P3。
```

但前提是 P1/P2/P3 都是 core proposition branches。若某一项只是 operationalization、mechanism、boundary、exclusion 或 robustness support，不生成独立 A03-Pi，而是挂回它服务的核心命题支。

每个 `A03-Pi` 都要分别回答：

```text
abstract objects；
observable / proxy；
proxy warrant；
supporting evidence；
competing interpretations；
若 Pi 是条件或关系命题，则分别处理 Bx、By 和 Bx -> By 的估计。
```

## 2026-07-06 Proposition ID System

用户进一步指出：协同阅读进行中应保留 `P1`、`P2`、`P3` 等命题编号。否则 A01 虽然拆开了，A03/A04/A07/A08 推进时仍可能重新变成松散模块。

新增规则：

```text
P1 / P2 / P3 不是一次性分析草稿，
而是贯穿协同阅读的持久 proposition IDs。
```

使用方式：

```text
A01:
  建立 P1 / P2 / P3。

A03:
  按 P1 / P2 / P3 生成 A03-P1 / A03-P2 / A03-P3。

A04/A05/A06/A07/A08:
  每一项都要尽量标注 linked proposition IDs，
  说明机制、文献对话、gap、识别设计、迁移分别服务哪个 Pi。
```

辅助支撑项不占用 P 编号，使用 `S-Pi-*` 挂回对应核心命题支。若某项服务整篇核心组合，标 `P-all`；若暂时无法判断，标 `P?` 并保留 open question。

## 2026-07-06 A02 Reframing: Proof Structure, Not Claim Decomposition

用户指出：A02 若继续做“命题拆解”，会和 A01 重复。更准确的分工应是：

```text
A01:
  识别核心断言；
  判断简单命题 / 复合命题；
  拆出 core proposition branches；
  建立 P1 / P2 / P3 编号。

A02:
  追问作者如何论证每个 Pi；
  将每个 Pi 还原为可检验的 proof structure。
```

因此 A02 改为：

```text
A02 Proof Structure / Argument Plan
```

每个 `Pi` 优先还原为：

```text
Pi-X = 理论上的解释对象 / 触发对象 / 处理对象；
Pi-Y = 理论上的被解释对象 / 行为结果 / 后果对象；
Pi-R = Pi-X 与 Pi-Y 之间的方向性关系或可检验关系。
```

重要分层：

```text
A02:
  只还原 Pi-X / Pi-Y / Pi-R，即作者要证明的基本经验关系。

A03:
  处理 Pi-X / Pi-Y 如何被 proxy / observable measurement 捕捉。

A04:
  处理为什么 Pi-X 会影响 Pi-Y，即 mechanism / warrant。

A07:
  处理统计设计、结果、diagnostic pattern、robustness、exclusion test。
```

案例纠偏：

```text
P1：基金经理受有限注意力影响。

正确 A02-P1：
  P1-X = 有限注意力 / attention exposure；
  P1-Y = 基金经理交易行为；
  P1-R = P1-X 与 P1-Y 存在符合有限注意力理论的关系。

错误写法：
  直接把“买入端强于卖出端”“不是 RPI / flow-catering / tone”列成 P1 proof burden。

原因：
  买入端强于卖出端是 diagnostic pattern；
  RPI / flow-catering / tone 是 alternative explanation / exclusion；
  它们服务于 P1-R 的可信度，但不是 A02 的第一层结构。
```

## 2026-07-06 A02 Theoretical Layer And Knowledge Base

用户进一步指出：A02-P1 不能写“如果媒体覆盖把股票推入注意力集合，那么基金经理交易行为应对媒体覆盖反应”。这已经让 `media coverage` 这个 proxy 偷跑进 A02。

修正规则：

```text
A02 必须停留在理论对象和理论关系层。
具体 proxy / measurement / statistical result 不得提前进入。

media coverage、PROPENSITY_BUY_MEDIA、future alpha、Table 9 等，
默认属于 A03 / A07，而不是 A02。
```

因此 A02-Pi 增加 `Pi-KB`：

```text
Pi-X = 理论解释对象 / 触发对象 / 处理对象；
Pi-Y = 理论被解释对象 / 行为结果 / 后果对象；
Pi-R = Pi-X 与 Pi-Y 的理论关系；
Pi-KB = 既有文献对 Pi-X / Pi-Y / Pi-R 的知识基础、已知结论和缺口。
```

以 P1 为例：

```text
P1：基金经理受有限注意力影响。

合格 A02-P1：
  P1-X = 有限注意力 / 注意力约束；
  P1-Y = 基金经理交易行为 / 投资选择；
  P1-R = 有限注意力会系统性影响基金经理交易行为；
  P1-KB = 既有文献支持有限注意力会影响投资者行为 / 市场反应，
          但专业基金经理是否同样受影响仍是本文要推进的问题。

A03-P1 才讨论：
  media coverage 如何代理 attention trigger；
  fund buys / sells 如何代理 trading behavior。

A07-P1 才讨论：
  媒体覆盖股票是否更容易被基金买入；
  买入端强于卖出端等 diagnostic pattern。
```

## 2026-07-06 A03 Must Follow A02 Proof Structure

用户进一步指出：A03 应该基于 A02 的 `P1-X / P1-Y / P1-R`、`P2-X / P2-Y / P2-R` 继续分析，而不是凭空列 proxy。

规则：

```text
A02 产出理论层 proof structure：
  Pi-X；
  Pi-Y；
  Pi-R。

A03 承接 A02：
  A03-Pi-X = Pi-X 如何被 proxy / observable 捕捉；
  A03-Pi-Y = Pi-Y 如何被 measurement 捕捉；
  A03-Pi-R = Pi-R 如何被经验化为可检验关系。
```

每个 A03 bridge 必须说明：

```text
A02 object / relation；
empirical proxy / measure / relation；
why credible；
remaining threats / competing interpretations。
```

重点不是“作者用了什么 proxy”而已，还要回答：

```text
作者凭什么说这个 proxy 能代表理论对象？
这个 empirical relation 为什么对应理论关系，而不是偷换问题？
还有哪些竞争解释或测量威胁？
```

案例：

```text
P1-X = 有限注意力 / 注意力约束。
A03-P1-X 才讨论 media coverage 如何代理 attention trigger。

P1-Y = 基金经理交易行为。
A03-P1-Y 才讨论 fund buys / sells 如何代理 trading behavior。

P1-R = 有限注意力会系统性影响基金经理交易行为。
A03-P1-R 才讨论 media-covered stocks -> fund buys 这个经验关系；
详细统计设计和结果留到 A07。
```
