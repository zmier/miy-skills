# Domain Adapter Contract

领域适配 Skill 用来把通用论证有效性能力映射到具体领域。它不是复制父 workflow，而是声明领域对象、证据类型、断点类型和输出文本约束。

## 必须声明

1. 领域对象：
   - 例如学术论文、商业报告、政策建议、课程材料。
2. 领域中的论点：
   - 例如贡献声称、政策建议、管理结论。
3. 领域中的论据：
   - 例如数据、模型、案例、文献、访谈、实验。
4. 领域中的关键箭头：
   - 例如 gap -> contribution、result -> recommendation。
5. 通用断点的领域化名称：
   - 例如概念不一致 -> construct-measure mismatch。
6. 输出文本约束：
   - 例如审稿意见要克制、证据化、可执行。

## 不允许

- 把课程逐字稿直接写进领域 Skill 主流程。
- 把一个领域案例的具体结论写成通用规则。
- 忽略父 workflow 的证据边界。
- 只调用父 Skill 名称，却不声明领域映射。

## 最小模板

```text
通用元素 -> 领域元素
论点 -> ...
论据 -> ...
箭头 -> ...
断点 -> ...
输出 -> ...
```
