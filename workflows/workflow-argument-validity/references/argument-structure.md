# Argument Structure

论证有效性审查先看结构，再看细节。

## 基本元素

| 元素 | 说明 |
|---|---|
| 论点 / 结论 | 作者想让读者接受的判断 |
| 论据 | 作者用来支撑结论的事实、数据、例子、理论或结果 |
| 箭头 | 从论据到结论的推理关系 |
| 隐含假设 | 作者没有明说，但推理成立必须依赖的前提 |
| 关键词 | 论据和结论中的核心名词、范围、层级、时间和衡量标准 |

## 常见结构

```text
直推：A -> B -> C
合推：A + B -> C
分推：A -> B / C
组合：多个直推、合推、分推嵌套
```

## 审查动作

1. 先找结论。
2. 再找论据。
3. 标出箭头。
4. 对比论据词和结论词。
5. 补出隐含假设。
6. 判断每个箭头是否成立。

## 段落表达

每个问题段尽量包含：

```text
定位 -> 分析 -> 收尾 -> 建议
```

定位说明作者的哪条推理；分析说明为什么推不出；收尾回到结论；建议说明如何补强或降调。
