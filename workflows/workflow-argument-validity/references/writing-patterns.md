# Writing Patterns

论证有效性写作的目标是克制、清楚、可执行。

## 通用段落模板

```text
作者将 A 作为 C 的依据。然而，A 更直接说明的是 A1；若要推出 C，还需要证明 B。当前文本尚未说明 B，因此 A 尚不足以支持 C。作者可以补充 B 的证据，或将结论限定在 A1 层面。
```

## 学术审稿段落模板

```text
作者将 A 作为 B 的经验证据，并进一步据此推出 C。然而，A 与 B 并不完全等同：A 更直接反映的是……，而 B 至少还要求……。因此，若作者希望维持关于 C 的较强表述，需要进一步说明 A 为什么能够有效代表 B；否则，结论应限定在 A 所能直接支持的范围内。
```

## 推荐措辞

| 中文 | 英文 |
|---|---|
| 尚不足以支持 | does not yet fully support |
| 有待进一步说明 | requires further clarification |
| 这一推理仍显跳跃 | this inferential step remains underdeveloped |
| 可能存在概念层面的错位 | may involve a construct mismatch |
| 需要更清楚地区分 | should more clearly distinguish |
| 当前证据更直接支持的是 | the evidence more directly supports |
| 作者可以考虑降低表述强度 | the authors may consider tempering the claim |

## 避免措辞

| 中文 | 英文 |
|---|---|
| 荒谬 | absurd |
| 毫无道理 | groundless |
| 显然错误 | obviously wrong |
| 完全无效 | completely invalid |
| 作者不懂 | the authors fail to understand |

## 可读性检查

写完后逐条问：

1. 读者知道我在质疑哪条作者论证吗？
2. 我解释了为什么推不出吗？
3. 我回到了作者核心结论吗？
4. 我给了作者可执行的修改方向吗？
5. 我有没有依赖只有自己知道的前序背景？
