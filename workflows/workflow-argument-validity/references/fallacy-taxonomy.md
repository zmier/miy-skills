# Fallacy Taxonomy

本表是断点识别库，不是术语堆砌清单。使用时优先解释“为什么推不出”，术语只作为内部分类。

| 类型 | 判断问题 | 常见修复 |
|---|---|---|
| 概念不一致 | 论据和结论是否使用不同概念 | 明确概念边界，补中间条件 |
| 过度推理 | 论据是否只能支持较弱结论 | 降低结论强度 |
| 因果跳跃 | 是否从相关、共现或时间顺序推出因果 | 补识别、机制或替代解释排除 |
| 以偏概全 | 是否从局部样本推出整体结论 | 限定适用范围或补样本证据 |
| 数字陷阱 | 平均数、比例、增长率、份额、指数是否被误读 | 解释量纲、基数、分布和转换 |
| 不当假设 | 是否依赖未证明前提 | 显式说明并验证假设 |
| 不当比较 / 类比 | 比较对象是否同层级、同口径、同条件 | 重设比较对象或说明可比性 |
| 条件陷阱 | 必要条件、充分条件是否混用 | 改写条件关系 |
| 手段目的陷阱 | 手段是否可行、可取、有效或最优 | 讨论可行性、成本、替代方案 |
| 自相矛盾 | 文中不同位置是否互相冲突 | 统一表述或说明边界 |
| 忽略发展 | 是否把历史事实直接推到未来或后续阶段 | 引入动态变化、滞后和边界 |
| 顾此失彼 | 是否只看一面，忽略反向机制或成本 | 补充反向机制和边界条件 |
| 更换衡量标准 | 评价对象和实际标准是否匹配 | 使用合适指标或降低结论 |

## 使用纪律

- 不要求每次输出术语。
- 不把一个断点硬塞进唯一分类。
- 同一问题可有多个分类视角，选择最有助于目标文本的表达。
- 对学术审稿，优先映射为 construct、measurement、identification、sample、result、claim 等专业问题。
