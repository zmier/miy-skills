# 09 论证有效性分析：谬误识别 4

## 本讲主题

讲最后两类逻辑问题：顾此失彼和更换衡量标准，并总结谬误识别学习方式。

## 顾此失彼

顾此失彼指只考虑问题一面，忽略另一面。

常见表现：

1. 只看好处，不看坏处；
2. 只看坏处，不看好处；
3. 只看某一部分，不看其他组成部分；
4. 只看一个因素，不看其他条件。

课程用“恨而知其长，爱而知其短”概括这种能力：反对时也看到长处，支持时也看到短处。

## 对论说文的启发

课程特别指出，商科考试重视分析利弊的能力。不是简单判断对错，而是：

```text
成年人分析利弊。
```

这意味着写作中可以有明确主张，但不能只看单面。

## 更换衡量标准

更换衡量标准是指用不合适的标准评价对象。

常见形式：

- 用学术刊物发表数量衡量真正经济学家；
- 用文化理解标准判断科学性；
- 用是否有用判断是不是科学；
- 用是否属于封建时代判断某种伦理标准是否合理。

分析方式：

```text
判断 A 应使用 A 对应的标准，
材料却用了 B 标准，
因此推理不充分。
```

## 日常对话中的论证

课程提醒：日常对话也有论证结构，只是更松散。训练有素的学习者要能在对话中分辨论据、结论和箭头。

## 谬误学习方式

课程最后用“从有招到无招”的比喻说明：

1. 初学时需要分类、套路和模板；
2. 熟练后不应拘泥于术语；
3. 考场上要形成自然反应；
4. 真正目标是融会贯通。

## 本讲核心句

```text
先从有招学起，最终不要拘泥于招式。
```
