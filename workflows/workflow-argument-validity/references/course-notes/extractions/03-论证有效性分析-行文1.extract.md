# 03 论证有效性分析：行文 1

## 本讲主题

讲标题、开头、结尾和总体措辞。核心是从结构层次上把握行文，而不是机械背模板。

## 标题写法

标题不能：

- 写成文体名，如“论证分析”；
- 提出自己的正向观点；
- 支持原材料结论；
- 写得情绪化或莫名其妙。

推荐方式：

```text
质疑论点的话题关键词
```

例如：

```text
利用赏罚就能治理好臣民吗
大学生就业真的不难吗
```

问号可加可不加。

## 全文行数规划

以 600 字左右为基础，课程建议：

```text
标题
开头 3 行以内
本论 4 段，每段约 6 行
结尾 3 行以内
```

这不是绝对公式，而是为了让结构清楚、方便阅卷。

## 开头写法

开头一般两层：

1. 概括材料；
2. 表达质疑。

例式：

```text
材料试图通过一系列论证得出结论：P。综观其论证过程，仍存在若干逻辑问题，其结论不那么可信。
```

注意：

- 论据复杂时概括即可；
- 不要长篇复述材料；
- 开头结构完整即可，不是得分重点。

## 结尾写法

结尾也一般两层：

1. 总结自己前文的分析；
2. 再次表达质疑。

例式：

```text
综上，材料中存在多处逻辑问题，因此关于 P 的结论尚需进一步讨论。
```

可适度列逻辑问题术语，但不必强求。

## 简约意识

课程反复强调“化繁为简”。开头和结尾不要啰嗦，因为真正得分的分析在本论部分。

## 本论措辞原则

总体措辞要“帮忙不添乱”，即：

| 推荐 | 避免 |
|---|---|
| 未必成立 | 非常荒谬 |
| 有些牵强 | 毫无道理 |
| 值得商榷 | 痴人说梦 |
| 也许 / 可能 | 必然 / 一定 |
| 有待证明 | 完全错误 |

语气要中性、克制、有分寸。

## 写与改

课程强调：

```text
写不能提高，改才能提高。
```

先写出来，再根据结构、措辞、分析深度和字数进行修改。

## 本讲核心句

```text
开头结尾起结构作用，真正要把空间留给本论分析。
```
