# 02 论证有效性分析：审题

## 本讲主题

讲如何审题、如何抓住论证结构。重点是通过结构关键词和标点，快速判断论点、论据和推理方式。

## 论点位置

论点可能出现三种位置：

1. 前置；
2. 中置；
3. 后置。

近年真题中，总论点常在第一段最后一句；最后一段可能有总结，也可能没有。

## 推理方法

课程把推理结构概括为三类：

| 推理方法 | 结构 |
|---|---|
| 直推法 | A -> B -> C |
| 合推法 | A + B -> C |
| 分推法 | A -> B / C |

复杂论证也通常由这些结构组合而成。

## 材料整体结构

近年材料常见结构是：

```text
总分总
或
总分
```

中间的“分”多为并列分论点，少数为递进式结构。

## 审题第一步：找总论点和总结论

技术动作：

1. 看第一段最后一句，找总论点；
2. 看最后一段第一个词，判断是否有总结；
3. 如果有总结，比较总论点和总结论的话题关键词；
4. 重点比较主谓宾是否一致。

这样可以发现可能的偷换概念。

## 审题第二步：看结构关键词

课程强调：

```text
句号先，逗号后。
```

先看句子之间的结构关系，再看句子内部的分句关系。

常见结构词包括：

| 词语 | 常见作用 |
|---|---|
| 据报道 / 据统计 | 引出论据 |
| 因此 / 所以 / 这说明 | 引出结论或推论 |
| 总之 / 由此可见 | 引出总结 |
| 因为 | 可能是补充论据，也可能是溯因 |
| 其实 | 常引出论点或分论点 |

## 标点的重要性

同样的词，因为前面是句号、逗号还是分号，可能影响推理关系。标点和结构词共同帮助判断段落内部层次。

## 话题关键词

判断论据和结论关系时，要抓话题关键词，尤其是主语、谓语和宾语。课程多次示范：只要论据词和结论词不一致，就可能存在概念或范围问题。

## 不要被故事带跑

看到“据报道”等词，不要先好奇报道了什么，而要先判断这句话在结构上是不是论据。审题时主要任务是识别结构，不是理解全部细节。

## 复杂结构处理

简单结构可以直接在材料中标箭头；复杂结构要在旁边写出结构图。遇到自问自答、解释说明、合推分推组合时，要先还原谁支持谁。

## 本讲核心句

```text
外行看热闹，看材料在说什么；内行看门道，看论证结构怎么搭。
```
