# 05 论证有效性分析：行文 3

## 本讲主题

继续讲本论段落，重点是分析句、连接词、收尾句，以及避免形式主义。

## 分析句引导词

常见分析引导：

| 词语 | 功能 |
|---|---|
| 因为 / 这是因为 | 引出原因分析 |
| 如果 | 引入条件或可能情况 |
| 也可能是 | 引入替代可能性 |

这些词告诉读者：后面开始解释为什么推不出。

## 组合分析连接词

组合分析需要连接多个分析点：

| 类型 | 常见词 |
|---|---|
| 递进 | 况且、进一步说 |
| 让步 | 即使、就算 |
| 并列 | 此外、同时 |

例式：

```text
这是因为……；况且……
即使……，也……
……；此外，……
```

## 收尾句

收尾句的作用是把前面分析和材料结论接上。

常见形式：

```text
因此，S 并不能说明 P。
所以，材料的这一推论并不充分。
```

课程强调：如果前面分析没有提到分论点或结论，收尾句就必须写；否则容易变成只找漏洞、不说明漏洞影响结论。

## 避免形式主义

### 定位句可以省，定位功能不能省

如果分析句已经通过关键词让读者知道你在说哪里，就可以不单独写定位句。

### 收尾句可以省，收尾功能不能省

如果分析句已经明确回扣结论，收尾句可以省；如果没有回扣，就必须补。

### 分析深度不等于字数多

分析要一针见血。冗长不代表深入，反而可能让阅卷者看不清。

## 官方解析的学习方式

课程提醒：官方解析不是给考生做完整行文示范的，它主要用于阅卷采点。学习时要吸收其中的思路和表达，但不能机械照抄。

## 常见错误写法

1. 开头缺少“必然”等限定，导致直接否定结论；
2. 用古人名言、个人观点或情感判断作为分析依据；
3. 脱离材料箭头，展开自己的观点；
4. 滥用逻辑术语但不分析；
5. 用“我认为”替代客观分析；
6. 提自己的论说文观点。

## 本讲核心句

```text
定位句和收尾句可以灵活，但定位功能和回扣功能不能丢。
```
