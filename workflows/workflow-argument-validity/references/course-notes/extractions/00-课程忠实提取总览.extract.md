# 论证有效性分析课程忠实提取总览

## 课程定位

本课程讲的是管理类/经济类联考写作中的“论证有效性分析”。它的任务不是提出自己的观点，也不是证明材料结论错误，而是指出材料中的论据不能充分支持结论。

一句话：

```text
看论据能不能推出结论；推不出，就说明箭头哪里断了。
```

## 课程四大模块

| 模块 | 解决的问题 | 核心动作 |
|---|---|---|
| 审题抓论证 | 找不到逻辑问题 | 找论点、论据、结构关键词、标点和箭头 |
| 行文结构 | 找到了但不会写 | 标题、开头、本论、结尾；本论定位-分析-收尾 |
| 谬误识别 | 说不清为什么错 | 积累常见推理错误和表达方式 |
| 练习方法 | 写不稳、改不动 | 电子版初稿、对照解析、修改、二稿、三稿 |

## 学习阶段

| 阶段 | 典型问题 | 课程解决方案 |
|---|---|---|
| 初学 | 找不到 | 不先理解故事，先识别论证结构 |
| 攻坚 | 说不清 | 学会谬误识别和分析句表达 |
| 成熟 | 道不尽 | 学会段落规划、组合分析和语言精炼 |

## 课程核心原则

1. **少评论，多分析**  
   评论只是说“论证不成立”；分析要说明为什么由论据推不出结论。

2. **命题点主要在箭头上**  
   重点不是材料讲了什么故事，而是论据和结论之间的推理关系是否成立。

3. **核心概念在论点里**  
   论点中的关键词最值得敏感，因为偷换概念常发生在这些词上。

4. **不是数漏洞个数**  
   关键是把每组论证中的主要问题分析到位。

5. **写作不是堆模板**  
   结构可以稳定，但语言必须根据材料灵活表达。

6. **术语不重要，讲清问题重要**  
   术语不能替代分析；官方解析也常常不用术语。
