# 07 论证有效性分析：谬误识别 2

## 本讲主题

继续讲常见逻辑谬误，重点包括极化思考、不当假设、因果问题和以偏概全。

## 极化思考

极化思考包括：

1. 非黑即白；
2. 过于绝对。

常见信号：

```text
不是 A 就是 B
要么 A 要么 B
不是 A 而是 B
完全
必然
首先（表示“最应该”时）
```

应对方式：

```text
是否还有第三种可能？
是否 A 和 B 可以同时存在？
是否二者都不成立？
```

## 不当假设

不当假设是较难的部分。它指论证依赖一个没有说出来、但必须成立的前提。

课程提醒：

- 这类题难度高；
- 近年不常作为重点；
- 学习它主要是为了增强论证感觉。

常见表达：

```text
该推理必须假设……
但这一假设未必成立。
```

## 因果问题

因果类问题要看：

1. 是否把相关当因果；
2. 是否忽略其他原因；
3. 是否强拉因果；
4. 是否把因果方向搞反。

常见削弱方式：

```text
另找他因
指出二者可能相互作用
指出现象可能由多种因素造成
```

## 求异实验

如果材料构造类似实验对比，要看差异因素是否唯一。若两组之间不止一个差异，就不能把结果归因于某一个因素。

## 以偏概全

以偏概全是从局部推出整体。

常见表现：

- 某地区推全国；
- 某时段推全年；
- 某类企业推所有企业；
- 部分群体推整体群体；
- 个别例子否定一般规律。

表达方式：

```text
A 只能说明局部情况，未必能代表整体。
```

## 选择性证据

课程扩展讲到选择性证据：只选支持自己结论的证据，而忽略不利证据。现实中网络讨论、晒分、机构宣传等都可能有选择性样本问题。

## 本讲核心句

```text
不要进入材料给你的二选一；先想有没有其他可能。
```
