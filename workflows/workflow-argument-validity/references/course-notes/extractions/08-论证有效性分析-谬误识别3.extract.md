# 08 论证有效性分析：谬误识别 3

## 本讲主题

继续讲数字陷阱、手段目的、条件、比较类比、自相矛盾和忽略发展。

## 数字陷阱

数字陷阱主要包括：

| 类型 | 问题 |
|---|---|
| 样本问题 | 样本太小、样本选择不代表总体 |
| 平均数陷阱 | 平均数掩盖分布、差异和两极分化 |
| 百分比陷阱 | 比例、增长率、份额不能直接说明绝对水平 |

课程提醒：看到比例、率、平均数，要想到基数、分子分母和样本来源。

## 手段目的陷阱

看到“为了……”“通过……”等结构，要判断手段和目的关系。

削弱角度：

1. 手段不可行；
2. 手段不可取；
3. 手段无意义；
4. 有更好替代手段。

表达重点：

```text
该手段未必能达到材料声称的目的。
```

## 条件陷阱

条件关系涉及充分条件、必要条件、充要条件。常见问题是把“需要”说成“只需要”，或把必要条件误当充分条件。

## 不当比较与不当类比

### 不当比较

比较对象在重要条件上不同，不能简单比较。

常见问题：

- 国家不同；
- 地区不同；
- 时间不同；
- 市场环境不同；
- 发展阶段不同。

### 不当类比

类比对象属于不同类别，且关键属性不一致。

课程提醒：寓言、实验、动物行为类材料如果类推到企业、社会或管理场景，容易存在不当类比。

## 自相矛盾

自相矛盾难点在识别，不在表达。因为矛盾的两句话可能隔得很远：

- 总论点和分论点矛盾；
- 分论点和论据矛盾；
- 两个分论点互相矛盾。

表达方式：

```text
材料一方面认为 A，另一方面又认为 B，二者自相矛盾。
```

## 忽略发展

忽略发展指用静态眼光看问题，忽视未来变化。

课程中的重要区分：

```text
历史不会重复它的事实，
但历史会重复它的规律。
```

如果认为某个历史事实一定再次发生，可能是忽略发展；如果从历史中总结规律，则不一定是错误。

常见信号：

- 过去几年；
- 未来十年；
- 当前未成年人未来成年后；
- 用现在数据推未来状态。

## 本讲核心句

```text
看到数字看样本和基数；看到时间差想发展变化；看到比较想可比性。
```
