# Acceptance Contract

## 任务类型

`case-calibration / prior-exposed / workflow-migration`

## GIVEN

- 已有论效题与 GRE Argument 分支，底层能力为：

```text
恢复论证树 -> 检查支撑箭头 -> 标注断点影响 -> 输出可读文本
```

- 已有对话洞见 001-004，提出学术论文的 `X1 + X2 -> Y` 顶层结构。
- 已有 J-260110 稿件和欣媛审稿意见作为 case-local evidence。

## WHEN

将学术论文审稿视为“大型论证树审查”，而不是模块 checklist：

```text
稿件 -> X1/X2/Y 论证树
欣媛 major concerns -> 断裂箭头
断裂箭头 -> 审稿意见写法 / adapter 规则
```

## THEN

本 TASK 通过当且仅当：

1. 能从稿件恢复 `Y: 论文值得发表 / 贡献成立` 的顶层论证；
2. 能区分 `X1: 问题有意义` 与 `X2: 作者证明了具体核心发现`，且 `X2` 必须写清哪个 X 通过什么机制 M 影响哪个 Y；
3. 能把欣媛审稿意见中的主要问题映射到具体箭头，而不是只归入文献、方法、变量、结果模块；
4. 能说明每个断点如何影响最终贡献成立；
5. 能给出可迁移规则与个案边界；
6. 能提出是否需要新建 `workflow-academic-review-argument` 子 workflow 的判断。
7. 能建立底层证据台账，将表格、系数、显著性、变量定义、模型设定、文献引用和原文段落追溯到对应节点/箭头；缺少具体表格值时标记 `needs-table-qc`。

## 不通过情形

- 只复述欣媛审稿意见，没有画论文论证树；
- 只按文献/方法/变量/结果列 checklist，没有说明箭头；
- 把 J-260110 的个案判断直接写成通用规则；
- 只证明欣媛意见“像论效”，但没有回答学术论文审稿如何迁移；
- 依赖 `workflow-paper-writing-review` 的模块流程覆盖论证树主轴。
