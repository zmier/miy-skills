# Review Issue Arrow Map

## 映射原则

每条欣媛审稿意见都映射为：

```text
review issue -> target arrow -> weakened node -> impact on Y
```

其中：

- `X1`：问题有意义；
- `X2`：作者证明了具体核心发现，即“主动披露违规 -> 声誉竞争/市场压力 -> 同行披露质量提升”；
- `Y`：贡献成立 / 值得发表。

|---|---|---|---|---|---|

## V2：论效式箭头审查表

上一表仍然偏“审稿 issue -> 节点”。为了更像论效题，需要改写为：

```text
作者用 A 推出 B；
欣媛指出 A 不足以推出 B；
因此 B / X2 / Y 变弱。
```

| arrow_id | from_node | to_node | 作者如何论证 | 欣媛如何质疑 | 影响 X1/X2/Y |
|---|---|---|---|---|---|
| A1 | 现有文献较少关注主动披露违规对同行披露质量的影响 | X1：问题有意义 | 作者把该缺口作为研究意义和贡献来源 | 欣媛主要未攻击 X1，但该 gap 仍需更清楚区分主动披露、负面披露、同行影响和披露质量 | X1 有基础但不算完全稳 |
| A2 | X：主动披露违规是一种治理态度/行为信号 | M1：市场正向反馈 | 作者认为“自曝其短”展示诚实守信和自我纠偏，因而市场给予声誉补偿 | 欣媛指出，若样本违规大多危害不高、信息含量少，这种低成本信号为何能得到强市场回报需要额外解释 | 削弱 X2 的理论机制，即 X 为什么能触发 M1 |
| A3 | M1：市场正向反馈 | Y1：同行披露质量改善 | 作者认为同行看到事件公司获得市场认可，会为维持竞争地位改善披露 | 欣媛指出，若事件公司自身披露质量没有改善或获益，同行模仿的直接前提不足 | 削弱 X2 的溢出机制，即 M1 如何传到 Y1 |
| A4 | KV 指数下降 / 变化 | Y1：同行信息披露质量改善 | 作者把 KV 作为信息披露质量反向代理，进而解释为披露质量提升 | 欣媛指出 KV 高度依赖量价关系，可能反映投资者情绪和交易行为，而非企业实质披露改善 | 削弱 X2 的测量有效性，即 Y1 是否被测到 |
| A5 | 当年无问询/处罚的违规披露 | X：真实主动披露违规 | 作者把当年未见问询/处罚作为主动披露定义 | 欣媛指出处罚可能跨年，企业可能是在监管程序中抢先披露，即“被迫主动” | 削弱 X2 的处理定义，即 X 是否成立 |
| A6 | 公司年度 EFD | 外部融资依赖异质性解释 | 作者用公司年度财务数据构造 EFD 并解释融资依赖差异 | 欣媛指出经典 EFD 更偏行业长期结构，公司短期指标可能是经营噪音或融资约束结果 | 削弱 X2 的异质性解释 |
| A7 | 公司层面聚类后的显著结果 | P6：DID 识别可信 | 作者在公司层面聚类后报告核心交互项显著 | 欣媛指出处理变量在行业年度层面变化，低层级聚类可能低估标准误并夸大显著性 | 削弱 X2 的统计显著性 |
| A8 | 剔除同业集中违规事件后的干净样本 | P5：样本能代表机制相关事件 | 作者认为剔除重叠事件可获得干净识别 | 欣媛指出这些被剔除事件可能恰是市场关注最高、溢出机制最强的事件 | 削弱 X2 的样本代表性和外部有效性 |
| A9 | POST 从事件当年开始取 1 | P6：处理效应被正确估计 | 作者把事件当年和后两年纳入处理后期间 | 欣媛指出同行观察、决策和披露改善需要时间，表3也显示当年不显著、后续显著 | 削弱 X2 的时间结构设定 |
| A10 | 多种常规稳健性通过 | P8：稳健性回应核心威胁 | 作者用堆叠 DID、Bacon、安慰剂、PSM、Oster、替换变量等证明稳健 | 欣媛指出这些检验多在同一有偏样本和定义下重复验证，未回应样本筛选、变量构造和聚类层级等核心质疑 | 削弱 X2 的稳健性支撑 |
| A11 | 处罚次数/严重程度不显著 | P7：信息传导机制不存在 | 作者用同行处罚不显著排除监管信息传导机制 | 欣媛指出处罚不显著也可能是威慑生效、企业整改后的结果，不能直接排除机制 | 削弱 X2 的机制排除 |
| A12 | Y1：同行披露质量短期改善 | Y2：行业自律发展 | 作者把同行 KV 改善上升为行业自律和资本市场治理改善 | 欣媛指出短期指标变化不足以承载长期、结构性的行业治理叙事 | 削弱 Y 的贡献上升，即 Y1 能否推出 Y2 |
| A13 | 回归表格规范 | Y：研究可信度/发表正当性 | 作者用回归表支撑经验发现 | 欣媛指出括号数值看似 t 值却标为标准误，虽属规范问题，但会影响读者对报告可信度的判断 | 轻度削弱 Y |

## V2 关键判断

从论效角度看，最重要的不是“欣媛提出了变量、样本、方法、机制问题”，而是她不断在问：

```text
作者当前给出的 A，真的足以推出 B 吗？
```

例如：

```text
KV 变化
-> 信息披露质量改善
-> 行业自律发展
```

这条链被拆成 A4 和 A12 两条箭头，分别对应测量有效性和贡献上升。

又如：

```text
无当年处罚/问询
-> 真实主动披露
-> 声誉机制成立
```

这条链被拆成 A5 和 A2，分别对应处理定义和理论机制。

因此，学术论文审稿版论证树应强制输出 `arrow table`，否则很容易退回模块 checklist。

## V3：中层节点继续展开的箭头

V2 的 `P5`、`P8` 仍然是中层命题。V3 需要继续拆它们自己的底层论据：

| arrow_id | from_node | to_node | 作者如何论证 | 欣媛如何质疑 | 影响 |
|---|---|---|---|---|---|
| A8-1 | 剔除同业重叠事件 + 保留行业首次事件 | 干净同行溢出样本 | 作者认为这样可以减少事件混淆，锁定单一行业冲击 | 欣媛指出同业集中事件可能正是市场关注度最高、机制最强的事件 | 削弱 P5 的代表性 |
| A8-2 | 干净同行溢出样本 | P5：样本能代表机制相关事件 | 作者从干净识别进一步默认样本能代表研究对象 | 欣媛指出干净识别不等于机制相关代表性 | 削弱 P5 -> P6 |
| A8-3 | 剔除事件公司自身样本 | 只考察同行反应 | 作者聚焦溢出效应 | 欣媛指出若事件公司自身没有改善或获益，同行模仿缺少直接前提 | 削弱 P3/P5 |
| A10-1 | 堆叠 DID + Bacon + 安慰剂 + PSM/熵平衡 + Oster + 替换变量 | 结果稳健 | 作者用多组检验说明主效应不依赖单一设定 | 欣媛指出这些检验多在同一核心定义和样本框架内重复验证 | 结果稳健只能部分成立 |
| A10-2 | 结果稳健 | P8：核心威胁已被回应 | 作者把常规稳健性通过上升为研究结论稳健 | 欣媛指出核心威胁来自处理定义、样本筛选、KV 测量、聚类层级和机制前提，常规稳健性没有逐一回应 | 削弱 P8 -> P6 |
| A1-1 | 证券法修订 + 处罚提高 + 违规仍多 + 事前预防监管 | G1：信息披露监管重要 | 作者用制度变化和现实违规说明研究背景重要 | 这一箭头相对稳，但只支持背景重要，不直接支持本文贡献成立 | 支撑 X1，但不能替代 gap/novelty |

V3 的关键修正是：

```text
中层命题本身也要被审查。
```

例如：

```text
P8 稳健性回应核心威胁
```

不是一个天然成立的节点，而是由：

```text
多种稳健性检验 -> 结果稳健 -> 核心威胁已被回应
```

组成的两级箭头。欣媛质疑的是第二级箭头。

## 汇总判断

欣媛意见不是平均攻击所有节点，而是集中攻击 `X2: 作者证明了核心发现`：

```text
F1 理论机制
F2 变量定义和测量
F3 样本设计
F4 识别策略
F6 稳健性
F7 机制检验
-> X2 作者证明了核心发现：主动披露违规提升同行披露质量
```

因此，在本 case 中：

```text
X1 问题有意义：有基础，但 gap/novelty 需要更精确
X2 作者证明了核心发现：被多条 major concern 削弱
Y 贡献成立：因为 X2 不稳而显著变弱
```

## 适合写入审稿意见的组合方式

可以将 R1、R3、R9、R10 合并为“机制链不闭合”：

```text
作者需要稳定地区分行为信号、内容信息、声誉竞争、市场压力和信息传导机制。
目前不同章节对这些机制的使用并不完全一致，因此机制证据尚不足以支撑核心解释。
```

可以将 R2、R5、R7、R8 合并为“识别与样本边界不稳”：

```text
样本筛选、处理定义、聚类层级和 POST 时间结构共同决定核心 DID 估计是否可信。
这些问题如果不解决，主结果即使显著，也难以支持强因果和政策结论。
```

可以将 R4、R11 合并为“测量与稳健性没有回应核心贡献”：

```text
如果 KV 主要反映短期市场量价关系，且稳健性没有转向更直接的披露质量指标或长期行业治理指标，
则论文不宜上升到“行业自律发展”的强贡献叙事。
```

## TASK01 迁移结论

本映射说明：学术论文审稿中的 major concern 应先绑定到论文论证树的节点和箭头。这样可以避免把审稿写成模块清单，也能解释为什么某些看似技术性的变量、聚类或样本问题，其实会影响最终贡献是否成立。
