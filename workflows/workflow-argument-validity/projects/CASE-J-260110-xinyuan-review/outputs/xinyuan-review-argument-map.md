# Xinyuan Review Argument Map

## 案例定位

本文件不重述审稿意见全文，只抽取其中可迁移的论证有效性结构。

## 作者稿件的核心声称链

```text
企业主动披露违规
-> 市场正向解读 / 声誉竞争 / 市场压力
-> 同行业其他企业提升信息披露质量
-> 行业自律发展
```

欣媛审稿意见主要不是逐字挑错，而是检查这条链中多个箭头是否成立。

## 结构观察

欣媛意见常用的段落结构：

```text
定位作者原文或表格
-> 指出核心前提
-> 解释为什么该前提不稳
-> 说明对结论链的影响
-> 给出可执行修改建议
```

这与课程中的“定位句 - 分析句 - 收尾句”同构，只是审稿场景中多了“修改建议”和“证据位置”。

## 语气边界

欣媛意见强度较高，适合作为“高压强审稿意见”样例。但进入 Skill 时应保留其结构，不直接复制语气。以下措辞需要后续 post-flight 调整：

| 原倾向 | 风险 | 更稳表达方向 |
|---|---|---|
| “基本常识” | 可能显得压迫或冒犯 | “这一点可能影响显著性判断” |
| “低级错误” | 情绪压强过高 | “表注与括号数值含义不一致，需核实” |
| “严重损害” | 可保留但需证据支撑 | “削弱了理论框架的一致性” |

## 可迁移结论

该案例证明，强审稿意见的关键不是多列问题，而是把每个问题放回作者贡献链中，说明它如何影响核心结论。
