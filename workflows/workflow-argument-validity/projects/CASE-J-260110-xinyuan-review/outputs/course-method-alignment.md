# Course Method Alignment

## 总体判断

欣媛审稿意见并不遵循考试作文的形式结构，但高度符合论证有效性分析的底层方法：

```text
抓作者论证链
-> 定位关键箭头
-> 解释为什么推不出
-> 回到结论影响
-> 给出修改建议
```

## 与课程方法对应

| 课程方法 | 欣媛意见表现 | 例子 |
|---|---|---|
| 少评论，多分析 | 几乎每条 major concern 都解释了为什么影响结论 | 主动披露定义时序漏洞不仅说“不清”，还说明监管处罚跨年如何改变主动性含义 |
| 命题点在箭头 | 她抓的是作者从变量/结果/机制到结论的推理链 | KV 指数 -> 信息披露质量 -> 行业自律发展 |
| 核心概念敏感 | 抓住“行为信号”和“内容信息”的切换 | 需要声誉机制时强调信号，需要解释异质性时淡化信息含量 |
| 组合分析 | 同一 major concern 下常组合多个断点 | 样本筛选同时影响代表性、外部有效性和声誉/市场压力机制适用范围 |
| 定位-分析-收尾 | 多数段落先定位页码/表格/定义，再展开分析，最后给建议 | 表13、表16、图3/表10 的理论逻辑对照 |
| 不贴术语 | 很少写“偷换概念”“过度推理”等术语，但实质分析充分 | 信息传导机制排除中的反向因果 |
| 克制表达 | 部分符合，部分偏强 | 大部分建议具体；但“低级错误”等措辞需降压 |

## 与课程不同之处

| 不同点 | 原因 | 是否应迁移 |
|---|---|---|
| 不写标题式反问 | 审稿意见不是考试作文 | 不迁移 |
| 不按固定四段本论 | 审稿按 major/minor issue 组织 | 不迁移 |
| 每段加入修改建议 | 审稿需要可执行反馈 | 应迁移到 adapter |
| 使用专业计量判断 | 学术审稿领域要求 | 应迁移到 adapter/reference |
| 语气更锋利 | 高压强审稿风格 | 结构可迁移，语气需 post-flight 控制 |

## 课程方法的真实迁移形式

考试作文：

```text
材料指出 A，因此得出 C。这样的推理难以成立，因为……。因此，C 尚不能成立。
```

欣媛审稿：

```text
作者在第 X 页/表 Y 中使用 A 支撑 C。然而，如果 A 的含义是 A1，则它并不能支持 C 所要求的 B。该问题会影响作者关于机制/识别/贡献的核心结论。建议作者补充……或重新界定……。
```

## 结论

欣媛意见是“论证有效性分析在学术审稿中的自然形态”。它不是课程模板的复制，而是课程底层动作在专业语境中的转译。
