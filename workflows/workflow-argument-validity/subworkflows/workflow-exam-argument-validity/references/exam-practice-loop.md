# Exam Practice Loop

## 目标

把“会听懂”变成“能稳定写出来”。

## 练习循环

1. 初稿：
   - 先独立审题；
   - 画出论证链；
   - 写出完整文章或至少 3 个本论段。
2. 对照：
   - 对照课程解析或参考答案；
   - 比较自己漏掉的箭头、误判的关键词、写虚的分析句。
3. 二稿：
   - 保留原有好段；
   - 重写问题段；
   - 强化“定位-分析-收尾”。
4. 三稿：
   - 只在二稿仍不稳时进行；
   - 重点修表达、结构和段落轻重。
5. 回收：
   - 稳定错误写入个人错题或 workflow tests；
   - 可迁移模式写入 reference；
   - 个题特有内容不写成通用规则。

## 回归记录字段

| 字段 | 说明 |
|---|---|
| 题目来源 | 真题、模拟题、课程例题或自建材料 |
| 漏掉的论证链 | 哪条箭头没有识别出来 |
| 误判原因 | 被故事带跑、关键词不敏感、结构词漏看等 |
| 修改动作 | 重画树、重选点、重写段落 |
| 可迁移发现 | 是否值得进入 reference 或 asset |
