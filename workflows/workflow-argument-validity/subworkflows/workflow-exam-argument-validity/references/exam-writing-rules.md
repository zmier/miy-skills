# Exam Writing Rules

## 目标

把已识别的断裂箭头写成论效题作文，而不是写成零散批注。

## 基本结构

中文论效题：

```text
标题
开头：概括材料论证存在若干问题
本论：3-4 个问题段
结尾：总结材料论证尚不足以支持结论
```

GRE Analyze an Argument：

```text
Introduction: state the argument's conclusion and that it depends on assumptions, evidence, or unanswered questions.
Body: 3-4 assumption-impact or question-impact paragraphs, following the prompt instruction.
Conclusion: state what evidence, clarification, or answers would be needed.
```

## 本论段结构

每个本论段优先使用：

中文论效题：

```text
定位 -> 分析 -> 收尾
```

- 定位：作者将 A 作为 B 的依据；
- 分析：A 只能说明 A1，不能直接推出 B，除非补充某个前提；
- 收尾：因此，该论证尚不足以支持作者结论。

GRE Argument：

```text
Assumption -> Role in arrow -> Impact if false
```

- Assumption：作者暗中假设 H 成立；
- Role：H 支撑 `A -> B` 或 `B -> C` 哪条箭头；
- Impact：如果 H 不成立，上层结论如何降级、变弱或断裂。

示例骨架：

```text
The argument assumes that H. This assumption is necessary because the evidence A supports B only if H is true. If H is false, then A may be explained by ..., and the conclusion that C would be much weaker.
```

当题目要求 `questions that need to be answered` 时，不要把问题写成孤立清单，改用：

```text
Question -> Target arrow -> Yes/no impact
```

- Question：为了评价论证，需要回答 Q；
- Target arrow：Q 检验 `A -> B` 或 `B -> C` 哪条箭头；
- Yes/no impact：若答案为 yes，作者论证在哪一点被加强；若答案为 no，哪个上层结论会变弱。

示例骨架：

```text
One question that must be answered is whether Q. This question matters because the argument uses A to support B. If the answer is yes, A would provide stronger support for B; if the answer is no, A may be compatible with another explanation, and the conclusion that C would be less convincing.
```

## 语言规则

- 少贴术语，多说明为什么推不出；
- 不写“我认为材料观点错误”；
- 不展开自己的正向论证；
- 不把同一断点重复写成多段；
- 连接词服务于分析，不为模板而模板。
- GRE 场景下，不只提出问题；必须说明问题答案如何影响结论。
- GRE 问题型题干中，每个问题都要有 yes/no 或 alternative answer 的影响分析。
- GRE 场景下，不写自己的政策、价值或事实立场，除非它直接服务于 assumption impact。

## 选点与组合

- 优先写影响总论点或关键分论点的断点；
- 同一论证链上可以做组合分析，但要按箭头顺序写；
- 一个段落只抓一个主问题，必要时补一个辅助问题；
- 若断点很多，宁可少写几个讲清楚，不堆清单。
- GRE 场景下优先选择最能削弱根结论的 assumptions，而不是最容易吐槽的细节。
