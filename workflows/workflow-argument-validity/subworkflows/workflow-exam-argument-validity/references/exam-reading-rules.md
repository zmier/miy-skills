# Exam Reading Rules

## 目标

把论效题材料先读成论证结构，而不是读成故事。

## 技术动作

1. 找总论点：
   - 先看第一段最后一句；
   - 再看最后一段第一个词，判断是否有总结；
   - 若有总结，比较总论点与总结论的话题关键词。
2. 比较关键词：
   - 抓主语、谓语、宾语；
   - 看论点和结论是否换概念、换范围、换标准。
3. 审查概念关系：
   - 先找材料反复使用或承担推理功能的关键概念；
   - 若材料连续使用多个近义概念，先拆开其历史语境、制度含义、适用对象和评价色彩，不默认它们可以互换；
   - 再判断两个概念之间是真同一，还是包含、交叉、并列相容、无关、手段目的或因果关系；
   - 若作者把“部分”当“整体”、把“有交集”当“可替代”、把“可并存”当“非此即彼”、把“一种手段”当“唯一必要手段”，通常就是断裂箭头；
   - 遇到定义句，要把定义代回原命题或总论点，检查是否造成重复、矛盾、范围变化或论证失效；
   - 遇到 A/B 两种解释、方案或路径，要先判断二者是否互斥且穷尽；若不互斥或不穷尽，否定 A 不能推出 B；
   - 遇到“标准、条件、因素、保证、只要、只有”等词，要判断它是必要条件、充分条件、辅助条件还是唯一条件；
   - 不把“速度/总量”“手段/结果”“局部/整体”等当作死记清单，它们只是概念关系误判的具体例子。
4. 审查外推维度：
   - 当材料用一个事实推出趋势、总体或强结论时，检查是否发生时间、空间、对象、指标、场景或强度外推；
   - 特别注意“过去 -> 未来”“局部地区 -> 整体地区”“某类人群 -> 目标总体”“观测记录/曝光数量 -> 真实发生率”“指标 A -> 概念 B”“弱趋势 -> 强结论”。
5. 审查对比实验和归因：
   - 当材料用 A/B 对比推出某个原因时，检查除目标因素外是否还有其他变化因素；
   - 如果两组同时改变了口味、顺序、对象、环境或时间，就不能把结果差异单独归因于作者选定因素；
   - 某次随机成功不能直接推出策略有效，还要看失败样本、成本风险和反馈机制。
6. 审查工具、材料与主因机制：
   - 当材料发现某种工具、材料、模具、记录或制度痕迹时，先判断它只是“存在”，还是足以证明作者声称的主要生产方式、主要原因或唯一机制；
   - 区分主生产工具、辅助工具、练习工具、修补工具、研究样本、偶然遗留物和替代用途；
   - 局部发现不能自动推出整体机制，例如只发现头部/手部模具，不能直接推出整件作品都由人体模具制成。
7. 审查预测类结论：
   - 当材料预测价格、价值、需求、政策效果或行为变化时，必须追问行动者是谁、评价标准是什么、传导机制是什么、反向机制是什么；
   - 不把“原因解释改变”直接等同于“市场价格必然改变”，除非材料说明收藏者、消费者或决策者确实会按该因素重新定价。
8. 找结构关键词：
   - 句号先，逗号后；
   - 先判断句子之间的关系，再判断分句之间的关系。
9. 识别三类推理：
   - 直推：`A -> B -> C`；
   - 合推：`A + B -> C`；
   - 分推：`A -> B / C`。
10. 复杂结构处理：
   - 简单结构可直接在题干旁标箭头；
   - 复杂结构应画局部结构图；
   - 遇到自问自答、解释说明、让步、并列时，不急着当作论证箭头。

## 概念关系审查

| 关系 | 审查问题 | 常见断点 |
|---|---|---|
| 同一 | A 和 B 真的是同一个概念吗？ | 把相近词当同义词 |
| 包含 | A 是否只是 B 的一部分，或 B 的一种表现？ | 以部分推出整体 |
| 交叉 | A 和 B 是否只是有交集？ | 用交集替代全部 |
| 并列相容 | A 和 B 是否可以同时成立？ | 把可并存误写成对立 |
| 无关 | A 与 B 是否缺少真实支撑关系？ | 只因放在同段就强行推出 |
| 手段目的 | A 是否只是实现 B 的一种手段？ | 把一种手段写成唯一必要手段 |
| 因果 | A 是否足以导致 B？ | 把相关、可能或条件之一写成必然因果 |
| 定义回代 | 把作者定义代回原命题后是否仍成立？ | 定义造成重复、矛盾或范围偷换 |
| 二分关系 | A/B 是否互斥且穷尽？ | 否定 A 就推出 B |
| 条件关系 | A 是必要、充分、辅助还是唯一条件？ | 把一项标准当唯一标准，把部分条件当充分条件 |
| 概念簇边界 | 多个近义概念是否真的同义？ | 利用近义滑动完成论证 |

## 外推与对比审查

| 类型 | 审查问题 | 常见断点 |
|---|---|---|
| 时间外推 | 过去能否推出未来？ | 用既有增长推出长期趋势 |
| 空间外推 | 局部地区能否代表整体？ | 用大城市推出全国或乡镇 |
| 对象外推 | 某类样本能否代表目标总体？ | 用店内顾客、高端消费者、专业岗位推出全部人群 |
| 指标外推 | 指标 A 是否测量概念 B？ | 用曝光数量推出真实发生率或道德水平 |
| 场景外推 | 某个场景偏好能否代表全部场景？ | 用便利场景推出全部饮食选择 |
| 强度外推 | 弱证据能否推出强结论？ | “可能有助于”推出“一定成功/杜绝” |
| 控制变量 | A/B 对比是否只改变目标因素？ | 两组同时改变多个变量却单一归因 |
| 偶然成功 | 一次成功是否代表策略有效？ | 用小概率逃生否定理性决策 |
| 工具机制 | 发现工具/材料是否等于它是主因或唯一机制？ | 把辅助工具、局部工具或遗留物当成主生产方式 |
| 预测机制 | 价值、价格或行为预测是否有行动者和传导机制？ | 用解释变化直接推出市场价格变化 |

## 常见结构词

| 词语 | 常见作用 |
|---|---|
| 据报道 / 据统计 | 引出论据 |
| 因此 / 所以 / 这说明 | 引出结论或推论 |
| 总之 / 由此可见 | 引出总结 |
| 因为 | 可能是补充论据，也可能是溯因 |
| 其实 | 常引出论点或分论点 |

## 读题提醒

看到事实、数字或报道时，不先追故事细节，而先判断它在结构上是论据、结论、解释还是让步。
