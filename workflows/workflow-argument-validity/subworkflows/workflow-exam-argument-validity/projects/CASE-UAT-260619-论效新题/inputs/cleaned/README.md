# Cleaned Inputs

## 说明

`../_ori/` 中是 OCR 文字识别稿，来源是一批早年 MBA 联考论证有效性分析真题资料，覆盖约 2003-2013 年。

本目录用于保存从 OCR 中清洗出的结构化题目材料。清洗目标不是重写内容，而是：

- 去掉页眉页脚、水印、页码和明显 OCR 噪声；
- 保留题干、论证结构、题目解析、范文参考、习作点评等栏目；
- 将可用于 UAT 的单题材料整理成稳定输入。

最终精校版已整理到 `../final/`。本目录保留为 OCR 到最终版之间的中间稿和溯源入口。

## 使用边界

当前清洗出的题目来自早年真题资料。它们可用于 UAT 演练和扩展回归，但由于早年题和课程材料可能存在主题/解法重叠，验收时应明确标记材料来源，并避免把一次通过直接夸大为完全迁移验证。
