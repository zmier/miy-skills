## 断点摘要

最值得写的断点集中在四处：

1. “形势变化 -> 勤俭节约过时”：时代变化不必然推出某一传统观念应被否定。
2. “勤俭节约 -> 忽视开源”：勤俭节约与开源并不必然冲突。
3. “勤俭持家 -> 放弃必要教育投资”：勤俭不等于该花的钱也不花。
4. “刺激内需 -> 必须反对勤俭节约”：合理消费、扩大内需与勤俭节约未必对立。
