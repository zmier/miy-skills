## 选点

本次作文建议选 4 个断点：

1. A1：从“时代变化”推出“勤俭节约过时”，缺少必要前提。
2. A2：把勤俭节约等同于只节流、不重视开源，概念理解偏窄。
3. A4：把勤俭持家等同于削减教育等必要投入，偷换了勤俭的含义。
4. A7/A8：从刺激内需推出必须反对勤俭节约，并进一步推出敢花能解决流通、积压和就业问题，因果链过长。

## 行文规划

标题：勤俭节约真的过时了吗？

开头：概括材料试图从个人、家庭、国家三个层面证明勤俭节约过时，但论证链存在多处跳跃。

本论段：

1. 时代变化不能直接推出勤俭节约过时。
2. 个人层面，勤俭节约与开源并不矛盾。
3. 家庭层面，勤俭持家不等于削减必要教育投资。
4. 国家层面，扩大内需和合理消费并不必然要求否定勤俭节约。

结尾：材料至多说明过度节俭或不合理节省有问题，不能证明勤俭节约整体过时。
