# TASK06 Skill Feedback

## 候选规则：对比实验控制变量审查

### 触发条件

材料出现“实验、对比、两组、前后、A 情况比 B 情况更快/更多/更好”等结构，并据此归因。

### 审查动作

1. 找作者要证明的目标因素 X；
2. 检查两组除了 X 之外，是否还有口味、顺序、对象、环境、时间等变化；
3. 若存在其他变化因素，则只能说 X 可能有关，不能说 X 直接导致结果。
