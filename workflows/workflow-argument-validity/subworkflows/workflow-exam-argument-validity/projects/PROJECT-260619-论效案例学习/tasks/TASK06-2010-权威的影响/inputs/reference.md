# 2010 年 10 月 MBA 联考真题：权威的影响 Reference

## 二、论证结构
材料通过猴群实验来类比市场营销和企业组织的变革，得出一个推论：权威对于新鲜事物的态度直接影响群体接受新鲜事物的进程。
根据这个推论，材料提出三个观点：
1.如果希望推动人们接受某种新商品，应当首先影响引领时尚的文体明星。
2.如果希望变革能够迅速成功，应当自上而下展开。
3.组织变革不能使组织成员吃苦头，否则难以推行。
考生只要抓住不当类比的问题，指出三个观点都不够全面即可。

## 三、题目解析

材料存在以下主要问题：
1.该论证的出发点是一个科学实验。而科学实验的结果只是猴子本能的一种反应，以此来类推出市场营销甚至企业组织变革是缺乏有效性的。例如，营销中，产品定位

各有不同，定位于婴幼儿市场的产品，想方设法去影响引领时尚的文体明星，这就没有什么价值。
2.决定猴群接受新口味的糖的因素有两个：一是猴子的地位高低，二是糖的口味差异。猴王品尝后认可的糖被猴群快速接受，还有一个可能的原因是口味更好。仅仅归因到权威，存在归因偏差。
3.位于时尚高端的消费者不接受某种新商品，并不意味着“该商品一定会遭遇失败”。不同的新商品有不同的针对人群，“时尚高端的消费者”只是其中一部分。

4.从猴群实验推广到企业变革，逻辑上有问题。要猴群接受一种新口味的糖，并不会带来不确定性，利益、权力冲突等变革中会遇到的问题。企业组织的变革比实验要复杂得多，不可简单类比。认为“自上而下展开，这样做遭遇的阻力较小，容易得到组织成员的支持”是不够严谨的。自上而下的变革并不一定能够减少阻力，得到群众支持。
5.“给猴王品尝苦涩的黄连，即使猴王希望其他猴子接受，猴群也不会干”，是主观臆断，与前面的实验，即论据没有任何联系。
6.猴子的辨别能力仅限于好吃和不好吃。而企业的变革涉及的范围要广得多，企业成员的认知能力也不是猴子所能及的。如果是对企业未来有帮助的组织变革，即使暂时让某些成员吃苦，也未必影响变革的进程。
7.在组织变革的过程中，某些组织成员的利益受到影响有时是不可避免的，只要他们不是大多数成员或者关键成员，变革不见得“只能以失败而告终”。
8.材料结尾提出“如果组织变革使某些组织成员吃尽苦头，组织领导者再努力也只能以失败而告终”，这与“权威对于新鲜事物的态度直接影响群体接受新鲜事物的进程”矛盾。
考生在分析中指出论证中存在的逻辑错误或漏洞，只要言之有理，都能得分。

## 四、范文参考
权威的影响真的大吗？
材料试图通过猴群实验，来论证人类社会中权威的影响较大这一观点，然而论证过程存在诸多逻辑错误，现分析如下：
首先，实验过程并不严谨。两次实验用了两种不同的糖，糖的种类是否会对实验结果产生影响不能确定。可能是糖本身的差别导致了被接受时间的差异，而不是由于是否首先被首领接受。因此，材料中由实验得出的观点“权威对于新鲜事物的态度直接影响群体接受新鲜事物的进程”仍需进一步论证。

猴群实验真的有效吗？
材料通过科学家对猴群开展的实验，来联系市场营销，进而分析企业组织变革，从而说明权威的态度对于群体接受新鲜事物的进程有着直接影响。但是，文中的分析仍存在一些值得商榷的地方，这个推论还需要进一步的论证。
首先，科学家对猴群的实验设计并不严谨。该实验将两种糖分别给地位最低的猴子和地位最高的猴王品尝，很有可能前者获得的糖不符合猴群的口味，而后者获得的糖符合猴群的口味，这有可能导致实验结果差别很大。仅凭这样的证据并不能说明“权威对于新鲜事物的态度直接影响群体接受新鲜事物的进程”。
其次，文中将对猴群的实验，来联系和分析市场营销和企业组织的变革，这种联系和分析也是不妥当的。猴子毕竟是一种智力远不及人类的动物，其行为缺乏理性，而市场营销和企业组织变革都属人类社会和经济活动范畴，人在社会活动中具有思考能力。因此，动物实验与人类社会活动不具备可比性。
再次，文中认为“如果位于时尚高端的消费者对于某种新商品不接受，该商品一定会遭遇失败”，这个观点太过武断。各类商品有不同的目标消费群，如果某种商品本身就定位于低端消费者，那么就算时尚高端的消费者对该商品不接受，而低端消费者却热衷于此，则该商品未必一定会遭遇失败。
最后，材料在分析企业组织的变革时，认为组织领导者若让某些组织成员吃尽苦头，其结果只能以失败告终，这一推论也值得商榷。倘若尝到甜头的组织成员的力量要比吃尽苦头的成员的力量更大，那么变革也有可能取得成功。此外，在组织变革的过程中，某些组织成员的利益受到影响有时是不可避免的，只要他们不是大多数成员或者关键成员，变革不见得“只能以失败而告终”。
综上，材料虽然写得头头是道，但是并没有对结论“销售商品应当首先影响引领时尚的文体明星”和“变革成功应当自上而下展开”进行充分论证。所以，其论据并不能很好地支持论证。

## 七、佳句集萃
1.通过不同口味的糖给不同地位的猴子吃来对比，推出权威对群体产生直接影响。推理过程中存在不恰当对比的漏洞。对比推理要有效，需保持除考察因素外无其他变化因素。文中有“口味”和“猴子地位”两个变化因素。因此，该对比推理有效性是值得商榷的。
2.“猴王”不等同于“权威”；“权威”不等同于“文体明星”。“文体明星”和“猴王”都只是各自群体中“权威”的一部分。
3.作者通过猴群两次接受食物速度的不同得到猴群中存在权威，在得出结论时，忽略了第一次实验对猴群的影响，猴群有可能因为第一次对糖感到陌生，在糖得到认可后，第二次很快就接受了这种食物，而并非是猴王的因素。所以，这个推论难以必然成立。
4.该材料将猴群与人进行类比，以猴群的行为来推断人类的行为，这犯了机械类比的错误。人类是有自己思想的生物，影响猴群的因素并不一定对人类的行为产生影响。因此，以猴群类比人类是不当类比。
5.就算猴群等同于人类，那也无法得出如果高端消费者对某种商品不接受，那该商品必定失败的结论。消费者的消费偏好是不同的，以小部分的高端消费者作为举例对象是片面的，不具有代表性，如果一款商品深受普通消费者的喜爱，但是高端消费

者对其反应平淡，能说那是失败的吗？
6.将市场营销和企业组织变革与猴群实验进行比较，这是不恰当的。因为企业组织的变革存在不确定性和利益、权力冲突等复杂问题，并不是能用生物实验简单类比的。因此，这里犯了不当类比的错误。
7.将猴群实验的结论推广到企业组织的变革也尚需论证。如果组织变革中，员工普遍接受并支持变革观念，那么组织变革则因为具备群众基础更可能成功。而如果组织变革自上而下开展，且变革仅仅符合领导的利益诉求而排斥员工的利益，那么变革的推行也将寸步难行。因此，文章中的推论未必成立。
8.即使市场营销可以等同于猴群实验，也未必能得出“时尚高端的消费者对于某种新商品不接受，该商品一定会遭遇失败”这一结论。因为如果该商品的定位是中低端产品，那么高端消费人群不接受不代表中低端消费者不接受，所以即使高端消费者不接受也不能说明该产品是失败的。
9.某种新商品不被高端消费者接受，很有可能是因为该商品不符合高端消费者的要求，但对于绝大多数普通消费者来说，可能是经济适用的，并且能被大众接受。论证者忽略了这种情况，所以无法得出“如果位于时尚高端的消费者对于某种新商品不接受，则该商品一定会遭遇失败”的结论。
10.通过调查及对比分析得到的结论是或然性的，以此无法得到必然的结论。即使高端消费者不接受，但中低端消费者接受，那该商品就不一定会遭遇失败。虽然组织变革使某些组织成员吃尽苦头，但是通过他们不断努力也不一定失败。
11.材料将猴群实验的结论和企业组织变革进行类比是不恰当的。因为两者之间存在本质的差异，猴群实验反映的仅仅是大自然最本质的动物本能，而企业变革是由人主导的，并且企业变革将会遇到各种各样的外部因素，比如，经济环境、竞争对手等。因此，将猴群实验的结论简单等同于企业变革是不科学的。
