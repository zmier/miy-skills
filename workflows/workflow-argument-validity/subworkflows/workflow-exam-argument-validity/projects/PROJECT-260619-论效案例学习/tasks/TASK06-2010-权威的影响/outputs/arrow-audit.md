## 最可写的 4 个断点

1. 单个猴群实验不足以推出普遍权威规律。
2. 猴王权威不能直接类比为文体明星或高端消费者。
3. 高端消费者不接受不能推出商品一定失败。
4. 组织变革中的“吃苦”不等于必然失败。
