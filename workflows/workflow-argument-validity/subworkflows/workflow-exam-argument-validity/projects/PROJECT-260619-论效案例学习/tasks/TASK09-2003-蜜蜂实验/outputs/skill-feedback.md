# TASK09 Skill Feedback

## 强化规则：偶然成功与策略有效

### 来源证据

苍蝇乱窜逃出瓶口，至多说明在该设置下出现了一个成功结果；不能推出无目的随机行动比理性决策更适合企业。

### 可迁移动作

当材料用“某次成功案例”推出“某策略有效”时，检查：

- 成功是否可能偶然；
- 是否有失败样本未呈现；
- 成本和风险是否被计算；
- 是否有反馈机制使试错可学习；
- 是否把小概率特例当普遍策略。

### 去向

并入 `arrow-break-taxonomy.md` 的 `causal leap / sample weakness / overclaim` 说明。
