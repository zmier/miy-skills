# 企业需要混乱行动吗？

材料由蜜蜂和苍蝇在玻璃瓶中的不同结果，推出企业在不确定环境中应放弃既定方向和规则，转向随机试错甚至混乱行动。该推理类比基础不足，结论也过于绝对。

首先，蜜蜂因趋光习性而无法逃出玻璃瓶，不能直接推出企业遵循规则或坚持方向就会失败。蜜蜂面对的是人为设置的特殊瓶子环境，而企业可以搜集信息、调整战略、改变资源配置。生物习性与企业管理规则之间并不等同。

其次，苍蝇乱窜后逃生，也不能证明随机试错一定更有效。它们逃出瓶口可能包含偶然成分；企业试错若没有目标、反馈和约束，可能带来资源浪费甚至更大风险。随机行动不能简单等同于有效探索。

再次，高科技环境难以预测，并不意味着预测和方向都没有价值。预测可能不精确，但企业仍可设定阶段目标、建立备选方案，并根据反馈调整。方向坚持和灵活试错并非完全对立。

最后，材料把选择说成“混乱行动”与“有序衰亡”之间的取舍，也过于二分。有序行动未必导致衰亡，混乱行动也未必带来生路；企业还可以采取有方向的试错、动态调整和规则创新。

综上，材料从动物实验推出企业经营原则，跨域类比过强，并把复杂战略选择简化为不恰当的二分。
