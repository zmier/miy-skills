## 漏点与差异

- 最大漏点是“忠诚职守，在封建社会是忠于君主，现在则是忠于国家”的定义链：这里不是普通概念偷换，而是定义内部把“职守”与“效忠对象”混在一起。
- 参考解析里的“必要条件被歪曲为充分条件”很有迁移价值，值得成为通用条件关系审查。

## 反哺判断

建议新增“条件关系审查”：

```text
遇到“标准、条件、因素、依据、原因、保证、只要、只有”等词时，检查作者把它当成必要条件、充分条件、辅助条件还是唯一条件；若条件类型被偷换，箭头通常断裂。
```

此规则能统一处理：

- “孝作为一项标准”被批成“孝足以产生功业”；
- “满足顾客需求”被当成战胜对手的充分条件；
- “标准化优势”被当成市场霸主的充分条件。
