## 最可写的 4 个断点

1. “孝”不是封建时代专属，传统性不能推出不适用。
2. 把孝作为一项标准，不等于偏重私德、忽视公德。
3. 未能尽孝行不等于没有孝心。
4. 以孝为标准不等于拘泥小节，更不能推出精英被拒、庸才上位。
