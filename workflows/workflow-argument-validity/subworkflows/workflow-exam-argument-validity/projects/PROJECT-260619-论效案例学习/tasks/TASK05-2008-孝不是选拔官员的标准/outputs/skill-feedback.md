# TASK05 Skill Feedback

## 候选规则：条件关系审查

### 来源证据

参考解析指出，材料把“孝”作为选拔干部的必要或辅助条件，歪曲成“孝足以产生成就功业的充分条件”后再加以批驳。

### 可迁移规则

看到以下词语时，优先判断条件类型：

- 一项标准；
- 重要因素；
- 必要条件；
- 充分条件；
- 唯一条件；
- 原因之一；
- 保证；
- 只要 / 只有。

如果作者把“部分条件”当“充分条件”，把“一项标准”当“唯一标准”，或把“非必要”说成“毫无意义”，就形成断裂箭头。
