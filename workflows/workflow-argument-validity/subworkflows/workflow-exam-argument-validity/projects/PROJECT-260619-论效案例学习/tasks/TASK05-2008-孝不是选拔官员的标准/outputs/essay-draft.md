# “孝”不能作为选官标准吗？

材料反对把“孝”作为选拔官员的一项标准，认为这会停留在封建时代、舍本逐末，并可能排斥精英。该论证在概念处理和推理关系上存在若干问题。

首先，主张把“孝”作为选官标准，并不等于思想停留在封建时代。“孝”可能在封建社会被强调，但这不意味着它只能属于封建社会，也不意味着现代社会不能保留其中合理的伦理要求。材料仅凭其传统色彩就否定其现代适用性，论证不充分。

其次，把“孝”作为一项标准，不等于偏重私德而忽视公德。选拔官员可以同时考察公德、能力、勤勉、绩效和某些私德表现。除非材料能证明“加入孝这一标准”必然挤压公德标准，否则不能从“孝属于私德”推出它不应作为任何参考。

再次，岳飞、孔繁森未能长期在母亲身边尽孝，并不能说明他们没有孝心，更不能说明“孝”不适合评价官员。未能履行某些外在孝行，可能是职责冲突下的结果；而材料把“未能尽孝”和“不孝”混为一谈，再以他们仍是优秀人物来反驳孝的价值，概念发生了偷换。

最后，材料认为重视孝会把胸怀鸿鹄之志的精英拒之门外，而让庸才占据岗位，这也缺少根据。是否有远大抱负，与是否有孝心并不必然对立；孝也未必只是“小节”。若没有证据表明精英通常不孝、庸才通常孝，就不能推出以孝为参考会导致错误选拔。

综上，材料对“孝”的含义、私德与公德的关系以及选拔后果均有跳跃，“孝不应作为选拔官员标准”的结论仍需更充分论证。
