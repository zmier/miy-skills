# TASK05 论证树

## 材料总论点

“孝”不应作为选拔官员的一项标准。

```mermaid

  A1["现在是 21 世纪，思想不能停留在封建时代"] --> B1["把孝作为选官标准不合适"]

  A3["忠孝难以两全：岳飞、孔繁森未能尽孝却是英雄/合格官员"] --> B3["孝不适合评价官员"]
  A4["二十四孝中的孝子未成就名垂青史功业"] --> B3

  B2 --> C
  B3 --> C
```

## 关键概念

| 概念 | 材料用法 | 审查点 |
|---|---|---|
| 孝 | 私德、小节、封建意识 | 是否被偷换为唯一标准、封建观念或不顾大局 |
| 孝心 / 尽孝行为 | 材料混用 | 不能尽孝是否等于没有孝心或不孝 |
| 公德 / 私德 | 对立处理 | 二者是否必然冲突，私德能否作为辅助标准 |
| 忠诚职守 | 公德定义 | 是否等同于忠于君主或国家 |
| 精英 / 庸才 | 选拔结果 | 是否有证据说明重孝会排斥精英、吸纳庸才 |
