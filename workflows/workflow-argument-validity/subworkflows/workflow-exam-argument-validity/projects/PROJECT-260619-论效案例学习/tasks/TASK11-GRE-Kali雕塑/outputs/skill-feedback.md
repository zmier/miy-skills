# TASK11 Skill Feedback

## 反哺 1：问题影响链

### 规则

当题目要求讨论需要回答的问题时，每个问题都必须写成：

```text
question -> target arrow -> answer A impact / answer B impact
```

只问“是否可能存在其他原因？”不够。必须说明如果答案不同，作者的哪条箭头会变强、变弱或断裂。

### 去向

- `workflow-exam-argument-validity/SKILL.md` 的 GRE Argument 分支；
- `exam-writing-rules.md` 的 GRE 段落模板；
- `output-ladder.md` 的 L4/L5 输出纪律。

## 反哺 2：预测类结论机制审查

### 规则

当作者从一个事实发现推出未来价格、价值、市场反应、政策效果或行为变化时，检查：

- 谁会改变行为？
- 他们根据什么评价标准改变？
- 事实发现如何传导到预测结果？
- 是否有相反市场机制或替代价值标准？

### 本题证据

“发现模具”不直接推出“真人大小雕塑贬值 / 微型雕塑升值”。中间还需要收藏者价值标准、稀缺性、审美、历史意义和市场需求等机制。

### 去向

- 父层 `arrow-break-taxonomy.md`，作为 `overclaim / hidden premise missing` 下的预测机制提示；
- 论效子 workflow `exam-reading-rules.md`，作为预测类结论的读题检查。

## 反哺 3：工具存在与主因机制区分

### 规则

发现某个工具或材料存在，不等于它就是主要生产机制。需要检查它是：

- 主要生产工具；
- 辅助工具；
- 练习或教学工具；
- 后期修补工具；
- 与其他技术共同使用的工具。

### 去向

并入 `condition confusion / alternative explanation / hidden premise missing`，不单独新建顶层分类。
