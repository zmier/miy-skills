# Reference 摘要

## 官方高分答案的主要断点

官方高分样文与点评集中在以下问题：

1. 发现头部和手部模具，是否足以推出真人大小雕塑整体都由真实身体模具制成。
2. 模具是否可能只是练习、研究或辅助工具，而不是直接生产工具。
3. 真人大小雕塑和微型雕塑是否属于同一艺术传统、同一时期、同一材料或同一市场，二者价值是否存在可比关系。
4. 微型雕塑抽象和风格不同，是否只能由“不能使用模具”解释。
5. 很少发现雕刻工具，是否意味着没有使用工具，还是工具腐坏、尚未发现、材料不同或工具被转移。
6. 收藏价值是否主要由制作方式决定，还是由稀缺性、审美、材料、历史意义、市场偏好等因素决定。

## 可反哺候选

- 覆盖范围审查：局部发现不能自动推出整体机制。
- 辅助工具与主因机制区分：发现某工具存在，不等于它是主要生产方式。
- 可比对象审查：两个对象是否同源、同市场、同评价标准。
- 价值预测审查：预测类结论需要额外机制，不能只靠技术发现推出市场变化。
- 问题型输出质量阶梯：问题必须连接到对应箭头和可能后果。
