## 题干核心

材料讨论 Kali Island 的古代真人大小陶土雕塑和微型雕塑。大意是：

1. 收藏者珍视 Kali Island 的古代真人大小陶土人像，但长期疑惑其逼真精度如何实现。
2. 考古学家最近在 Kali 发现人头和手部模具。
3. 作者据此认为，古代 Kalinese 艺术家使用真实身体模具，而不是雕刻工具和技巧来制作真人大小雕塑。
4. 作者认为这也解释了为什么微型雕塑抽象且风格不同，因为模具只能用于真人大小雕塑。
5. 作者还认为这解释了为什么很少发现古代 Kalinese 雕刻工具。
6. 收藏者进一步预测：真人大小雕塑会贬值，而微型雕塑会升值。

## 写作指令

官方要求讨论需要回答哪些问题，才能判断该预测及其所依赖的论证是否合理，并说明这些问题的答案如何帮助评估预测。

## 可还原的核心论证链

```text
发现头部和手部模具
-> 真人大小雕塑由真实身体模具制成
-> 并非主要由雕刻工具和技巧制成
-> 解释微型雕塑风格不同、工具发现少
-> 真人大小雕塑价值下降，微型雕塑价值上升
```
