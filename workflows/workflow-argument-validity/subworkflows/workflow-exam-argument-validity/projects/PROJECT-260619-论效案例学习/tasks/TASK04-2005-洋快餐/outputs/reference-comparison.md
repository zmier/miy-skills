## 反哺判断

建议新增或强化“外推维度审查”：

```text
当材料用一个事实推出趋势、总体或强结论时，检查是否发生时间、空间、对象、指标、场景或偏好的外推。
```

此规则不是 2005 个案专属，也能覆盖学术审稿中的样本外推、指标外推和结论强度问题。
