# TASK04 Skill Feedback

## 候选规则：外推维度审查

### 来源证据

本题中至少出现三种外推：

- 过去五年 -> 未来十年；
- 大城市 -> 中小城市、乡镇、全国；
- 网点数增长 -> 市场占有率、行业霸主地位。

### 可迁移规则

材料若用局部事实推出总体趋势，先逐项检查：

| 维度 | 审查问题 |
|---|---|
| 时间 | 过去能否推出未来？ |
| 空间 | 局部地区能否推出整体地区？ |
| 对象 | 某类人群能否代表目标总体？ |
| 指标 | 指标 A 能否代表概念 B？ |
| 场景 | 某场景偏好能否外推到全部消费场景？ |
| 强度 | 弱趋势能否推出强结论？ |
