# 企业经营只需战胜对手吗？

材料由猎人遇虎的故事推出企业经营首先应战胜竞争对手，并认为追求更高竞争目标会浪费资源。该论证存在若干跳跃，结论未必能够成立。

首先，材料用“跑赢同伴即可脱险”的故事来类比企业经营，类比基础并不充分。猎人在老虎面前面对的是短时生死逃避，而企业经营是长期市场竞争；故事中的老虎也可能代表更强大的外部威胁或行业标准。若企业只盯着身边对手，而忽视更强竞争者或市场变化，反而可能陷入危险。因此，该故事不足以推出企业只需战胜直接竞争者。

其次，材料说“顾客不是选择你，就是选择你的竞争者”，这个二分并不完整。顾客可能暂不消费，也可能选择替代品，还可能对你和现有竞争者都不满意。既然选择集合并不只有两项，那么只比竞争者稍好一点，并不必然使企业脱颖而出。

再次，满足顾客需求也不能被简化为“比竞争者快一点”。顾客需求可能包含质量、价格、服务、品牌、创新和稳定性等多种因素。速度只是其中一个维度，甚至在某些行业并非最重要的维度。因此，仅凭“快一点”不能推出企业一定能够战胜对手。

最后，材料认为跑赢老虎式的较高目标是幼稚战略，并会浪费大量资源，这一判断也需要额外前提。较高目标如果脱离资源条件，确实可能造成浪费；但如果目标合理，它也可能促使企业积累能力、抵御更强竞争。材料没有证明目标必然过高，也没有证明投入必然无效。

综上，材料从寓言、二分选择和速度优势推出企业经营原则，论证链条存在多处断裂，“企业经营首先要考虑战胜竞争对手”的结论仍需更充分支持。
