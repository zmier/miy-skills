# TASK03 论证树

## 材料总论点

企业经营首先要考虑的是如何战胜竞争对手；“跑得比老虎快”是企业战略幼稚的表现，追求过高竞争目标会浪费资源。

## Mermaid 论证树

```mermaid
flowchart BT
  A1["猎人故事：只要跑赢同伴，不必跑赢老虎"] --> B1["企业也只要战胜直接竞争者"]
  A2["顾客不是选择你，就是选择竞争者"] --> B2["比竞争者快一点即可脱颖而出"]
  A3["追求过高目标会浪费大量资源"] --> B3["跑赢老虎式目标是幼稚战略"]
  B1 --> C["企业经营首先考虑战胜竞争对手"]
  B2 --> C
  B3 --> C
```

## 关键概念

| 概念 | 材料用法 | 审查点 |
|---|---|---|
| 老虎 | 故事中的外部威胁 | 是否可类比为企业外部环境、强大跨界竞争者或市场标准 |
| 同伴/竞争者 | 直接竞争对象 | 是否等同于企业经营中唯一要战胜的对象 |
| 顾客选择 | 二选一选择 | 是否真的只有“你/竞争者”两个选项 |
| 快一点 | 满足顾客需求的速度差 | 是否足以代表质量、价格、品牌、创新等综合竞争力 |
| 过高目标 | 跑赢老虎式目标 | 是否必然浪费资源，是否可能是必要的长期目标 |
