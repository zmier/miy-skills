## 最可写的 4 个断点

1. 寓言类比到企业战略，类比基础不足。
2. 顾客选择不是“你/竞争者”的封闭二分。
3. “快一点”不能代表满足顾客需求的全部条件。
4. 高目标不必然幼稚或浪费，可能是必要战略储备。
