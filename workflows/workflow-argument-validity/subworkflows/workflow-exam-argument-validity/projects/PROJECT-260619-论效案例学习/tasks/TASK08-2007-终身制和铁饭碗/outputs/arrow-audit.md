## 最可写的 4 个断点

1. 长期雇佣能缓解期界问题，但不能证明终身制总体为好。
2. 德日专业岗位经验不能直接外推到中国企业全部劳动关系。
3. 控制机会主义不只有忠诚感，更不只有铁饭碗。
4. 终身教授不能直接类比为企业工人的铁饭碗。
