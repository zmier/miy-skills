# Reference 摘要

## 官方高分答案的主要断点

官方高分样文与点评集中在以下问题：

1. 二十年前的体能标准与当前体能标准未必可比。若标准改变，达标比例下降不一定代表真实健康水平下降。
2. 电脑拥有率不等于电脑使用时间。高拥有率地区可能只是更富裕，并不代表居民花更多时间使用电脑。
3. 高电脑拥有率地区健康水平高，可能由收入、饮食、健身资源、社区环境等第三因素解释。
4. 健身产品和服务支出低，不一定说明经济衰退是主要原因；人们也可能通过不花钱的方式锻炼。
5. 即使经济改善，也不必然推出健康水平会恢复，因为健康行为和消费支出之间仍有缺口。

## 可反哺候选

- 假设影响链：每个假设都要说明它支撑哪条箭头，如果不成立，上层结论如何降级或断裂。
- 指标口径可比性：当前标准和过去标准不一致时，时间比较可能失效。
- 操作化错配：电脑拥有率不等于电脑使用时间。
- 替代解释：收入、生活方式、社区资源等可能解释健康水平差异。
- 问题型输出展开：只问问题不够，要说明问题答案如何改变结论可信度。
