# 2006 年 10 月 MBA 联考真题：企业丑闻 Reference

## 二、论证结构

第一组论证：
论据：美国是世界上经济最发达的国家，曝光的企业丑闻数量却比发展中国家多得多。
推论：经济的发展不一定带来道德的进步。
第二组论证：
论据：企业丑闻迭出而导致社会道德风气的败坏。
推论：完全有理由怀疑企业这种组织的存在对于整个社会的意义。
第三组论证：
论据：
1.高管可能滥用自己的权力。
2.即便丑闻迭出，高管们仍然获得高薪。
3.拿着高薪的高管无须为业绩下滑或亏损支付罚金。
推论：只有建立有效的激励机制，才能杜绝企业丑闻的发生。

## 2006年10月MBA联考真题：企业丑闻

材料存在以下主要问题：
1.美国比发展中国家曝光的企业丑闻更多，并不必然意味着其实际企业丑闻的数量比发展中国家更多，这一结果可能是由于不同的媒体曝光度或自由度造成的，也可能与其他文化背景相关。因此，也就无法由此推断出“经济的发展不一定带来道德的进步”这一结论。
2.媒体上丑闻迭出，并不必然导致社会道德风气败坏。丑闻数量多，推不出出现丑闻的企业数量多；即使如此，也不能否定企业组织的存在对于整个社会的意义，毕竟任何组织的存在对于社会的影响都是复杂多元的。
3.“公司的高管们坐着商务飞机在全球遨游”与“管理层是否在滥用自己的权力”缺乏因果关系。论述中将这两个事件以某种方式联结，暗示其因果关系，是牵强附会。
4.媒体上出现的丑闻公司并不一定是大公司，即使是大公司，也可能只占大公司总体很小的一部分。况且，出现丑闻的原因可能非常复杂多样，因此，将丑闻与支付给大公司高管的报酬联系到一起，在推理上并不成立。
5.企业业绩下滑甚至亏损的原因可能很复杂，外部环境的变化、市场竞争的加剧、消费习惯的转变、公司治理结构的缺失等，都可能导致业绩下滑或亏损，公司高管的错误决策只是其中一个可能的原因。题干中的推断存在归因谬误。
6.即使公司高管的错误决策造成业绩下滑，也不是必须支付罚金，否则公司高管就成了企业风险的实际承担者，这就将职业经理人的角色与股东的角色混为一谈。因此，不能推断出这是一种“无效的激励机制”的结论。
7.从上述分析可以发现，激励机制与企业丑闻之间并不存在必然的联系，因此，“只有建立有效的激励机制，才能杜绝企业丑闻的发生”的结论未必成立。在实践中，再有效的措施恐怕也只能减少企业丑闻的发生，“杜绝企业丑闻的发生”只是一个美好的愿望。
考生在分析中指出论证中存在的逻辑错误或漏洞，只要言之有理，都能得分。

## 四、范文参考

杜绝企业丑闻要靠激励机制吗？
上述材料认为企业发生丑闻无法带来道德进步，进而怀疑其存在对于社会的意义，
从而推论出“只有建立有效的激励机制，才能杜绝企业丑闻的发生”，这是值得推敲的。首先，即使美国曝光的企业丑闻数量多于发展中国家，很可能是因为美国的企业也远远多于发展中国家的企业。材料通过曝光的企业丑闻绝对数量多推理出“经济的发展不一定带来道德的进步”，这里的衡量标准是成问题的。此外，企业丑闻数量与道德进步
之间并不具备必然联系。曝光的企业丑闻多也许可以说明信息的通畅度好，新闻的自由

度高，但并不代表道德没有进步。
其次，媒体上出现的丑闻公司并不一定是大公司，即使是大公司，也可能只占大公司总体很小的一部分。况且，出现丑闻的原因可能非常复杂多样，因此，将丑闻与大公司高管的报酬联系到一起，在推理上并不成立。
再次，因为存在丑闻，从而怀疑企业的存在对于社会的意义是有失偏颇的。企业对于社会的意义要从经济、政治、管理、就业、产品、市场等诸多方面进行考量，如果企业对社会起到的积极作用更大，那么只看到消极的一面就以偏概全了。
最后，文章谈到只有建立有效的激励机制才能杜绝企业丑闻的发生，两者不存在直接的联系。因为材料只是提到无效的激励机制，使企业的高管在企业发生下滑和亏损时，无须承担责任；但是企业业绩下降与发生丑闻没有必然的联系，所以将有效的激励机制作为杜绝企业丑闻发生的方法，不一定正确。
通过上述分析，可以发现文中存在以偏概全、强拉因果等诸多逻辑漏洞，在论证方面有许多缺陷。因此，文中所推出的结论是值得推敲的。

## 七、佳句集萃
1.作者认为美国曝光的企业丑闻数量比发展中国家多，那么经济发展不一定带来道德的进步。这样的推理难以必然成立。因为被曝光的数量未必等于实际发生的数量，况且美国企业数量远多于发展中国家，丑闻数量多但所占比例不一定大。如果发生丑闻的企业只占美国企业总数的极小部分，那么材料据此推出上述结论就以偏概全了。
2.材料认为“美国是世界上……不一定带来道德的进步”，此观点有失偏颇。不能因为“经济发达”和“企业丑闻”这两个现象同时存在，就简单得出前者可能导致后者的结论。也许是美国对企业的监督机制完善、信息透明度高等原因，使得美国曝光的企业丑闻数量多。
3.即使“丑闻迭出而导致社会道德风气的败坏”，也不能“完全有理由怀疑企业这种组织的存在对于整个社会的意义”。出现丑闻的企业毕竟只是所有企业中的一部分，不能由部分企业出现的状况而否定所有的企业；更何况，即使部分企业出现丑闻，也不能否认企业这种组织对于整个社会经济的促进作用。

这是否有失偏颇？企业对于社会的意义有积极面和消极面，如果企业对于社会更多的是积极意义，如促进社会经济的发展、协调市场竞争等，那么只看到企业的消极面就有些片面了。
