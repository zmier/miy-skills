# 激励机制能杜绝企业丑闻吗？

材料从美国企业丑闻较多、高管薪酬和业绩责任不匹配等现象出发，认为只有建立有效激励机制才能杜绝企业丑闻。该论证存在指标错配和结论过强的问题。

首先，美国曝光的企业丑闻比发展中国家多，并不一定说明美国真实发生的企业丑闻更多，也不能直接说明经济发展没有带来道德进步。曝光数量还可能取决于监管力度、媒体自由度、司法透明度和公众监督水平。用“曝光多”衡量“道德差”，指标并不匹配。

其次，企业存在丑闻也不能推出企业组织对于社会的意义可疑。企业可能产生道德风险，但同时也创造财富、就业和产品服务。个别或部分企业丑闻最多说明治理存在问题，不能直接否定企业这种组织形式的社会价值。

再次，高管薪酬较高而公司亏损时不支付罚金，确实可能暴露激励约束问题，但不能由此断定激励机制是企业丑闻的根本原因。公司业绩下滑可能受市场环境、行业周期等因素影响，高管责任也需要具体判断。

最后，即使有效激励机制有助于减少丑闻，也不能说只有它才能杜绝丑闻。企业丑闻还受法律监管、信息披露、内部控制、审计制度和组织文化影响。况且“杜绝”本身是很强的结论，材料没有证明任何制度可以完全消除丑闻。

综上，材料从丑闻曝光和薪酬机制推出“只有有效激励机制才能杜绝丑闻”，论证链条并不充分。
