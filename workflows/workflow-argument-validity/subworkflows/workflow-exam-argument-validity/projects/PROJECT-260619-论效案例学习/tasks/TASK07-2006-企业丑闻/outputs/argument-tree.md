# TASK07 论证树

## 材料总论点

只有建立有效激励机制，才能杜绝企业丑闻发生。

```mermaid
flowchart BT
  A1["美国经济发达但曝光企业丑闻更多"] --> B1["经济发展不一定带来道德进步"]
  A2["企业丑闻导致社会道德败坏"] --> B2["可怀疑企业组织存在的社会意义"]
  A3["股东无法知晓高管是否滥权"] --> B3["应怀疑是否该给高管高报酬"]
  A4["高管高薪但业绩下滑不支付罚金"] --> B4["激励机制无效"]
  B4 --> C["高管朝错误方向滑落"]
  C --> D["只有建立有效激励机制，才能杜绝企业丑闻"]
```

## 关键概念

| 概念 | 材料用法 | 审查点 |
|---|---|---|
| 曝光数量 | 被报道或发现的丑闻数量 | 能否代表真实发生数量 |
| 道德进步 | 社会道德水平 | 能否由企业丑闻数量直接衡量 |
| 企业组织意义 | 企业存在价值 | 能否由丑闻推出整体否定 |
| 高管报酬 | 激励机制一部分 | 是否等同全部激励约束 |
| 有效激励机制 | 杜绝丑闻的条件 | 是否是唯一必要且充分手段 |
