# Academic Workflow Routing

## 输入类型

| 输入 | 路由 |
|---|---|
| 整篇手稿 Markdown | 先抽作者树，再验箭头 |
| 已有 quick reconstruction | 用作一句话核心发现和 X/M/Y 初稿 |
| 已有变量/方法/结果审查 | 回填到 evidence ledger 和 arrow audit |
| 已有审稿意见 | 不放入作者树；映射到 review-issue-arrow-map |
| 写作自审草稿 | 按作者目标结论反向检查缺失节点 |

## 输出选择

| 目标 | 输出 |
|---|---|
| 看懂论文贡献链 | paper-argument-tree + Mermaid |
| 准备审稿 major concern | academic-arrow-audit + arrow-repair-map + academic-argument-issue-selection + review-issue-arrow-map |
| 投稿前自查 | weak-arrow list + arrow-repair-map + revision actions |
| Obsidian 知识管理 | obsidian-link-map |
| 后续文献定位 | X1 gap nodes + citation links |
