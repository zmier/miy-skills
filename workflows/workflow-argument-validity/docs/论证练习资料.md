# 结论先行
管综**论证有效性分析（论效）** 完全对应 GRE 写作里的 **Argument Task（论证分析）**；
GRE 另一道写作 Issue（立论作文），对应管综的**论说文**，和论效无关。

## 一、二者核心本质完全同源
### 相同核心任务（最关键）
两者规则一模一样：
1. **不评判原文结论对错，只拆解「推导过程的逻辑漏洞」**
   禁止思路：“这个观点本身是错的”
   标准思路：“作者给出的论据无法支撑结论，推理存在缺陷”
2. 考察的逻辑谬误库高度重合：
   偷换概念、以偏概全、样本缺陷、强加因果/因果倒置/另有他因、不当类比、充分必要混淆、非黑即白、数字陷阱、诉诸主观等，两类考试高频缺陷几乎通用。
3. 标准行文结构统一：
   - 开头：概括原文论点，点明论证存在多处逻辑缺陷
   - 主体：3～4段，一段一个漏洞 → 引用原文表述+指出谬误类型+分析为何推不出结论
   - 结尾：总结原文论证失效，结论不足采信

## 二、核心差异（备考不能直接照搬模板）
### 1. 素材话题风格
- 管综论效：中文短文，经济、企业管理、市场、社会发展为主（利润、供需、竞争、人口、教育等商科话题）
- GRE Argument：英文材料，多为城市政策、民间调研、科学实验、地方商业提案，大量问卷、实验数据类陷阱

### 2. 评分侧重点
- 管综阅卷：
  踩点给分，**找准4处核心漏洞是第一得分点**；中文说理通顺、结构规整即可，不需要深度挖掘隐含前提。
- GRE Argument：
  极其看重拆解**隐含假设（assumption）**，分析深度分层打分；同时严格评判英文词汇、句式、语法，机器+人工双评。

### 3. 篇幅与时间
- 管综：30分钟，中文600字左右
- GRE Argument：30分钟，英文400–600词

### 4. 表述术语习惯
- 管综国内体系：直接用通俗叫法——偷换概念、类比不当、数字谬误等
- GRE 体系：高频强调 assumption（隐含假设）、alternative explanation（其他合理解释），是分析的核心抓手

## 三、备考互通价值
1. 学 GRE Argument 挖掘隐含假设的思维，能显著提升管综论效的分析深度，避免只简单贴谬误标签；
2. 管综刷题积累的全部逻辑错误类型，可以直接平移用于 GRE Argument；
3. 注意：两套写作模板不能互译套用，中文阅卷话术、得分逻辑和英文写作评分标准完全独立。

## 补充区分（避免混淆）
- GRE Argument = 管综论效（驳已有论证）
- GRE Issue = 管综论说文（自己提出观点、自主立论）
