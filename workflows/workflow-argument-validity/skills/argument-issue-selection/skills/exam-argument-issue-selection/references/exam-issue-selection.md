# Exam Issue Selection

## 中文论效题

从 `exam-arrow-audit-table.md` 中选 3-4 个最可写断点。

优先：

1. 总论点附近的主箭头；
2. 分论点向总论点的跳跃；
3. 数字、样本、比较、因果、概念关系明显不稳的箭头；
4. 能用“定位-分析-收尾”写清的一段；
5. 能说明“如果这条箭头断了，上层结论为什么变弱”的问题。

避免：

- 只改措辞；
- 需要外部专业知识；
- 多段重复攻击同一小点；
- 离总结论太远；
- 只有术语，没有“为什么推不出”。

## GRE Argument

先读 prompt instruction：

| instruction | 选点方式 |
|---|---|
| assumptions | 选最关键 hidden premise |
| questions | 选答案会改变结论可信度的问题 |
| evidence needed | 选能直接 strengthen/weaken target arrow 的证据 |
| alternative explanations | 选能解释同一 observed fact 的 rival mechanism |

## 段落路线

中文论效：

```text
定位：材料由 A 推出 B。
分析：但 A 只能说明 A1；若要推出 B，还需要证明 H。
收尾：因此，A 不足以支持 B，总结论仍需进一步论证。
```

GRE assumptions：

```text
The argument assumes H.
H is necessary for A to support B.
If H is false, B and the conclusion would be weakened.
```

GRE questions：

```text
Question Q needs to be answered.
Q tests whether A really supports B.
If the answer is yes, the argument is strengthened; if no or alternative answer, B and the conclusion are weakened.
```
