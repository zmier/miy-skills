# Management Exam Adapter

用于中文管理类/经济类联考论证有效性分析。

## 重点

- 快速找总论点；
- 拆出论据、分论点、总结论；
- 判断直推、合推、分推；
- 选择 3-4 个可写断点；
- 服务“定位-分析-收尾”的本论段。

## 常见箭头

| 箭头 | 常见问题 |
|---|---|
| 个案 -> 总体 | 样本代表性 |
| 过去 -> 未来 | 忽略变化 |
| 相关 -> 因果 | 因果倒置 / 第三变量 |
| 手段 -> 结果 | 必要性 / 充分性不足 |
| 局部 -> 整体 | 以偏概全 |
| 指标 -> 概念 | 衡量标准错配 |

## 输出倾向

优先输出能写成段落的断点，不追求穷尽。
