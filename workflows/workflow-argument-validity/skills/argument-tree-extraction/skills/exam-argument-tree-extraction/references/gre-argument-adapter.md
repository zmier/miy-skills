# GRE Argument Adapter

用于 GRE Analyze an Argument。

## Prompt Instructions

| Prompt | Focus |
|---|---|
| assumptions | unstated assumptions |
| evidence | what evidence would strengthen/weaken |
| questions | what must be answered |
| alternative explanations | rival mechanisms |

## Output Shape

```text
conclusion:
support chain:
target arrow:
assumption/question/evidence/alternative:
impact:
```

Do not write a generic flaw list. Tie every issue to an arrow.
