# Node / Arrow Model

## Node Types

| Type | 含义 |
|---|---|
| root | 总结论 / 根结论 |
| middle-claim | 中层命题 / 分论点 |
| subclaim | 子观点 |
| evidence | 事实、数据、表格、引文、例子、题干材料 |
| implicit-premise | 隐含前提 |

## Arrow Types

| Type | 含义 |
|---|---|
| support | A 支撑 B |
| requires | B 需要 A 成立 |
| explains | A 解释 B |
| measures | A 衡量 B |
| identifies | A 识别 B |
| generalizes-to | A 上升到 B |

## Status

| Status | 含义 |
|---|---|
| strong | 当前证据足以支撑 |
| weak | 有支撑但不足 |
| broken | 推不出 |
| unclear | 信息不足 |
| not-yet-audited | 抽树阶段暂未审计 |
