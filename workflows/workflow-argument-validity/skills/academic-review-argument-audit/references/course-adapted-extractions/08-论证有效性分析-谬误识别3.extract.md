# 08 论证有效性分析：谬误识别 3 提取

## 一句话提炼

这一讲把经验论证中最常见的问题集中起来：样本、平均数、百分比、手段目的、条件关系、类比比较、自相矛盾和忽略发展。

## 本讲主要谬误与审稿迁移

| 类型 | 课程含义 | 审稿迁移 |
|---|---|---|
| 样本问题 | 样本太小、选择性样本、样本不代表总体 | 数据来源、样本筛选、幸存者偏差、行业/地区代表性 |
| 平均数陷阱 | 平均数掩盖分布差异和两极分化 | 只报均值不报分布、异质性或头部企业驱动 |
| 百分比陷阱 | 比例变化不能直接说明基数或水平变化 | share、rate、index 与 level 的解释要清楚 |
| 手段目的陷阱 | 某手段未必可行、可取、有效或最优 | 作者政策建议或管理建议是否能由结果推出 |
| 条件陷阱 | 充分条件/必要条件混用 | “只要”“只有”“如果”类机制表述是否严谨 |
| 不当比较/类比 | 比较对象背景不同，或类比属性不相关 | 跨国、跨行业、宏观到微观、动物/实验到企业场景的外推 |
| 自相矛盾 | 文中不同位置的判断互相冲突 | 摘要、引言、理论、结果和结论是否互相打架 |
| 忽略发展 | 用过去事实直接推出未来状态，忽视动态变化 | 时间结构、滞后效应、政策变化、产品清单更新 |

## 经验论文特别相关的检查点

### 1. 样本与选择性证据

```text
作者需要说明样本筛选是否会系统性排除某些企业。例如，如果只有持续出口或有进口记录的企业进入样本，那么结果可能更能反映这类企业本身的能力，而不是机器人采用的影响。
```

### 2. 平均数和分布

```text
均值结果可能掩盖企业之间的显著差异。建议作者报告分布、分位数或异质性检验，以说明结果不是由少数头部企业驱动。
```

### 3. 百分比、份额和量纲

```text
如果 EPS 被称为 share，但描述统计均值或最大值超过通常的份额范围，作者需要说明该变量是否经过百分比化、指数化、对数化或其他转换。否则，读者难以判断系数的经济含义。
```

### 4. 忽略发展

课程里“历史不会重复它的事实，但会重复它的规律”可以迁移为：

```text
如果作者使用固定的历史产品分类或基准年份清单，需要说明后续年份新出现的产品如何处理。否则，基于旧清单的分类可能无法覆盖样本期内真实发生的产品变化。
```

这正好对应我们之前讨论的“2001 年之后出现的新产品如何处理”。

## 对 Skill 的要求

`argument-validity-audit` 应加入“经验论证陷阱库”：

| 陷阱 | 触发信号 |
|---|---|
| 样本问题 | selected sample, matched sample, balanced panel, only firms with... |
| 平均数陷阱 | mean, average, representative, typical |
| 百分比陷阱 | share, rate, ratio, percentage, index |
| 类比/比较 | compared with, similar to, following prior macro measure |
| 忽略发展 | base year, historical list, future years, post-period products |
| 条件陷阱 | if, only if, as long as, must, necessary |

## 对当前论文的直接启发

1. EPS 或产品升级指标若来自国贸文献，需要检查其企业层面的适配性；
2. Robot 指标如果是进口量或进口额，需要说明量纲和“采用”的关系；
3. 新产品分类若依赖某一年份或既有清单，需要说明样本期后续新增产品如何处理；
4. 稳健性指标如果使用 IFR 行业层面数据，需要说明它为何能替代企业层面的机器人采用。
