# 06 论证有效性分析：谬误识别 1 提取

## 一句话提炼

谬误识别不是背术语，而是训练对“论据词与结论词不一致”“论据只能支持弱结论却被推出强结论”的敏感度。

## 本讲主要谬误

| 类型 | 课程含义 | 审稿迁移 |
|---|---|---|
| 概念问题/违反同一律 | 核心概念界定不清，或前后使用不一致 | 检查作者标题、摘要、变量、结果和贡献中的概念是否漂移 |
| 偷换概念 | 论据中的 A 被结论中的 B 替换 | robot imports -> robot adoption；product list exports -> product upgrading |
| 转移话题 | 从一个问题滑到另一个问题 | 从企业出口行为滑到宏观产业升级 |
| 过度推理 | 论据只能支持较弱结论，却推出强结论 | 相关性被写成因果；局部样本被写成一般规律 |
| 比例/率与绝对量混用 | 增长率、利润率、比例不能直接推出绝对水平 | 回归系数、份额、指数、对数变量的量纲必须讲清楚 |

## 可迁移检查表

| 检查对象 | 要问的问题 |
|---|---|
| X 概念 | 作者声称的 X 和操作化指标 X' 是否同一件事 |
| Y 概念 | 作者声称的 Y 和测量指标 Y' 是否同一层级、同一口径 |
| 比例/份额/指数 | 该指标是否能支持作者对“水平”“能力”“升级”的表述 |
| 证据强度 | 证据支持的是“可能”“相关”“局部”，还是作者写成“必然”“导致”“整体” |

## 审稿段落模板

```text
作者在论证中使用了两个并不完全相同的概念。实证部分直接衡量的是 A，但引言和结论讨论的是 B。A 可能与 B 有关，但二者不能直接等同；若要从 A 推出 B，作者需要说明二者之间的中间条件和排除的替代解释。否则，当前证据只能支持关于 A 的较弱结论。
```

## 对当前论文审稿的直接启发

这讲正好对应我们已经发现的两个核心问题：

1. X 端：机器人相关产品进口不必然等于机器人采用；
2. Y 端：某一产品清单中的出口增加不必然等于企业层面的产品结构升级。

这些问题不应只归为“变量问题”，而应提升为“核心论证中的概念不一致”。
