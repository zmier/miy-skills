# 09 论证有效性分析：谬误识别 4 提取

## 一句话提炼

最后两类谬误强调“全面看问题”和“用正确标准评价”：不要只看一面，也不要拿不相关标准证明结论。

## 本讲主要谬误

| 类型 | 课程含义 | 审稿迁移 |
|---|---|---|
| 顾此失彼 | 只看到好处或坏处，忽略另一面 | 论文只讲预期机制，不讲反向机制、成本、副作用或边界条件 |
| 更换衡量标准 | 用错误标准判断对象 | 用宏观贸易指标衡量企业升级；用进口行为衡量实际采用；用显著性衡量理论重要性 |

## 顾此失彼的审稿迁移

审稿中常见表现：

1. 只讲机器人采用带来效率提升，不讲组织调整成本或技能替代成本；
2. 只讲产品升级，不讲企业可能只是调整出口组合或跟随需求变化；
3. 只讲显著结果，不讲不显著结果、相反结果或经济意义；
4. 只讲机制成立，不讲其他机制也能解释同一结果。

### 模板

```text
作者目前主要强调 A 对 Y 的正向机制，但较少讨论可能的反向机制或边界条件。例如，A 也可能通过 D 影响企业行为，从而削弱或改变作者提出的机制。若不处理这些可能性，当前叙事容易显得单向度，难以充分支撑较强的理论结论。
```

## 更换衡量标准的审稿迁移

审稿中最关键的问题是：**作者想评价的对象是什么，实际使用的标准是否适合评价它。**

| 作者想评价 | 实际标准 | 潜在问题 |
|---|---|---|
| 企业机器人采用 | 机器人相关产品进口 | 进口不等于使用、安装、生产流程改变 |
| 企业产品升级 | 国贸产品分类或宏观产品复杂度 | 宏观产品指标未必适配企业层面 |
| 理论机制 | 机制回归显著 | 显著不等于机制链成立 |
| 贡献重要性 | 文献中较少研究 | 少不等于重要，也不等于 gap 成立 |
| 政策启示 | 回归结果方向 | 政策建议还需要成本、可行性和外部有效性 |

### 模板

```text
稿件需要更清楚地区分评价对象和衡量标准。作者讨论的是 A，但实际使用的标准更接近 B。B 可以作为相关证据，但不足以直接评价 A。若要维持当前结论，作者需要说明为什么 B 是评价 A 的合适标准；否则，建议将结论限定在 B 所能直接支持的范围内。
```

## 对 Skill 的要求

`argument-validity-audit` 应加入“标准匹配检查”：

| 被评价对象 | 作者使用的衡量标准 | 标准是否匹配 | 不匹配风险 | 建议 |
|---|---|---|---|---|

这能直接捕捉我们之前反复讨论的 Y 端宏观-微观 mismatch。
