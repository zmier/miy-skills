# 07 论证有效性分析：谬误识别 2 提取

## 一句话提炼

这一讲重点训练“不要被二选一、绝对化、隐含假设和因果故事牵着走”；审稿时尤其要找作者没有明说、但结论依赖它成立的前提。

## 本讲主要谬误

| 类型 | 课程含义 | 审稿迁移 |
|---|---|---|
| 极化思考 | 非黑即白、不是 A 就是 B、要么 A 要么 B | 作者把机制或解释写成唯一解释，忽略中间状态 |
| 过于绝对 | 使用“完全、必然、只要、一定、唯一”等强词 | 论文结论强度超过证据强度 |
| 不当假设 | 论证依赖未说明且未证明的隐含前提 | IV 排除限制、平行趋势、变量代理有效性都属于隐含假设 |
| 因果问题 | 从现象推出原因，或把相关解释为因果 | 需要 DAG/后门/前门或识别设计来支持 |
| 求异实验/他因 | 两组差异不止一个因素，不能锁定唯一原因 | 经验模型未排除遗漏变量、选择效应、共同趋势 |

## 审稿中的隐含假设识别

| 作者推理 | 隐含假设 | 审稿问题 |
|---|---|---|
| A 指标代表 X | A 与 X 高度一致 | 代理变量是否有效 |
| IV 影响 X 进而影响 Y | IV 不直接影响 Y | 排除限制是否可信 |
| 处理组变化来自政策/技术 | 没有其他同时变化因素 | 后门路径是否关闭 |
| 机制变量显著 | 机制链成立 | 是否只是相关机制或共同结果 |
| 稳健性替代指标一致 | 替代指标衡量同一构念 | 指标之间是否真的等价 |

## 审稿段落模板：隐含假设

```text
这一论证依赖一个尚未充分说明的隐含前提：A 必须主要通过 X 影响 Y，而不能通过 D 等其他路径影响 Y。当前稿件尚未对这一前提提供足够证据。因此，即使 A 与 Y 之间存在显著关系，也不能直接推出作者声称的 X -> Y 因果机制。
```

## 审稿段落模板：过于绝对

```text
作者的表述比现有证据更强。当前结果可以说明 A 与 B 之间存在相关关系，或至少说明在本文样本和模型设定下二者相关；但它尚不足以说明 A 必然导致 C。建议作者降低结论强度，并明确该发现成立的条件。
```

## 对 Skill 的要求

`argument-validity-audit` 应新增一列：

| 论证箭头 | 作者显性论据 | 作者显性结论 | 隐含假设 | 该假设是否被证明 | 替代解释 |
|---|---|---|---|---|---|

这能防止我们只看作者写出来的东西，而漏掉真正支撑结论的隐藏前提。
