# Case-Derived Review Patterns

来源案例：`projects/CASE-J-260110-xinyuan-review`

状态：`case-derived / partial / forward-test-pending`

## 使用边界

本文件保存真实审稿案例中可迁移的审稿论证模式。它不是具体稿件判断清单，也不是通用父 Skill 规则。使用时必须回到当前稿件证据。

## Pattern 1：核心故事线前提一致性

### 触发

作者在不同章节、表格或机制解释中反复使用同一个理论机制，但解释时切换了关键前提。

### 检查

```text
作者在 A 处依赖前提 P1
作者在 B 处又依赖 P2
P1 和 P2 是否一致？
如果不一致，是否解释了适用条件？
```

### 审稿写法

```text
稿件需要更清楚地区分【前提一】和【前提二】。目前作者在解释主效应时依赖【前提一】，但在解释异质性或机制结果时又转向【前提二】。这使得核心机制的适用条件不够稳定。建议作者分别界定两种效应，并说明各自何时发挥作用。
```

## Pattern 2：机制相关样本剔除

### 触发

作者为获得“干净识别”剔除了某类事件、行业或样本，但这些被剔除样本可能正是最能检验机制的对象。

### 检查

```text
被剔除样本是否更可能包含强处理、强关注、强机制或强外部效应？
剔除后保留样本是否偏向机制较弱、关注较低或偶发事件？
```

### 审稿写法

```text
当前样本筛选规则虽然有助于减少事件重叠，但也可能剔除了最能体现作者机制的事件。如果这些被剔除事件具有更高市场关注度或更强外部冲击，那么保留样本可能无法代表作者想讨论的总体。建议作者报告被剔除样本的行业和事件分布，并考虑将集中发生的事件作为一组冲击处理。
```

## Pattern 3：溢出效应的直接效应前提

### 触发

论文主张一个行为、政策或事件会影响同行、同群或邻近对象，但没有检查事件主体自身是否发生了相应变化或收益。

### 检查

```text
如果作者说 B 会模仿 A，
A 自身是否真的改善、获益或受到市场奖励？
如果 A 自身没有变化，B 为什么要模仿？
```

### 审稿写法

```text
若要论证该效应通过同行模仿或声誉竞争扩散，稿件需要先说明事件主体自身是否确实出现了相应改善或收益。否则，同行企业为何会模仿这一行为仍缺少直接前提。建议作者补充事件主体在事件前后的变化，作为溢出效应检验的逻辑基准。
```

## Pattern 4：机制排除中的反向解释

### 触发

作者用某个结果“不显著”来排除某机制。

### 检查

```text
该结果不显著是否真的说明机制不存在？
还是也可能说明机制已经生效，使被观察结果不再出现？
```

### 审稿写法

```text
当前稿件用【结果不显著】来排除【机制】仍不够充分。该不显著结果也可能是机制已经发挥作用后的结果，而不一定说明机制不存在。作者需要进一步区分“机制未发生”和“机制发生后改变了被观察结果”这两种解释。
```

## Pattern 5：稳健性是否回应核心质疑

### 触发

作者提供常规稳健性检验，如替换变量、PSM、安慰剂、Oster 等，但核心质疑来自样本筛选、定义、机制前提、聚类层级或识别边界。

### 检查

```text
稳健性检验是否直接回应当前最重要的断点？
还是只是在同一问题框架下重复验证？
```

### 审稿写法

```text
现有稳健性检验主要重复验证了基准设定下的相关关系，但尚未回应本文最核心的识别/测量/样本质疑。建议作者围绕这些核心断点设计稳健性检验，而不仅是替换变量或重复匹配。
```

## Pattern 6：强结构与低压措辞分离

### 触发

审稿意见结构有力，但措辞可能显得情绪化、人格化或压迫过强。

### 规则

保留：

- 定位；
- 分析；
- 结论影响；
- 修改建议。

降调：

- “低级错误” -> “表注与括号数值含义不一致，需核实”；
- “基本常识” -> “这一设定可能影响标准误和显著性判断”；
- “严重损害” -> “削弱了理论框架的一致性”。

## 与 course-derived patterns 的关系

这些模式本质上是课程中的：

```text
抓箭头
-> 比较关键词和隐含前提
-> 组合分析
-> 收尾回到结论
```

在学术审稿语境下的专业化表现。
