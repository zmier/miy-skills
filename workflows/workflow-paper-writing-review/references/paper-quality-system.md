# Paper Quality System

## 核心模型

论文质量可以先抽象为一条贡献链：

```text
研究问题
-> 文献缺口
-> 理论机制
-> 识别策略 / 研究设计
-> 数据、变量和样本
-> 结果、稳健性和边界
-> 贡献叙事
-> 表达、引用和结构
```

写论文时，这条链用于正向构造。审稿或自审时，这条链用于逆向验收。

## 质量维度

| 维度 | 写作时的问题 | 审稿时的问题 |
|---|---|---|
| 研究问题 | 问题是否重要、清楚、可研究 | 作者的问题是否真的重要，是否被夸大 |
| 文献缺口 | 是否定位到真实 gap | gap 是否成立，是否遗漏关键文献 |
| 理论机制 | 机制是否自洽、可检验 | 机制是否跳步、概念是否混用 |
| 识别 / 设计 | 方法是否能支持主张 | 因果语言是否越过识别条件 |
| 数据 / 变量 | 样本、变量、口径是否匹配问题 | 数据和变量是否足以支撑结论 |
| 结果叙事 | 结果是否服务主线 | 叙事是否过度解释或选择性呈现 |
| 贡献定位 | 贡献是否具体且不夸大 | 贡献是否重复、过宽或过弱 |
| 引用质量 | 引用是否准确、充分、必要 | 是否缺引、错引、堆引或引用不支撑论断 |
| 表达结构 | 是否清楚、规范、符合期刊 | 是否有 AI 味、报告体、术语混乱或结构断裂 |

## 状态机制

每个质量项可以使用以下状态：

- `unexamined`：尚未检查；
- `questioned`：存在疑问，需要证据；
- `supported`：已有证据支持；
- `weak-supported`：部分支持，但边界较窄；
- `unsupported`：主张缺乏证据；
- `overclaimed`：表述越过证据；
- `revision-needed`：需要修改；
- `acceptable`：当前目标下可接受。

## 元规则

本 reference 只定义共享质量系统。具体学科、期刊、方法、数据和写作风格的细节，应由领域 Skills 或具体项目处理。
