# 审稿是一场知识旅行

我最近越来越觉得，审稿这件事，不应该被理解成“找错误”。

当然，错误要找。变量有没有定义清楚，识别干不干净，文献有没有吹过头，机制是不是只是事后叙事，表格有没有对不上，这些都要看，而且要很认真地看。

但如果审稿只剩下这些，它就会变成一种很冷的工作：像拿着红笔坐在门口查票，谁证件不齐就拦下来。

我现在更喜欢另一个理解：

> 审稿是借一篇稿件进入一个研究领域，让我们对这个世界多一点了解。

一篇稿子像一个有点话唠的旅伴。它兴冲冲地跑来跟你说：你看，我发现了一个问题；你看，这里有一组数据；你看，这些文献好像还没说清楚；你看，我用这个方法跑出来了一个结果。

它可能真的有点话唠。它可能会把一个小山坡说成新大陆，把相关性说成因果，把旁边村子早就修过的路说成没人来过的秘境。它的地图可能比例尺不对，路标可能也有点歪。

但这不妨碍我们感谢它。

因为它确实把我们带到了一处风景面前。哪怕作者的因果识别不干净，哪怕贡献叙事有点喜欢吹牛，哪怕文献定位还不够稳，它仍然给了我们一个进入新领域的入口。它把问题、文献、变量、数据、方法和争议点打包带到我们面前，让我们有机会重新理解一小块世界。

所以，审稿最好的姿态也许不是“我来审判你”，而是：

> 感谢作者带来的风景，但认真校准地图。

这句话对我很重要。

“感谢风景”，意味着我们先承认作者的劳动和好意。一个研究问题能被提出，一组数据能被整理，一套机制能被写出来，本身就已经把某个角落照亮了一点。我们不必急着拆台。先看它想带我们去哪儿，先问这个领域原本在讨论什么，先把知识树画出来。

“校准地图”，意味着我们不能因为感激就放松判断。地图该量还是要量。比例尺不对，要说；路标错了，要说；把旧路说成新路，要说；把可能的相关性写成确定的因果，也要说。

只是说法可以不同。

我们不是冷冰冰地说：你错了。

我们可以说：这个问题很有意思，也确实把我们带到一个值得看的地方。但如果按目前的文献谱系来看，你声称自己站在这里，可能有点远；更稳妥的位置大概在那里。你这条路也许能走通，但需要把变量定义讲清楚，把识别假设说明白，把已经有人修过的路标出来。

这就是我想要的审稿：温柔，但不糊涂；犀利，但不刻薄；感谢作者，但不替作者放水。

从 workflow 的角度看，这意味着审稿至少有四层。

第一层是技术层。变量、模型、识别、数据、表格、引用、稳健性，都在这一层。这里要精确，要有证据，要能定位到段落、表格、公式和文献。

第二层是流程层。材料怎么归档，PDF 怎么还原，贡献链怎么重建，文献怎么检索，问题怎么进入台账，审稿意见怎么组装。这一层让审稿不靠灵感，而靠可复现的工作流。

第三层是判断层。什么算贡献成立？什么算 gap 太窄？什么算 overclaim？什么问题是 major，什么只是 minor？这一层决定审稿意见有没有边界感。

第四层是姿态层。也就是：我为什么审稿？我怎样进入一篇稿子？我把作者看成对手、学生、被审判者，还是一个有点话唠但愿意带我看风景的旅伴？

不同审稿人当然会不一样。

有人是守门人型，最关心期刊门槛。有人是导师型，最想帮作者把文章改好。有人是方法警察型，特别在意识别策略和模型规范。有人是领域地图型，最关心文章到底挂在知识谱系的哪里。

我想沉淀的是另一种姿态：

```text
reviewer-stance: knowledge-travel-companion
```

也就是：

```text
先感谢风景
再重建地图
然后校准路线
最后和作者对话
```

这不是浪漫化审稿，也不是降低标准。恰恰相反，它要求我们更认真。

因为如果你真的感谢这片风景，你就不会随便说它好或不好。你会想知道它属于哪座山脉，旁边有没有旧路，地图上哪些地方已经有人标过，哪些地方作者真的带你看到了新东西。你会认真查源头文献，认真看变量定义，认真问因果识别能不能支撑作者的语气。

比如一篇文章说它研究“机器人采用如何推动出口产品结构升级”。如果我们只审作者，很容易直接问：gap 成立吗？识别干净吗？结论夸大吗？

但如果我们把它当作一场知识旅行，顺序会变：

先问，这个领域原本怎么理解“出口升级”？是出口质量、出口品种、出口复杂度，还是产品范围？

再问，产品生命周期理论里的“新产品”到底是什么意思？比如 Xiang 那篇文章中的新产品，并不是企业自己研发的新产品，而是美国历史分类体系中后来出现、并能匹配到进口商品描述的产品类别。

再问，机器人文献已经知道什么？机器人会影响企业生产率、用工结构、出口质量、产品范围还是企业出口绩效？

等这些地图画出来，再回头看作者这篇：哦，原来它真正的窄贡献，可能不是“机器人与出口升级”，而是“机器人采用与基于产品生命周期的新产品出口占比”。这个位置可以讨论，但不能吹成新大陆。

这时审稿意见就会更稳，也更有善意。

不是说：你不行。

而是说：谢谢你带我看到这个地方。这个地方确实值得看。但你现在的地图有几处需要校准：第一，你的新产品定义来自一个特定历史分类体系；第二，你和出口质量、产品范围文献的距离没有讲清楚；第三，你的因果识别还不能完全支撑现在的语气。如果这些地方补好，这趟旅行会更可信。

这大概就是我想要的审稿系统。

不是挑刺机器。

也不是无原则鼓励。

而是一种带着感激、好奇、证据感和边界感的同行对话。

每一篇稿子都可能让我们多理解一点世界。哪怕它不完美，哪怕作者有点话唠，哪怕地图画得歪歪扭扭。我们还是可以感谢他带来的风景，然后认真、温柔、犀利地帮他把地图校准一点。
