# Engine Radar

## Pandoc

用途：通用 Markdown / R Markdown / Quarto 底层转换，支持 docx 和 `--reference-doc`。

要点：reference-doc 用于调整样式；docx template / reference-doc 不是完整 Word 模板系统。

来源：

- https://pandoc.org/MANUAL.html
- https://github.com/jgm/pandoc/issues/5268

## Quarto Journals

用途：外刊 manuscript、journal template、qmd/rmd 生态。

来源：

- https://quarto.org/docs/journals/formats.html
- https://github.com/quarto-journals
- https://github.com/quarto-journals/plos

## academic-pandoc-template

用途：通用 academic article / thesis / presentation，含 Word 输出样本。

来源：

- https://github.com/maehr/academic-pandoc-template

## markdown2docx

用途：Python Markdown 到 DOCX converter，支持模板、表格、脚注、目录、代码高亮。

来源：

- https://github.com/cnkang/markdown2docx

## markdown-docx

用途：Node/browser Markdown -> DOCX，可自定义 styles / colors / numbering。

来源：

- https://github.com/vace/markdown-docx

## python-docx-template

用途：复杂 Word 模板、固定页面、变量插入、页眉页脚和表单内容。

来源：

- https://github.com/elapouya/python-docx-template
