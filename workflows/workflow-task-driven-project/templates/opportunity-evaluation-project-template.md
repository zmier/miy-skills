# Opportunity Evaluation Project Template

## 推荐目录

```text
PROJECT-机会评估-项目名/
├── README.md
├── PROJECT-评估目标与决策.md
├── TASK-总-机会评估.md
├── inputs/
│   └── 原始材料.md
├── tasks/
│   ├── TASK01原始材料归档/
│   ├── TASK02真实需求识别/
│   ├── TASK03风险与可行性评估/
│   ├── TASK04客户追问与确认/
│   ├── TASK05PoC设计/
│   └── TASK06接单决策/
├── docs/
├── final_outputs/
│   └── 是否进入执行阶段-评估报告.md
└── logs/
```

## 标准 TASK

### TASK01 原始材料归档

保存客户原文、截图、文件、语音转写、上下文来源。只做保真记录，不做承诺。

### TASK02 真实需求识别

区分表层需求、真实急需、隐含期待、一期/二期边界。

### TASK03 风险与可行性评估

识别技术风险、合规风险、交付风险、客户协作风险、验收不确定性。

### TASK04 客户追问与确认

产出必须追问的问题、客户确认清单、范围边界。

### TASK05 PoC 设计

如果关键能力未知，设计最小验证，而不是直接报价完整交付。

### TASK06 接单决策

给出：接 / 不接 / 先 PoC / 改范围，并说明证据。
