# 逆向红灯分类

## 目的

红灯不是“失败”，而是路线选择信号。父 workflow 先把红灯分层，再路由到平台子 workflow。

## 红灯总表

| 红灯 | 表现 | 第一判断 | 下一步 |
| --- | --- | --- | --- |
| 看不到目标流量 | 代理里没有目标接口 | 流量可能不走普通 HTTP 代理 | 识别网络通道或运行态 bridge |
| 请求可见但重放失败 | 状态码异常、业务错误、签名错误 | 缺动态字段、环境态、时序或服务端绑定 | 建待解字段列表并做最小化 |
| 静态搜不到业务代码 | 只有壳、代理类、动态加载 | 可能加固、拆分、运行时加载 | 进入壳/加载器/运行时类恢复分支 |
| 静态代码可见但不可读 | 短名、控制流扁平化、字符串隐藏 | 混淆或保护 | 建符号映射，结合动态证据 |
| 找到函数但不知道实参 | 静态调用链太长或运行时分支复杂 | 需要动态观测 | hook / trace / breakpoint |
| Hook 后闪退 | 插桩被检测或时机不对 | 反调试、反 Frida、版本/ABI 不匹配 | 诊断插桩环境 |
| 算法复现不一致 | 中间值或最终值对不上 | 输入、编码、排序、padding、环境态不一致 | 分层 fixture 比对 |
| 离线运行缺环境 | native/wasm/harness 报缺对象或 API | 运行态依赖没有补齐 | 补环境或切回运行态代发 |
| 服务端拒绝 | 频率、账号、设备、签名、风控限制 | 不一定是算法错 | 限速、冷却、运行态代发、停止边界 |
| 工具不可用 | 版本、授权、架构、路径、依赖问题 | 工具链红灯 | 建 smoke test 与替代路线 |
| 单次成功但批量失败 | 小样本可用，长跑后 403/418/1009/验证码/空数据 | 进入服务端窗口或运行态长跑红灯 | 分接口队列、限速学习、断点、停止或降级覆盖率 |
| 同账号换设备可用、同设备换账号仍拒绝 | 账号不是主因，设备画像更强 | 设备态、自洽 bundle、运行态 envelope | 只读溯源设备态，避免后置乱改字段 |
| App/浏览器运行态可发，外部脚本失败 | 服务端接受真实运行态 envelope | R1 不一定是当前正确目标 | 选择 R4 代发并声明边界 |

## 分层原则

优先定位首个不一致层：

```text
目标行为
→ 网络是否可见
→ 请求是否可重放
→ 参数是否可解释
→ 算法是否可复现
→ 运行态是否可代发
→ 服务端是否接受
```

不要在没有证据时跳层。例如重放失败不一定是加密算法错，也可能是账号态、设备态、连接态或风控态。

遇到服务端拒绝时，先区分：

```text
算法/参数不合法
vs
运行态 envelope 不自洽
vs
账号/设备/连接/频率窗口
vs
授权或服务端压力边界
```

只有第一类才优先继续破算法；后几类应考虑 R4、限速、冷却、停止或覆盖率降级。

## 平台适配示例

| 抽象红灯 | Android 可能表现 | JS 可能表现 |
| --- | --- | --- |
| 流量不可见 | App 忽略系统代理、mobilegw、长连接 | fetch 被 service worker/iframe/worker 包装，或走 WebSocket |
| 代码不可读 | R8/ProGuard、Dex 壳、OLLVM | webpack 混淆、压缩变量、控制流混淆 |
| 动态实参未知 | Java/Native 方法参数只在运行时生成 | 函数闭包、运行时状态、浏览器环境对象 |
| 离线环境缺失 | Unidbg 缺 Android API / Java 对象 | Node 缺 window/document/crypto/localStorage |

## 记录要求

每个红灯都要进入证据台账：

- 红灯名称；
- 观察到的现象；
- 证据文件或操作窗口；
- 当前假设；
- 下一步最小实验；
- 成功/失败后的路由。
