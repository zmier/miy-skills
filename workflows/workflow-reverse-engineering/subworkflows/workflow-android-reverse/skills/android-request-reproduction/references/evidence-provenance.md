# 证据来源与角色

每项结论必须区分“工具参与过”和“哪些产物承担 Green”。

## 证据角色

- `primary`：可重复执行、已落盘，并直接满足预设 Green 条件。
- `confirmatory`：由独立工具或路线复核 primary 结论。
- `exploratory`：用于发现目标、排错或形成假设，不能单独升级完成状态。
- `superseded`：曾参与过程，但已被更完整证据替代；保留过程说明，不再作为当前依据。

## 必填字段

```yaml
结论:
证据角色:
工具或MCP:
输入哈希:
调用或命令:
落盘产物:
可重复性:
Green条件:
结果:
```

MCP 对话返回若未落盘，只能作为 `exploratory` 或 `confirmatory`。要承担 `primary`，必须保存最小报告或机器可读导出，并记录数据库哈希、会话操作和关闭状态。

同一结论允许多个证据源，但不能用“工具列表”替代“证据角色”。
