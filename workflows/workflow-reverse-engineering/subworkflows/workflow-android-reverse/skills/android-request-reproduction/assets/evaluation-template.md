## Procedure

1. Reproduce the teacher's critical manual steps.
2. Run the Skill-assisted path without giving it the expected conclusion.
3. Compare intermediate evidence, not only the final output.
4. Assign A, B, or C using the umbrella Skill policy.
5. Update the Skill only from observed failure or ambiguity.
