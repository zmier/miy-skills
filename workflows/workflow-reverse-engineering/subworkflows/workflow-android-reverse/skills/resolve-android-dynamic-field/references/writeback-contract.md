# 字段闭环写回

## 字段 TASK

至少保存：

- 字段目标、请求位置和路线；
- 静态读取与生成链；
- 缓存、持久化和首次生成层；
- 分支输入与触发条件；
- Frida 当前分支证据；
- 外部实现和测试；
- 替代构造的范围与绑定风险；
- 结论和未覆盖场景。

## 请求构造台账

Mermaid 中从真实字段节点展开：

```text
字段
→ 字段 TASK
→ 读取/生成方法
→ 验证结果
→ 缓存、持久化、首次生成、来源和编码子节点
```

节点表同步更新能力状态、真实性要求、绑定风险、证据和下一动作。

同时更新：

- 对应 Unit 测试状态与 fixture；
- Mermaid 中的红灯、Green 状态和证据链接；
- 唯一 `NEXT`；不得保留已经完成字段的旧指针。

## 工作流状态

- 从对应路线的未解决叶子移除前，确认已经达到该路线门槛。
- 只完成替代构造时保留真实还原叶子。
- 下一步应指向新的最小阻塞，不继续保留已经完成的字段。
- 字段只达到 `observed` 或 `hook-available` 时，不得把 R3 的真实生成测试标为通过。

## ReAct 日志

只记录可审计摘要：

- `Reason`：缺少哪一层证据；
- `Action`：静态搜索、只读 Hook、离线实现或状态实验；
- `Observation`：实际返回值、分支和对照结果；
- `Decision`：状态推进、适用范围和下一动作。
