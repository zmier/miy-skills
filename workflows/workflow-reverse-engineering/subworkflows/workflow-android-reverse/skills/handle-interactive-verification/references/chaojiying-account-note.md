# 超级鹰账户配置说明

- 账号标识从本机忽略文件 `.env.local` 的 `CHAOJIYING_USER` 读取；不要把注册邮箱或账号写进版本库。
- 官方站点：https://www.chaojiying.com/
- 默认识别类型：`1902`，官方价格页说明为 4~6 位英文数字，官方单价为 10/12/15 题分；如遇滑块/坐标题，按 https://www.chaojiying.com/price.html 重新选择 `codetype`。
- 安全备注：不要记录或传播包含 `sid` 等会话参数的邮箱链接；超级鹰账号密码、邮箱登录态和识别结果仍应放在本地忽略文件或人工手册中，不写入日志。
