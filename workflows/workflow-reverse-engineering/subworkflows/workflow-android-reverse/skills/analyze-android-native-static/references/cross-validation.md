# IDA、objdump 与 Frida 交叉验证

| 证据源 | 最擅长回答 |
|---|---|
| IDA/Hex-Rays | 控制流、伪代码、xref、JNI 对象构造 |
| LLVM objdump | 指令字节、Thumb 解码、直接调用偏移 |
| Frida | 当前运行的真实参数、长度、分段顺序与返回地址 |

注意：Frida 的返回地址通常落在调用指令之后，因此可能比 IDA/objdump 标出的 `BL` 指令地址大 4 字节。这是观察点差异，不是冲突。

比较顺序：

1. 先确认输入二进制哈希一致；
2. 再确认地址类型一致；
3. 再比较控制流、算法角色和数据流；
4. 工具函数边界不同但语义一致时，记录为表示差异；
5. 真实参数冲突时以同次运行时 fixture 为准，并回查静态假设。
