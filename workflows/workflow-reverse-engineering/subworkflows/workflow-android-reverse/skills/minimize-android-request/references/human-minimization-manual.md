# 人类参数归约操作手册

## 原则

- 每次只修改一个参数；
- 每次从未修改的基线请求复制；
- 未收到明确实验编号时不自行试删；
- 发送一次后停止，原样报告响应；
- 不复制敏感值到聊天或 Markdown。

## 单次操作格式

```text
实验编号：
基线请求：
目标参数：
修改动作：
禁止修改：
发送次数：
需要反馈：
停止条件：
```

## 人类反馈

至少报告：

```text
MIN-EXP-* 响应：HTTP <状态>
业务码：<原样摘要>
页面观察：<原样显示或不适用>
异常：<无或具体情况>
```

AI 收到反馈后先写日志，再给出下一项实验。不要让人类一次执行整张清单。
