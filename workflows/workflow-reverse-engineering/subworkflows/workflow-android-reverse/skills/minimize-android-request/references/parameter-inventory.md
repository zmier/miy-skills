# 参数清单

## 分类

按位置建立清单：

| 位置 | 示例 | 初始处理 |
|---|---|---|
| URL Path | `/x/report/click/android2` | 固定，不作为参数删减 |
| Query | `ts`、`sign` | 单字段实验 |
| 标准头部 | `Accept-Encoding`、`User-Agent` | 先测试低风险项 |
| 应用头部 | 设备、会话、应用版本字段 | 逐项测试并脱敏记录 |
| Form/JSON | 业务实体、状态、签名 | 逐项测试 |
| 不透明正文 | protobuf、gRPC、密文 | 整体视为一个不可分字段 |

## 清单字段

每项记录：

- 稳定编号 `PARAM-*`；
- 参数位置和脱敏名称；
- 当前样本中的形态，不保存敏感原值；
- 静态、环境、动态或未知；
- 预计风险；
- 对应实验；
- 最终状态；
- 下一步。

## 实验顺序

通常按以下次序降低返工：

1. 代理或协议栈可自动补充的头部；
2. 展示、压缩和客户端描述头部；
3. 应用环境头部；
4. 会话与设备字段；
5. 业务实体字段；
6. 时间戳、签名、加密正文等动态字段。

这只是优先级，不是必要性结论。
