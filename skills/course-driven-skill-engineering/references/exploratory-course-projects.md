# 探索性课程项目

## 适用场景

探索性课程项目介于课程复现和真实研究之间：

- 由课程、训练营或老师提示触发；
- 没有完整标准答案，或标准答案只覆盖一部分；
- 目标会随着抓包、运行、服务端反馈、数据覆盖率和工具边界逐步变化；
- 最终产物既包括业务/研究交付，也包括对领域 Skills 的升级。

典型例子：

```text
老师讲了抓包专题
→ 选择一个真实授权 App 或小程序
→ 发现普通代理看不到目标业务请求
→ 通过 bridge/RPC Hook 确认数据通道
→ 封装 Frida RPC 工具
→ 又发现分页窗口、账号限制、服务端压力和多入口覆盖问题
→ 把这些红灯反哺到抓包、通道识别、响应建模、批量采集和任务管理 Skills
```

## 与标准课程案例的区别

| 维度 | 标准课程案例 | 探索性课程项目 |
|---|---|---|
| 答案来源 | 教师路线可作为对照 | 没有完整答案，真实反馈优先 |
| 冻结对象 | 教师解法 | 初始假设、既有经验、过早结论 |
| Green | 复现指定现象或算法 | 达到阶段性证据、工具可用或研究边界清楚 |
| 风险 | 抄答案、伪装独立发现 | 把阶段成果误称为全量、忽略服务端/账号/覆盖率边界 |
| Skill 产物 | 路线、工具、失败模式 | 研究策略、操作护栏、数据边界、工作流转向规则 |

## 启动方式

1. 写明探索问题，而不只写任务动作。
2. 定义阶段终点：
   - `capability`：能否建立一种工具能力；
   - `coverage`：能否扩大样本或入口覆盖；
   - `explanation`：能否解释一个红灯或限制；
   - `deliverable`：能否产出可用数据、文档或脚本。
3. 预先写停止条件：
   - 授权边界触达；
   - 服务端压力或账号限制出现；
   - 新入口收益低于成本；
   - 证据足以升级 Skill，但不足以声明全量。
4. 建立 TASK 工作区，使用 ReAct 日志记录路线变化。
5. 把每个新发现标注为：
   - `field-discovery`：真实环境暴露的新现象；
   - `workflow-gap`：现有 workflow 没覆盖；
   - `tool-gap`：缺少脚本、MCP 或自动化适配；
   - `boundary`：不能越过或暂不应越过的边界；
   - `transfer-candidate`：可迁移规则候选。

## 证据分层

探索性项目中，证据角色除 `primary / confirmatory / exploratory / superseded` 外，还要记录：

- `field-primary`：真实项目中直接观察到、可重复的现象；
- `field-limited`：真实可用但受账号、时间、服务端窗口或入口限制；
- `field-hypothesis`：有线索但未充分验证；
- `field-boundary`：授权、安全、服务端压力或平台限制决定的停止边界。

不要把 `field-limited` 写成通用能力已验证。它只能触发 Skill 中的边界说明、降级路线或后续实验。

## Skill 提炼规则

探索性项目最值得沉淀的不是个案数据，而是“遇到什么红灯，如何转成下一步”：

| 发现 | 放入 TASK | 放入 Skill |
|---|---|---|
| 某个真实 ID、Token、URL、账号状态 | 是 | 否 |
| 某接口最多返回约 1000 条的证据 | 是 | 作为数据边界模式 |
| 多入口收集 ID 再去重 | 证据与脚本 | 作为研究策略 |
| 限速、断点续跑、脱敏保存 | 实际参数 | 作为操作护栏 |
| 普通代理看不到目标业务流量 | 抓包日志 | 作为通道识别路由规则 |
| Frida RPC 比纯外部重放更合适 | 工具实现 | 作为交付路线选择规则 |

## Evaluation

探索性项目的 evaluation 不只问“老师答案是否复现”，而要问：

1. 阶段终点是否达成；
2. 新红灯是否被准确命名；
3. 现有 Skill 是否能独立路由到下一步；
4. 新增规则是否避免个案固定值；
5. 操作护栏是否足以防止过度采集、服务端压力或敏感数据落盘；
6. 下一个类似项目能否不用本次对话背景也走到同类方案。

## 常见误判

- 把“当前账号能访问”误判为“接口无限制”。
- 把“能拿到 1000 条”误判为“全量拿完”。
- 把“Hook 到 bridge/RPC”误判为“已经能纯 Python 重放”。
- 把“真实项目里成功一次”误判为“Skill 迁移已 validated”。
- 把“课程没讲”误判为“不属于课程驱动 Skill 工程”；探索性课程项目正是课程能力向真实场景迁移时的必经层。
