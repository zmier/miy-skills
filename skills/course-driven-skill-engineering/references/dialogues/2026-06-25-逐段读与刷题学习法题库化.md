# 逐段读与刷题学习法题库化

## 触发问题

用户在讨论《Empirical Asset Pricing》前 6 章题库化时追问：

> 原子知识点覆盖表你准备怎么抽？逐章做对吧？每章内部你又准备如何抽呢？你肯定得先读嘛对吧？具体怎么读、怎么抽呢？

随后进一步确认：

> 那你会逐段文字读，然后判断是否需要抽知识点吗？

## 共同发现

原子知识点不能靠章节标题猜，也不能靠模型凭印象一次性列大纲。对于要“尽量穷尽知识点”的题库化项目，必须回到材料本身逐段读。

但逐段读不等于每段都抽题。更稳的流程是：

```text
逐段读取
→ 先判断段落功能
→ 再判断是否产生可检测 atom
→ 再决定是否进入覆盖表
→ 最后由覆盖表生成题库
```

## 候选原则

1. 段落功能分类先于知识点抽取。
2. atom 必须能被一道题检测，否则更像学习札记或章节摘要。
3. 覆盖表是正式题库的前置门，不应跳过。
4. 刷题学习法不是取代精读，而是把精读结果变成诊断器。
5. 错题和薄弱 atom 要回流章节档案或知识修复，而不是停留在题库内部。

## 保留边界

不进入通用 Skill 的内容：

- 实证资产定价 Ch1-Ch6 的具体 atom；
- A 股热榜因子例子；
- 具体题库文件名；
- 用户个人错题和盲区。

这些应留在 SMK 项目 TASK、章节档案和刷题系统题库中。
