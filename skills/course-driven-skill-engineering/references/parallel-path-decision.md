# 教师平行路线决策

为每条教师路线按 0-2 分评估：

| 维度 | 0 | 1 | 2 |
|---|---|---|---|
| 新知识 | 无新增 | 加深理解 | 新原理或新技术层 |
| 新工具能力 | 已覆盖 | 新操作方式 | 新工具/自动化能力 |
| 路线优势 | 明显更差 | 有局部优势 | 更快、更稳或更通用 |
| 交叉验证 | 不能增加置信度 | 局部复核 | 独立证据链 |
| 迁移价值 | 个案技巧 | 条件性复用 | 可形成通用规则 |
| 教学必要性 | 可跳过 | 有助理解 | 课程核心目标 |

## 决策

- `0-3`：不补做，记录差异即可。
- `4-7`：选择关键步骤做最小平行实验。
- `8-12`：建立完整平行 TASK，并评估是否升级 Skill。

分数不是机械命令。若涉及高风险副作用、授权不足或环境不可控，即使高分也停止。

## 路线关系

- `alternative`：可替代主路线。
- `confirmatory`：用于独立复核。
- `enhancement`：主流程完成后的学习增强。
- `fallback`：主路线失败时启用。

路线完成后必须补充选择条件，而不只是记录“还有另一种做法”。
