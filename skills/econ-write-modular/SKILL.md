# 模块化经济学写作

这个 skill 是原始 `econ-write` skill 的模块化重组。实质性写作指南保存在 `references/` 中；本文件只负责把任务路由到相应的原始章节。

## 总是先读取

在处理经济学写作、改写、审读或结构组织任务前，先读取 `references/00_前言.md` 和 `references/01_核心原则.md`。

## 章节路由

- 摘要任务：读取 `references/02_写摘要.md`。
- 引言、开篇钩子、文献定位、增量贡献或路线图任务：读取 `references/03_写引言.md`。
- 理论、结构模型、假设、命题、证明、公式或可检验预测：读取 `references/04_写模型部分.md`。
- 数据、样本构造、关键变量、描述性统计、制度背景：读取 `references/05_写数据部分.md`。
- 结论任务：读取 `references/06_写结论.md`。
- 风格、清晰度、语态、词语选择、脚注、符号、段落、反 AI 痕迹：读取 `references/07_写作风格规则.md`。
- 表格、图形、标题说明、回归表、数据可视化：读取 `references/08_表格和图形.md`。
- 实证识别、结果、零结果、异质性、机制：读取 `references/09_实证研究规则.md`。
- 现代实证实践、预注册、多重检验、可复现性、引用、复制包、AI 披露：读取 `references/10_现代实证实践.md`。
- 标题任务：读取 `references/11_标题写作.md`。
- 按应用微观、宏观、贸易、金融等领域调整：读取 `references/12_分领域惯例.md`。
- 全文结构、附录、JMP、博士论文：读取 `references/13_论文结构概览.md`。
- 用户要求起草、改写、写具体章节、报告展示、综述、期刊版本转换、基金、非学术输出、审读、审计、审稿回复：读取 `references/14_使用场景说明.md`。
- 投稿前或最终全文检查：读取 `references/15_修改检查清单.md`。

## 从原始 Skill 保留的配套参考文件

- 按识别策略区分的写作指南：读取 `references/16_按识别策略写作.md`。
- LaTeX 格式指南：读取 `references/17_LaTeX格式指南.md`。
- 带模拟审稿人与评分的结构化论文审读：读取 `references/18_论文审读清单.md`。

## 使用规则

只加载用户任务需要的文件，但应用时要保留原始 `econ-write` 指南的内容。除非用户要求简短回答，不要把具体规则、例子、检查清单或注意事项概括掉。
