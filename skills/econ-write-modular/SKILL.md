# 模块化经济学写作

这个 skill 是原始 `econ-write` skill 的模块化重组。实质性写作指南保存在 `references/` 中；本文件只负责把任务路由到相应章节与辅助线指南。

## 总是先读取

在处理经济学写作、改写、审读或结构组织任务前，先读取 `references/00_前言.md` 和 `references/01_核心原则.md`。

## 章节路由

- 摘要任务：读取 `references/02_写摘要.md`。
- 引言、开篇钩子、文献定位、增量贡献或路线图任务：读取 `references/03_写引言.md`；若任务是中文经济学论文、政策背景较强、现实事件进入研究问题，或用户提到中文期刊模板/杨子晖模板，追加读取 `references/20_中文引言写作经验.md` 和 `references/examples/introduction/00_中文期刊三段式引言.md`。
- 文献综述、理论假设、研究空白、文献线索整理任务：读取 `references/14_使用场景说明.md` 中“当用户要求写文献综述时”；若任务是中文经济学论文、独立第二章“文献综述/理论假设”、按机制渠道组织综述、或用户提到中文期刊模板/杨子晖模板，追加读取 `references/21_中文文献综述写作经验.md` 和 `references/examples/literature-review/00_机制线索式文献综述.md`。
- 理论、结构模型、假设、命题、证明、公式或可检验预测：读取 `references/04_写模型部分.md`。
- 数据、样本构造、关键变量、描述性统计、制度背景：读取 `references/05_写数据部分.md`。
- 结论任务：读取 `references/06_写结论.md`。
- 风格、清晰度、语态、词语选择、脚注、符号、段落、反 AI 痕迹：读取 `references/07_写作风格规则.md`。
- 表格、图形、标题说明、回归表、数据可视化：读取 `references/08_表格和图形.md`。
- 实证识别、结果、零结果、异质性、机制：读取 `references/09_实证研究规则.md`。
- 现代实证实践、预注册、多重检验、可复现性、引用、复制包、AI 披露：读取 `references/10_现代实证实践.md`。
- 标题任务：读取 `references/11_标题写作.md`。
- 按应用微观、宏观、贸易、金融等领域调整：读取 `references/12_分领域惯例.md`。
- 全文结构、附录、JMP、博士论文：读取 `references/13_论文结构概览.md`。
- 用户要求起草、改写、写具体章节、报告展示、综述、期刊版本转换、基金、非学术输出、审读、审计、审稿回复：读取 `references/14_使用场景说明.md`。
- 投稿前或最终全文检查：读取 `references/15_修改检查清单.md`。

## 辅助线与写作状态路由

当用户要求写整篇论文、重写引言、全文检查、大修、梳理主线、统一术语、搭框架、建立逐段提纲、检查论断证据或排查审稿风险时，读取 `references/blueprint/00_辅助线总则.md`。

辅助线是论文写作过程中的中间工件，不一定进入最终正文，但用于持续约束全文主线、术语、结构和证据。若用户项目中没有写作状态文件，优先建议或创建 `writing-state/`，并使用 `references/blueprint/templates/00_写作状态文件夹模板.md`。

按任务追加读取：

- 初始化或重建论文主线：读取 `references/blueprint/01_一句话核心发现.md`。
- 梳理研究问题、文献位置、贡献：读取 `references/blueprint/02_研究问题与贡献地图.md`。
- 统一概念、术语、关键词、标题用语：读取 `references/blueprint/03_概念术语表.md`。
- 对齐理论概念、变量、符号、表格：读取 `references/blueprint/04_变量概念映射表.md`。
- 梳理机制、假说、可观测预测、替代解释：读取 `references/blueprint/05_机制链条.md`。
- 搭全文结构或章节目录：读取 `references/blueprint/06_三级目录大纲.md`。
- 写作或审读长章节、引言、结果、结论前：读取 `references/blueprint/07_逐段TopicSentence细纲.md`。
- 检查强论断、证据、贡献、摘要和引言承诺：读取 `references/blueprint/08_论断证据表.md`。
- 组织表格、图形、结果段落和附录取舍：读取 `references/blueprint/09_结果叙事表.md`。
- 投稿前、大修、返修或模拟审稿：读取 `references/blueprint/10_审稿人风险清单.md`。

写正文前先读取相关辅助线；写正文后检查是否需要反向更新辅助线。不要从语言润色开始替代主线、术语、证据和结构检查。

## 使用规则

只加载用户任务需要的文件，但应用时要保留原始 `econ-write` 指南的内容。除非用户要求简短回答，不要把具体规则、例子、检查清单或注意事项概括掉。
