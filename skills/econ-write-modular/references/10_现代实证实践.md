# 现代实证实践

## 预注册和预分析计划

- 如果研究已预注册，在引言说明（这是可信度资产）。
- 清楚区分预先指定分析和探索性分析。
- 引用预分析计划（如 AEA RCT Registry 编号）。

## 多重检验

- 检验多个结果或子组时，承认多重检验问题。
- 报告 family-wise error rate 修正（Bonferroni, Holm）或 false discovery rate（Benjamini-Hochberg）。
- 至少标注哪些结果经多重检验修正后仍成立。

## 规格稳健性

- 不要只呈现“有效”的规格。
- 对关键结果考虑 specification curve 或 multiverse analysis。
- 报告合理规格下估计值的分布。

## 透明性和可复现性

- 清楚说明数据可得性：公开、受限访问或专有。
- 提供或引用复制代码。
- 描述会实质影响结果的数据清洗决策。
- 使用受限数据时，说明申请流程，使他人可复现。

## 引用完整性

- 核验每条引用：作者名、年份、期刊和关键发现是否准确。AI 工具经常编造或误引。
- 引用其他论文结果时，确认引用的是正确规格（如首选估计，而非稳健性检验）。
- 区分工作论文版本和发表版本；发现可能在版本间变化。
- 不要引用没读过的论文。如果只通过二手引用知道某文，应引用二手来源：“as discussed in [secondary source]”。
- 对知名结果（如 Mincer returns、gravity equation），引用原始来源，而不是教材或综述。

## 复制包（AEA Data Editor 标准）

- 所有提交给 AEA 期刊的实证论文（以及越来越多其他期刊）都必须包含复制包。
- README 应遵循 Social Science Data Editors 模板：Data Availability & Provenance Statements、Dataset List、Computational Requirements、Description of Programs、Instructions for Replicators。
- 在 manuscript 的 References 中引用每个数据集，包括你自己创建的数据集。
- 目录结构：`data/raw/`、`data/analysis/`、`code/`、`results/`。不要混放代码和数据。
- 代码必须无人工干预地复现所有结果。唯一例外是一个配置文件，让复现者设置路径。
- 对受限访问数据，提供 Data Availability Statement，说明申请流程、预计等待时间和费用。
- 包含 `LICENSE.txt`（默认数据和代码使用 CC-BY 4.0）。
- 将每个表和图映射到具体程序文件：“Table 3 is produced by `code/table3_main_results.do`”。
- 这些标准适用于 AEA、Econometrica（ES Data Editor）、Economic Journal，并越来越多适用于领域期刊。

## AI 使用披露

- AEA 政策：AI 不能列为作者。如果使用 AI 起草或编辑 manuscript，投稿时披露。
- Econometric Society：要求责任声明，所有合作者对全部内容负责。
- 需要披露的内容：起草辅助、代码生成、文献检索辅助、数据分析建议。
- 通常不需要披露：拼写检查、语法工具、LaTeX 格式。
- 无论期刊政策如何：你负责核验所有 AI 生成内容，包括引用、数字主张和统计解释。
- 实用规则：如果 AI 起草了一个段落，就像读一个粗心 RA 写的段落一样，核验每个事实、每条引用、每个数字。
