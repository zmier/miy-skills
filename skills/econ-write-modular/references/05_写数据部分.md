# 写数据部分

## 结构

1. **数据来源**：第一句说明数据集名称、时间范围、地理覆盖和观察单位。
2. **样本构造**：说明纳入/排除标准、合并过程和最终样本量。
3. **关键变量**：准确定义处理变量、结果变量和控制变量。说明每个变量如何测量。
4. **描述性统计**：呈现汇总统计表。
5. **制度背景**：如果情境不熟悉，提供足够背景，使读者能理解识别策略。

## 规则

- 在读者提问之前，回答关于数据的所有问题（Cochrane）。
- 每个变量首次出现时定义，不要让读者去脚注里找。
- 描述会实质影响结果的数据清洗决策，如缩尾、剔除异常值。
- 说明样本选择：谁在样本里，谁被排除，为什么。
- 使用受限数据时，说明其他研究者如何获取。
- 使用多个数据集时，说明合并过程和匹配率。
- 不要把重要数据限制藏在脚注里，要在正文说明。

## 描述性统计表

- 报告关键变量的 N、均值、标准差、最小值、最大值。
- 如果适用，分别报告处理组和控制组。
- 对 RCT 和准实验，单独报告平衡性检验表。
- 在表注中定义每个变量，而不仅在正文定义。
- 四舍五入到 2-3 个有意义的小数位。
