# 中文经济学论文写作总则

## 定位

本文件补充原始经济学写作原则在中文经济学期刊语境中的使用方式。原始原则仍然有效：读者优先、中心贡献清楚、具体胜过抽象、每段服务主线。

中文论文写作的特殊之处在于：不少文章需要从政策背景、现实事件或中国制度情境进入研究问题，再把问题转化为可测概念、模型设定和经验检验。使用中文模板时，不要把政策背景写成空泛动员，也不要让现实材料替代理论问题。

## 核心规则

1. 政策背景只能负责“为什么重要”，不能替代研究问题。
2. 现实事件只能负责“为什么有问题”，不能替代机制解释。
3. 研究问题必须落到明确的 X、Y、机制、方法或场景。
4. 文献综述应按机制线索组织，而不是按作者罗列。
5. 论文自己的核心发现不能伪装成已有文献共识。
6. 政策概念应降格为背景或结论，不抢占模型主线。
7. 中文表达可以稳健，但不能含混；可以有政策语境，但不能通篇政策腔。

## 概念闭环

中文论文尤其需要检查概念是否闭环：

```text
引言提出概念
-> 文献综述解释概念来源
-> 模型/变量将概念操作化
-> 结果回收概念
-> 结论和政策建议回到概念边界
```

如果一个概念只在引言出现，后文没有测度、机制或结果回收，应考虑降格、删除或换成普通表达。
