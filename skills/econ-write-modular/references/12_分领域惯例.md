# 分领域惯例

不同经济学子领域惯例不同。按领域调整规则。

## 应用微观（劳动、公共、健康、教育、发展）

- 本 Skill 默认采用应用微观风格。多数规则直接适用。
- 发展 RCT：预注册几乎必需；包含 CONSORT 式流程图；报告成本效果和处理效应。
- 平衡性表对实验研究很重要，应显著呈现，而不是放附录。

## 宏观经济学

- 论文更长（40-60 页正常）；“40 页以内”的建议不适用。
- 校准表是标准配置：参数名、数值、来源/目标矩。
- 冲击响应函数（IRFs）是主要结果可视化，而不是回归表。
- 需要模型验证部分（“Model Fit”），比较模型矩和数据矩。
- DSGE 论文：描述稳态、log-linearization 或求解方法，以及冲击设定。
- 结果常写成 “the model generates X”，而不是 “I find X”。

## 贸易

- 引力模型有特定惯例：PPML 估计（Santos Silva and Tenreyro 2006）、多边阻力控制、固定效应结构。
- 结构贸易论文通常需要一般均衡反事实。
- 使用 3 年或 5 年面板间隔，而不是年度间隔，并给出具体理由。

## 金融

- 一些金融期刊摘要限制通常为 100 词，而非 150。
- Fama-MacBeth 回归和组合排序展示是标准惯例。
- 变量 1%/99% 缩尾是常见预期，且必须报告。
- 部分期刊使用 Chicago Manual of Style 引用格式（不同于 AEA）。
