# 表格和图形

## 回归表

- 每张表都必须有自足标题，解释回归、变量和展示内容。
- 不要在表中放正文没有讨论的数字。
- 使用普通英文变量名（“Years of education”“Female”），不要用代码名。
- 全表小数位一致（2-3 位）。
- 对每个重要数字报告标准误。说明聚类层级（“Standard errors clustered at the state level”）。
- 表底部列出 N、R-squared、固定效应、控制变量。
- 显著性星号：* 10%，** 5%，*** 1%（注意部分期刊不鼓励星号，检查目标期刊风格）。
- 读者应能仅凭表格写出精确回归。

## 描述性统计表

- 报告所有关键变量的 N、均值、标准差、最小值、最大值。
- 若适用，处理组和控制组分 panel。
- 平衡性检验：在单独列或单独表中报告均值差和 p 值。
- 在表注中定义每个变量。

## 图形

- 好图比大表更能传达模式。
- 图注应自足，并用文字定义符号。
- 坐标轴标签清楚，单位合理。
- 避免复印后消失的虚线。
- 对波动剧烈的序列不要使用破折线。

## 何时用图，何时用表

- 用**图**展示：时间趋势、分布、非线性关系、RD/event-study 图，以及任何视觉模式本身就是重点的结果。
- 用**表**展示：带标准误的回归系数、跨规格精确数值比较、汇总统计。
- 展示 20 个回归系数时，系数图通常好于 20 行表格。
- 经验法则：如果你写 “as Table 3 shows, there is an inverted-U relationship”，把表换成图。
- 每个关键结果要么出现在图中，要么出现在表中，不要两者都放（节省篇幅）。
- 最重要的图/表应放在结果部分开头附近。

## 数据可视化（Schwabish, JEP）

- 展示数据，而不是展示分析者有多聪明。
- 减少非数据墨水（Tufte 原则）。
- 尽可能使用直接标签，而不是图例。
- 突出关键比较。
- 相关图形使用一致色彩方案。
