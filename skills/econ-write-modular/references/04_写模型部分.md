# 写模型部分（理论和结构模型论文）

## 核心原则（Glaeser, Varian）

- “从一个例子开始。一个好例子抵得上一千个定理。”（Glaeser）
- 使用能生成关键洞见的最简单模型。如果两期模型够用，就不要用无限期模型。
- 每个假设都必须值得存在：解释哪些是假设对结果必要，哪些只是简化。

## 结构

1. **设定段落**：在任何数学之前，用普通语言描述经济环境、主体、时序和信息结构。
2. **形式化模型**：呈现 primitives、偏好、技术、约束。
3. **均衡定义**：清楚说明解概念。
4. **主要结果**：命题之前先给经济直觉，再给正式证明。
5. **比较静态**：用语言讨论：“When X increases, Y falls because...”
6. **扩展**：一次放松一个关键假设，以显示稳健性。

## 写命题和证明

- 每个命题先用普通语言陈述，再正式表述。
- 命题陈述后立即给经济直觉，在证明之前。
- 证明放到附录，除非证明本身揭示了经济机制。
- 复杂证明在正文给 proof sketch，完整证明放附录。
- 只给你后文会引用的命题、引理和推论编号。

## 写假设

- 明确列出假设并编号。
- 对每个假设说明：（a）形式化陈述；（b）普通语言解释其经济含义；（c）它是必要假设还是简化假设。
- 讨论放松关键假设后会发生什么，这能展示稳健性并建立可信度。

## 文中公式

- 只给后文会引用的公式编号。
- 展示公式前必须先用语言引入：“Firm i's profit is...” 然后再放公式。
- 每个变量在公式后立即定义，即使之前定义过。
- 不要展示能用文字说明的琐碎公式，例如“工资等于劳动边际产出”不需要展示公式。
- 全文符号一致：拉丁字母用于变量，希腊字母用于参数。

## 可检验预测

- 明确生成可检验预测。即使不检验，也要说明需要什么数据。
- 对理论与实证结合论文：实证部分应明确检验模型预测。每个回归都要映射到具体命题。
