# 机制链条

## 作用

机制链条控制理论机制、研究假说和实证检验之间的一致性。它要求论文把“为什么会发生”拆成可解释、可观察、可检验的环节。

如果 [[02_概念术语表]] 已使用 M 编号，本文件应继承同一编号。机制链条不是另起一套编号，而是把概念谱系中的 M 编号展开为理论机制、模型设定、可观测预测和结果解释。

## 建议模板

```markdown
# 机制链条

## 机制编号对应

| 机制编号 | 机制环节 | 上位概念 | 下位概念/模型部件 | 对应章节 |
|---|---|---|---|---|
| M0 | 冲击入口/场景 |  |  | 引言、模型设定 |
| M1 | 第一机制路径 |  |  | 文献综述、模型设定、结果 |
| M2 | 第二机制路径 |  |  | 文献综述、模型设定、结果 |
| M3 | 结果路径/机制耦合 |  |  | 结果、结论 |

## 主机制

M0 [冲击 X] -> M1 [第一机制路径] -> M2 [第二机制路径/行为调整] -> M3 [结果 Y]

## 经济学解释

1. 为什么 X 会影响 M1：
2. 为什么 M1 会引发 M2：
3. 为什么 M2 会改变 Y：

## 可观测预测

| 机制编号 | 机制环节 | 可观测变量/模型部件 | 对应检验/仿真对照 | 支持证据 |
|---|---|---|---|---|
| M0 -> M1 | X -> M1 |  |  |  |
| M1 -> M2 | M1 -> M2 |  |  |  |
| M2 -> M3 | M2 -> Y |  |  |  |

## 替代机制

| 替代解释 | 为什么可能成立 | 本文如何排除或区分 |
|---|---|---|
|  |  |  |
```

## 使用规则

- 写理论机制、假设、机制检验前读取。
- 引言中讲研究设计和核心机制时也要读取。
- 若结果段新增机制解释，反向更新本文件。
- 若 [[02_概念术语表]] 存在 M 编号，本文件必须继承，不得另造“机制 1/机制 2”之类的平行编号。
- 对 ABM、DSGE、结构模型、计算实验类论文，应同时写清“理论机制链”和“模型生成机制链”：哪些机制来自文献，哪些机制是本文通过模型模块显式设定出来的。

## 检查问题

- 机制链条是否闭合到核心结果变量？
- 每个机制环节是否有经济学解释？
- 可观测预测是否对应后文实证检验？
- 替代机制是否需要在正文中提前回应？
- 机制编号是否与概念术语表一致？
- 文献综述中的机制铺垫是否能逐项对应到模型设定、公式、参数或仿真对照？
