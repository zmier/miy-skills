# 审稿人风险清单

## 作用

审稿人风险清单提前暴露最可能被质疑的点。它让全文审读从“哪里不顺”升级为“审稿人为什么可能不信、不懂或不认可”。

## 建议模板

```markdown
# 审稿人风险清单

| 风险 | 类型 | 可能的审稿人问题 | 当前回应 | 需要补什么 |
|---|---|---|---|---|
| 识别不足 | 方法 | X 是否外生？ |  |  |
| 机制不清 | 理论 | 为什么是资本约束而不是需求冲击？ |  |  |
| 贡献不足 | 文献 | 相比已有风险传染文献新在哪里？ |  |  |

## 高优先级风险

1. 
2. 
3. 
```

## 使用规则

- 投稿前必须更新。
- 返修前必须更新。
- 全文审读时应先看高优先级风险，而不是先润色语言。
- 审稿回复时，用此表检查回应是否覆盖主要疑虑。

## 检查问题

- 读者最可能不懂哪个概念？
- 审稿人最可能质疑哪个识别、机制或数据选择？
- 哪个贡献最容易被认为不新？
- 哪些格式、图表和表述会显得不专业？
