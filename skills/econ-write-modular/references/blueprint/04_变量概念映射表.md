# 变量概念映射表

## 作用

变量概念映射表将理论概念、实证变量、符号、数据来源和结果表格对齐，防止“概念讲一套，变量测另一套”。

如果 [[02_概念术语表]] 已使用 M 编号，应在本表继承同一编号，避免变量、符号、公式和机制概念脱节。

## 建议模板

```markdown
# 变量概念映射表

| 概念编号 | 理论概念 | 实证变量/模型部件 | 变量符号 | 数据来源 | 测度方式 | 所在表格 | 注意事项 |
|---|---|---|---|---|---|---|---|
| M2 | 资本约束 | 资本充足率 / 资本缺口 |  |  |  |  |  |
| M0 | 房地产冲击 | 涉房坏账 / 房企违约暴露 |  |  |  |  |  |
| M3 | 尾部风险 | VaR / CoVaR / 分位数损失 / 破产出清 |  |  |  |  |  |

## 映射风险

- 哪些概念只能被近似测量？
- 哪些变量容易被误解？
- 哪些变量名需要在正文中重新解释？
```

## 使用规则

- 写数据、变量、识别策略、模型设定、结果段前读取。
- 若正文出现概念但没有变量映射，应提示作者补充。
- 若表格符号和正文术语不一致，优先统一映射表。
- 若 [[02_概念术语表]] 存在 M 编号，本表不得另造编号；继承原编号并补充变量、符号、公式、数据和表格。

## 检查问题

- 每个核心概念是否有对应变量？
- 变量是否真的测量了文中声称的概念？
- 符号、表格标题和正文表述是否一致？
- 哪些测度需要在正文中弱化解释？
- 概念编号是否与概念术语表一致？
- 同一 M 编号下的模型部件、变量和结果指标是否真的测量同一理论概念？
