# 逐段 Topic Sentence 细纲

## 作用

逐段 Topic Sentence 细纲控制段落级逻辑。它把每段的功能、主句、支撑材料和正文状态放在同一张表里。

如果 [[02_概念术语表]] 和 [[05_机制链条]] 已使用 M 编号，逐段细纲应增加“对应概念/机制编号”列，用来检查每段是否服务明确的概念、机制或结果路径。M 编号是写作辅助线，不要求正文每段显式写出。

## 建议模板

```markdown
# 逐段 Topic Sentence 细纲

## 引言

| 段落 | 段落功能 | 对应概念/机制编号 | Topic Sentence | 支撑材料 | 是否已写入正文 |
|---|---|---|---|---|---|
| P1 | 现实背景 | M0 |  |  |  |
| P2 | 风险事实/案例 | M0/M1/M2 |  |  |  |
| P3 | 研究问题 | M3 |  |  |  |
| P4 | 研究设计 | M1/M2/M3 |  |  |  |
| P5 | 核心结果 | M3 |  |  |  |
| P6 | 贡献 1 |  |  |  |  |
| P7 | 贡献 2 |  |  |  |  |

## 实证结果

| 段落 | 段落功能 | 对应概念/机制编号 | Topic Sentence | 对应表图 | 是否已写入正文 |
|---|---|---|---|---|---|
| R1 | 基准结果 | M3 |  |  |  |
| R2 | 经济显著性 | M3 |  |  |  |
```

## 使用规则

- 写长章节前先生成。
- 改段落时先看它的段落功能。
- 若某段没有 topic sentence，应先补细纲再改正文。
- 如果一段承担多个功能，优先拆段或改写主句。
- 若概念术语表存在 M 编号，细纲中的段落应尽量标注对应编号，便于检查段落是否漂离核心机制。
- M 编号不能替代段落主句。Topic Sentence 仍必须是一句可直接指导正文写作的短句。

## 检查问题

- 每段是否只有一个中心任务？
- Topic sentence 是否能概括该段？
- 段落是否服务上一层结构和一句话核心发现？
- 支撑材料是否足够，还是只是在堆概念？
- 段落对应的 M 编号是否与概念术语表、机制链条一致？
- 是否存在没有段落承接的关键机制编号，或没有机制编号支撑的游离段落？
