# 辅助线更新日志模板

```markdown
# 更新日志

## YYYY-MM-DD

### 本次修改的正文范围

- 

### 更新的辅助线

- [[00_一句话核心发现]]：
- [[02_概念术语表]]：
- [[06_逐段TopicSentence细纲]]：
- [[07_论断证据表]]：

### 关键变化

- 核心发现是否变化：
- 新增或删除的概念：
- 概念权重或 M 编号是否变化：
- 新增或弱化的论断：
- 图表叙事是否变化：
- 新增审稿风险：

### 下次修改前必须检查

- 
```

使用规则：

- 每次大改摘要、引言、结果或结论后更新。
- 如果只是局部措辞润色，可以不更新。
- 如果正文和辅助线不一致，应在日志中说明是更新正文还是更新辅助线。
