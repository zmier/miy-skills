# 写作状态文件夹模板

在用户论文项目中创建：

```text
writing-state/
  00_项目管理.md
  00_一句话核心发现.md
  01_研究问题与贡献地图.md
  02_概念术语表.md
  03_变量概念映射表.md
  04_机制链条.md
  05_三级目录大纲.md
  06_逐段TopicSentence细纲.md
  07_论断证据表.md
  08_结果叙事表.md
  09_审稿人风险清单.md
  10_更新日志.md
  log.md
```

最小版本：

```text
writing-state/
  00_项目管理.md
  00_一句话核心发现.md
  02_概念术语表.md
  05_三级目录大纲.md
  06_逐段TopicSentence细纲.md
  07_论断证据表.md
  10_更新日志.md
  log.md
```

命名规则：

- 文件名使用两位序号，保证阅读顺序稳定。
- 文件名使用中文，方便作者直接浏览。
- 每个文件应短而可维护，优先表格和短句。
- 每次大改正文后更新 [[10_更新日志]]。
- 如果项目使用 Obsidian，引用其他文件时使用双链，例如 [[00_一句话核心发现]]；不要用反引号包裹文件名。
- [[00_项目管理]] 用于任务看板，[[log]] 用于讨论台账，二者不要合并。
