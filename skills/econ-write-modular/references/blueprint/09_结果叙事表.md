# 结果叙事表

## 作用

结果叙事表把一组表格、图形和计算结果转化为论文叙事。它要求每个表图都回答一个问题、表达一句核心发现，并服务某个主结论。

## 建议模板

```markdown
# 结果叙事表

| 结果模块 | 表图 | 要回答的问题 | 核心发现 | 经济含义 | 支撑哪个主结论 |
|---|---|---|---|---|---|
| 基准结果 | 表 1 | X 是否影响 Y |  |  |  |
| 稳健性 | 表 2 | 结果是否依赖测度/样本/模型 |  |  |  |
| 异质性 | 表 3 | 效应在哪些主体更强 |  |  |  |
| 机制检验 | 表 4 | M 是否是传导渠道 |  |  |  |

## 结果写作顺序

1. 先写最重要结果。
2. 再写量级和经济含义。
3. 再写稳健性。
4. 最后写机制或边界条件。
```

## 使用规则

- 写结果部分前必须建立。
- 如果表格变化，应更新叙事表。
- 如果叙事表中某个结果不支撑主结论，应移到附录或弱化。
- 图表过多时，优先保留服务主线的表图。

## 检查问题

- 每个表图能否用一句话说明“从中可知什么”？
- 结果顺序是否按照叙事重要性，而不是计算顺序？
- 图表是否过多、过杂或格式不统一？
- 正文是否解释经济含义，而不只是复述显著性？
