# 论断证据表

## 作用

论断证据表保证每个核心论断都有证据。它尤其用于检查摘要、引言和结论中的强表述是否被模型、数据、表图或文献支撑。

## 建议模板

```markdown
# 论断证据表

| 论断 | 所在章节 | 证据类型 | 对应表图/文献/模型 | 支撑状态 | 风险 |
|---|---|---|---|---|---|
|  | 引言 | 表格结果 | 表 3 | 已支撑 |  |
|  | 结果 | 稳健性 | 表 5 | 需补强 |  |

## 支撑状态

- 已支撑
- 需补证据
- 需弱化
- 应删除
```

## 使用规则

- 写摘要和引言时尤其重要。
- 任何强论断都必须进入此表。
- 没有证据的论断必须弱化、补证据或删除。
- 全文审读时，先检查论断证据，再做语言润色。

## 检查问题

- 每个强论断是否有明确证据位置？
- 证据是直接支持，还是只间接相关？
- 论断是否比证据更强？
- 是否存在“贡献很大但证据很弱”的表述？
