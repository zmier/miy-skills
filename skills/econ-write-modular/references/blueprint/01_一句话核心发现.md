# 一句话核心发现

## 作用

一句话核心发现控制整篇论文的中心。它回答：

- 本文最重要的发现是什么；
- 这个发现包含哪些必要元素；
- 是否能用一句话讲清楚 X、Y、机制、场景和贡献边界。

## 建议模板

```markdown
# 一句话核心发现

## 当前版本

[X] 通过 [机制 M] 影响 [Y]，并在 [场景/样本/冲击] 中表现为 [方向/量级/分布变化]。

## 必须包含的元素

- 核心解释变量 X：
- 核心结果变量 Y：
- 关键机制 M：
- 识别来源或研究场景：
- 最重要结果：
- 贡献边界：

## 不能偏离的表述

- 不要把本文写成：
- 不要声称：
- 不要混用：

## 更新记录

- YYYY-MM-DD：初版。
```

## 使用规则

- 写摘要前必须读取。
- 改引言前必须读取。
- 写结果和结论前必须读取。
- 若结果部分出现新重点，必须反向检查是否需要更新本文件。
- 核心发现句应短、硬、可反复回看；机制、场景、贡献边界可以放在展开解释中，不要为了“一句话讲完所有内容”把核心句拖长。
- 如果导师或作者已经认可一个短句版本，优先锁定该短句作为全文锚点，再用后续辅助线解释它。

## 检查问题

- 这句话是否包含论文真正的 X 和 Y？
- 机制是否是本文能解释或检验的机制？
- 这句话是否过度声称因果、政策效果或普遍性？
- 摘要、引言、结果和结论是否围绕同一句话展开？
- 这句话是否已经变成“核心发现 + 机制解释 + 场景说明”的长句？如果是，应拆成核心句和展开句。
