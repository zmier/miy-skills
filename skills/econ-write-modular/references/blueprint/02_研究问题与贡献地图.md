# 研究问题与贡献地图

## 作用

研究问题与贡献地图控制“本文问什么”和“相对谁贡献什么”。它把现实重要性、理论重要性、文献位置和本文增量放在同一张地图里。

## 建议模板

```markdown
# 研究问题与贡献地图

## 研究问题

本文问：

## 为什么重要

现实重要性：
理论重要性：
政策重要性：

## 文献位置

| 文献线索 | 已有研究做了什么 | 仍未解决什么 | 本文如何推进 |
|---|---|---|---|
| 文献线索 1 |  |  |  |
| 文献线索 2 |  |  |  |
| 文献线索 3 |  |  |  |

## 本文贡献

贡献 1：
贡献 2：
贡献 3：

## 不应声称的贡献

- 
```

## 使用规则

- 写引言和文献综述前读取。
- 每次修改贡献段后更新。
- 写审稿回复时读取，用来判断如何回答“创新性不足”。

## 检查问题

- 研究问题是否是问题，而不是主题标签？
- 每条贡献是否对应明确文献线索？
- 贡献是否过多、过散或过度声称？
- 现实重要性是否能自然导向研究问题？
