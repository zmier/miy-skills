# 写结论

## 公式（Bellemare 改编）：按论文类型调整

### 第一部分：总结（1-2 段）

用不同于摘要和引言的方式重述主要发现。讲一个故事。不要简单复制前文。结论、摘要、引言都会陈述同一发现，但应使用不同表述。

### 第二部分：含义（1 段）

- 应用实证论文：给出政策含义和粗略成本收益评估（back-of-the-envelope 可以）。指出赢家和输家。不要做结果无法支持的主张。
- 理论论文：说明机制的更广泛适用性、与其他理论框架的关系，以及模型如何回应未解决争论。
- 结构模型论文：说明反事实结果对政策和福利计算的含义。

### 第三部分：未来研究（1 段）

指出 1-2 个具体方向：

- 更好的识别策略或更丰富数据。
- 更广泛外部有效性（新人群、新场景）。
- 模型扩展或放松关键假设。
- 你的发现引出的后续问题。

## 规则

- 保持简短。20 页论文的结论应不超过一页单倍行距（Nikolov）。
- 不要逐字重述全部发现。“摘要说一次，引言说一次，正文说一次，应该够了！”（Cochrane）
- 不要超出数据或模型进行推测。
- 不要在这里写基金申请（Cochrane）。
- 不要说 “I leave X for future research”（Cochrane），而是具体描述扩展会是什么。
- 不要在结论中加单独的 “limitations” 或 “caveats” 小节。结论应投射对发现的信心，而不是削弱发现。如果有局限，应放在正文中相关分析附近。
- 如果是应用微观论文，可考虑把结论写得像政策简报（Nikolov）。
