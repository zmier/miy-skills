# 按识别策略写作

不同识别策略和论文类型需要不同的叙事结构。写作时要根据方法调整表达方式。

---

## 随机对照试验（RCT）

- 先说明干预及其政策相关性。
- 尽早描述随机化机制和平衡性检验。
- 将意向处理效应（ITT）作为主规格；合规性和 LATE 另行讨论。
- 把样本流失和溢出效应作为主要识别威胁处理。
- 报告参与率或接受率；它们对解释处理效应至关重要。
- 预分析计划：如果已注册，在引言中说明注册编号。
- 结果结构：先 ITT，再在合规性不完美时报告 LATE/IV，最后报告异质性。
- 外部有效性通常是主要关切；讨论结果可以推广到哪些人群。

## 双重差分（DiD）

- 先说明产生处理变化的政策变化或自然实验。
- 平行趋势假设是识别核心；用完整一段讨论它。
- 用图展示处理前趋势；事件研究图是现代 DiD 论文的必需品。
- 如果相关，讨论处理时间差异和交错实施。
- 如果使用交错 DiD，回应近期计量经济学关切（Goodman-Bacon、Sun and Abraham、Callaway and Sant'Anna）。
- 对交错处理：报告双向固定效应估计的分解（Goodman-Bacon 2021），说明哪些比较驱动结果。
- 使用合适估计量：Callaway and Sant'Anna (2021) 用于随时间变化的异质性处理效应，Sun and Abraham (2021) 用于事件研究规格，de Chaisemartin and D'Haultfoeuille (2020) 用于无符号反转假设。
- 同时报告传统 TWFE 和稳健估计量的结果。如果不同，解释原因（负权重、处理效应异质性）。
- 展示稳健估计量得到的事件研究图，而不只是 TWFE 版本。
- 报告加入和不加入协变量的结果，以展示敏感性。
- 如果政策在实施前已经公布，讨论预期效应。
- 处理处理组和对照组随时间发生的构成变化。

## 工具变量（IV）

- 在引言第一段中说出工具变量。
- 用完整一段说明工具变量相关性（第一阶段 F 统计量；报告 Kleibergen-Paap 或有效 F 统计量）。
- 用完整一段说明排除限制；用经济学逻辑而不只是统计证据来论证。
- 同时报告 OLS 和 IV 估计；解释二者为何不同（测量误差、选择、LATE 与 ATE）。
- 讨论服从者人群是什么样的；也就是工具变量改变其行为的边际个体是谁。
- 如果工具变量较弱（F < 10），使用 Anderson-Rubin 置信区间。
- 如果估计 LATE，处理单调性假设。
- 需要谨慎讨论的常见工具变量：Bartik/shift-share（Goldsmith-Pinkham, Sorkin, and Swift 2020）、法官/审查员宽严度、历史/地理工具变量。

## 断点回归（RDD）

- 先说明运行变量和阈值。
- 用图展示断点；RD 图是你的“图 1”。
- 讨论运行变量操纵问题（McCrary/密度检验）。
- 呈现带宽敏感性分析；结果应在合理带宽范围内稳定。
- 报告使用最优带宽的局部多项式估计（Calonico, Cattaneo, and Titiunik）。
- 强调 RDD 估计对阈值附近是局部的；明确讨论外部有效性。
- 对模糊 RDD：分别报告简约式（结果变量跳跃）和第一阶段（处理变量跳跃）。
- 处理阈值处可能混淆估计的其他不连续变化。

## 合成控制

- 先说明处理单元和事件/政策。
- 描述捐赠池选择标准：为什么选这些比较单元？
- 用图展示处理前拟合；这就是你的识别。如果处理前拟合很差，方法就失败。
- 将安慰剂检验（置换推断）作为主要推断工具。
- 讨论合成反事实在实质上意味着什么。
- 报告捐赠权重；哪些比较单元获得最大权重？
- 如果捐赠单元与处理单元差异很大，处理插值偏误问题。
- 对多个处理单元，考虑增强/惩罚合成控制或合成 DiD。

## 合成双重差分（Arkhangelsky 等）

- 先说明政策变化，以及为什么标准 DiD 或单独的合成控制都不充分。
- 解释双重稳健性质：只要平行趋势假设或合成控制权重有一个正确，估计就有效。
- 同时呈现标准 DiD、合成控制和合成 DiD 估计，便于比较。
- 展示单元权重和时间权重；读者需要知道哪些比较单元和处理前时期驱动估计。
- 推断时使用基于安慰剂的程序（置换处理分配），而不是渐近标准误。
- 讨论何时优先使用合成 DiD：处理单元少导致 DiD 噪声大，或处理前时期很多导致合成控制可能过拟合。

## 结构估计

- 在数学表达之前，用普通语言清楚说明经济模型及其关键假设。
- 区分识别假设（可检验或不可检验）与函数形式假设。
- 直观解释识别：数据中的什么变化识别了每个参数？
- 报告模型拟合；展示模型能够复现数据中的关键矩。
- 在可能时用样本外预测验证模型。
- 反事实模拟是回报所在；要突出呈现。
- 讨论对关键假设的敏感性：如果风险厌恶不同会怎样？如果主体拥有不同信息会怎样？
- 尽可能把结构估计与简约式估计比较，以增强可信度。

## 描述性和测度论文

- 先说明这种测度或描述为什么对经济学重要。
- 明确写出：“本文不估计因果效应。本文记录 [模式/事实/测度]。”
- 详细描述数据构造过程；这本身就是贡献。
- 展示描述性模式对替代定义和样本的稳健性。
- 讨论这些新事实能让未来研究者回答哪些因果问题。
- 将描述性发现与已有理论预测联系起来。

## 堆积估计（Saez, Kleven）

- 先说明产生堆积的政策 kink 或 notch。
- 用图展示堆积；堆积图是核心图形。
- 描述反事实分布及其估计方式。
- 报告由堆积程度推出的弹性。
- 讨论优化摩擦：如果存在调整成本，堆积估计是下界。
- 处理操纵与真实反应的区分（税收堆积中：逃避与真实劳动供给）。
- 呈现对带宽和反事实多项式阶数的稳健性。
- 对 notch 设计：讨论被支配区域及其对理性行为的含义。

## Shift-Share / Bartik 工具变量

- 在引言中明确说出 shift-share 工具变量。
- 清楚描述两个组成部分：“shares”（暴露权重）和“shifts”（全国/部门冲击）。
- 说明识别依赖哪一类变化来源：
  - 如果依赖 shares 的外生性：说明为什么前期产业构成是外生的（Goldsmith-Pinkham, Sorkin, and Swift 2020）。
  - 如果依赖 shifts 的外生性：说明为什么这些冲击近似随机（Borusyak, Hull, and Jaravel 2022）。
- 报告 shift-share 工具变量的有效 F 统计量。
- 讨论 shares 的颗粒度，以及驱动变化的冲击数量。
- 呈现“leave-one-out”估计，说明结果不是由单一冲击或部门驱动。
- 使用 shift-share 结构处理处理前趋势。

## 事件研究

- 先说明事件及其经济意义。
- 将事件研究图作为核心图形。
- 包含事件前系数以评估处理前趋势（至少 3-4 个处理前时期）。
- 将一个处理前时期系数标准化为零（通常是 t = -1）。
- 讨论事件后动态的解释：效应是即时、渐进还是暂时的？
- 对交错事件：使用合适估计量（Sun and Abraham、Callaway and Sant'Anna），并讨论处理效应异质性。
- 报告关键事件后时期的点估计和置信区间。
- 如果事件可预见，处理预期效应。

## 用于因果推断的机器学习

- 清楚说明 ML 用于预测、异质性还是因果估计。
- 对异质性处理效应（Causal Forests, Athey and Imbens 2016）：描述样本分割程序，以及如何避免过拟合。
- 对 double/debiased ML（Chernozhukov 等 2018）：解释交叉拟合程序及其必要性。
- 报告传统标准误和置信区间；ML 不改变推断要求。
- 讨论可解释性的权衡：更灵活的模型可能牺牲经济直觉。
- 将 ML 估计与更简单的参数估计比较，以增强可信度。
- 对基于 LASSO 的变量选择：说明为什么数据驱动选择合适，并报告对惩罚强度的敏感性。

## 使用多种识别策略的论文

- 许多现代论文结合多种策略（例如 DiD 作为主规格 + IV 作为稳健性，或 RDD + 合成控制）。
- 指定一种策略为“主要策略”并优先呈现。其他策略应被表述为稳健性或互补证据。
- 当多种策略得到相近估计时，强调收敛：“X 的 IV 估计与 Y 的 DiD 估计在统计上无法区分，从而强化了因果解释。”
- 当多种策略得到不同估计时，解释原因：不同局部人群（LATE 与 ATT）、不同识别假设，或不同调整边际。
- 除非确实没有理由偏好某一种策略，否则不要把多种策略呈现为同等权重。读者想知道你最相信哪个结果。
- 在引言中说出主要策略。简要提及次要策略：“我使用 [替代方法] 确认这些发现。”

## 按论文类型调整引言

| 论文类型 | Hook 策略 | 第 4-6 段写什么 | 需要讨论的关键威胁 |
|-----------|--------------|-----------------------------|-----------------------|
| RCT | 干预的政策相关性 | ITT 和 LATE 估计 | 样本流失、溢出、外部有效性 |
| DiD | 政策变化或自然实验 | 主要 DiD 估计 + 事件研究 | 平行趋势、预期效应 |
| IV | 工具变量及其巧妙之处 | OLS 与 IV 比较 | 排除限制、弱工具变量 |
| RDD | 阈值及其利害关系 | RD 估计 + 带宽敏感性 | 操纵、其他不连续 |
| Synthetic Control | 处理单元和事件 | 合成路径与实际路径 | 处理前拟合、捐赠池 |
| Synthetic DiD | 政策变化 + 少量处理单元 | 合成 DiD 与 DiD、SC 比较 | 平行趋势、合成控制拟合 |
| Structural | 需要模型回答的经济问题 | 关键反事实结果 | 模型假设、外部有效性 |
| Theory | 模型解决的谜题或悖论 | 主要命题和直觉 | 机制对假设的稳健性 |
| Descriptive | 事实/测度为什么重要 | 带量级的关键模式 | 测度有效性、样本选择 |
| Bunching | 政策 kink/notch 及受影响人群 | 弹性估计 + 堆积图 | 优化摩擦、操纵 |
| Shift-Share | 冲击和地方暴露 | 主要估计 + leave-one-out | shares 外生性、shifts 外生性 |
| Event Study | 事件及其利害关系 | 事件研究图 + 关键系数 | 处理前趋势、预期效应 |
| ML/Causal | 预测或异质性问题 | ML 与参数估计比较 | 过拟合、可解释性 |
