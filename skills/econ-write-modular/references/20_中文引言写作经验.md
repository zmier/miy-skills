# 中文引言写作经验

## 定位

本文件补充 [[03_写引言]]。原始引言原则强调结果前置、贡献清楚、避免清嗓子；中文经济学期刊中还常见一种“政策背景—现实事件—研究问题”的三段式引言。该模板适用于政策相关、风险防范、宏观治理、产业链供应链、金融监管、中国制度情境较强的论文。

使用本模板时，不要把它理解为可以空泛铺陈政策。三段式的目标仍然是尽快把读者带到本文的研究问题。

## 三段式模板

### Para 1：政策背景 + 正面进展 + 规模事实

功能：说明研究问题为什么重要。

常见结构：

```text
政策命题/现实背景
-> 重要部署或制度变化
-> 已有进展
-> 规模事实或硬事实
```

写作要求：

- 政策背景要服务研究问题，不要堆文件名称。
- 最好有一个规模事实、统计事实或制度事实压舱。
- 不要在第一段提前塞入全部机制概念。

### Para 2：转折风险 + 现实事件 + 机制解释 + 审视反思

功能：说明为什么已有背景下仍然存在需要研究的问题。

常见结构：

```text
然而，现实关联或风险形态发生变化
-> 近期事件或典型案例
-> 事件为什么与本文核心概念有关
-> 简短机制解释
-> 引出学术界和监管部门的审视
```

写作要求：

- 现实事件不是新闻复述，而是用来承载核心解释变量或关键机制。
- 机制解释应足够具体，但不要把完整理论机制提前写完。
- 结尾要自然指向研究问题，而不是停在风险感慨。

### Para 3：研究问题 + 方法视角 + 学术价值 + 现实意义

功能：告诉读者本文研究什么，以及为什么值得研究。

常见结构：

```text
如何处理/解释/测度 [核心问题]，是 [政策或理论关切]
-> 本文通过 [方法/数据/模型] 考察 [X 对 Y 的影响]
-> 有助于从 [若干机制或视角] 理解 [问题]
-> 为 [政策治理或理论推进] 提供参考
```

写作要求：

- 第三段应明确本文研究对象和方法，不要只写意义。
- 如果正文第二章有独立文献综述，第三段可以轻轻预告后文的机制分类框架。
- 预告的是既有机制线索或研究视角，不是把本文核心发现当作文献综述主题。

## 何时使用

适合使用：

- 中文 CSSCI/经济学期刊论文。
- 政策语境强，且研究问题需要从中国现实制度背景进入。
- 引言之后另有独立“文献综述/理论假设”章节。
- 文章需要用典型事件引出机制问题。

谨慎使用：

- 目标期刊更接近英文顶刊风格，要求引言中较早报告结果。
- 研究问题没有明显政策背景或现实事件入口。
- 用户明确要求极短引言或摘要式引言。

## 与文献综述的衔接

三段式引言的第三段应为第二章开门，但不能替第二章展开文献综述。

好的衔接：

```text
引言第三段提出：本文从 [机制线索 1] 和 [机制线索 2] 考察 [X 对 Y]。
第二章接着综述：已有文献如何分别讨论 [机制线索 1] 和 [机制线索 2]。
```

不好的衔接：

```text
引言第三段提出本文发现 A 和 B。
第二章直接综述 A 和 B。
```

如果 A 和 B 是本文核心发现，它们应在理论假设或结果部分出现，而不是作为已有文献综述对象。

## 检查问题

- 第一段是否只有背景，没有研究问题入口？
- 第二段的现实事件是否真正承载核心机制？
- 第三段是否明确说明本文做什么？
- 第三段是否为第二章预告了机制分类框架？
- 是否把本文核心发现误写成已有文献共识？
- 政策概念是否抢占了模型概念和结果概念？
