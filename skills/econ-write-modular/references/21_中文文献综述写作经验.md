# 中文文献综述写作经验

## 定位

本文件补充 [[14_使用场景说明]] 中的文献综述规则。原始规则强调文献综述要讲故事、聚焦最接近文献、建立 however/although 转折；中文经济学论文中，若正文另设“文献综述/理论假设”章节，常需要把文献综述组织为“机制线索综述 + 研究空白 + 理论假设”的结构。

使用本文件时，应同时检查 [[02_研究问题与贡献地图]]、[[03_概念术语表]] 和 [[05_机制链条]]。文献综述不是资料堆放区，而是为本文概念、机制、模型设定和假设出口提供来源。

## 核心原则

1. 文献综述按机制线索组织，不按作者时间顺序罗列。
2. 综述对象应是既有文献中的机制、视角、概念或方法，不是本文自己的核心发现标签。
3. 如果本文 X-Y 关系本身是研究空白，不要写“大量研究表明 X 会影响 Y”；应写“相关研究分别从 A 和 B 方面提供了理解基础”。
4. 每段应有明确 Topic Sentence，并在段末回扣风险、机制、模型部件或假设出口。
5. 研究空白段必须承接前文机制综述，不能另起一个新问题。

## 常见结构

### 两段机制综述 + 一段研究空白

适用于第二章只叫“文献综述”，理论假设另设小节或后文展开。

```text
Para 1：机制线索 1
-> 该机制为什么重要
-> 代表文献如何解释
-> 该机制的边界或不足

Para 2：机制线索 2
-> 该机制为什么重要
-> 代表文献如何解释
-> 该机制的边界或不足

Para 3：研究空白
-> 现有研究如何分割
-> 哪个关键交织机制尚未解释
-> 本文如何补上
```

### 两段机制综述 + 一段研究空白 + 一段理论假设

适用于章节标题为“文献综述与理论假设”。

```text
Para 1：机制线索 1 综述
Para 2：机制线索 2 综述
Para 3：研究空白与本文设计
Para 4：由机制线索推出理论假设或可检验预测
```

理论假设段可以引出本文核心预测，但不要把核心预测伪装成已有文献共识。

## 段落内分层

### 争议型机制综述

适用于同一机制下已有文献方向不一致。

```text
机制主题句
-> 概念对或机制分类
-> 观点 A：机制解释 + 代表文献
-> 观点 A 的边界
-> 观点 B：反向机制 + 代表文献
-> 段末回扣本文问题
```

写作要点：

- 先写最直观或经典观点，再写边界和反向机制。
- 不要把文献写成“作者 A 发现、作者 B 发现、作者 C 发现”。
- 文献都应服务同一个机制张力。

### 单向机制综述

适用于文献共识较强、分歧不明显的机制。

```text
机制主题句
-> 现实/理论背景
-> 主流机制判断
-> 子渠道 1：机制解释 + 代表文献
-> 子渠道 2：机制解释 + 代表文献
-> 段末回扣风险结果或模型部件
```

写作要点：

- 如果没有明显争议，就把机制拆成子渠道。
- 子渠道应能映射到本文模型设定、变量、参数或仿真对照。

### 研究空白段

```text
纵观相关研究
-> 空白 1：视角不足 + 为什么重要
-> 空白 2：机制/结果不清 + 本文如何解决
-> 空白 3：现实情境或方法不足 + 为什么重要
-> 本文设计：对象 + 方法 + 解决的问题
```

写作要点：

- 空白数量不宜多，通常 2 到 3 个。
- 每个空白应承接前文综述，而不是突然换主题。
- 本文设计句应直接回答这些空白。

## 如果本文 X-Y 是研究空白

不要写：

```text
大量研究表明，[本文原创 X-Y 命题]。
```

可以写：

```text
相关研究虽尚未直接讨论 [X 如何影响 Y]，但已分别从 [机制线索 1] 和 [机制线索 2] 两个方面，为理解这一问题提供了重要基础。
```

或：

```text
现有文献主要从 [机制线索 1] 和 [机制线索 2] 解释 [相关现象]，但较少考察二者在 [场景/约束/冲击] 下如何共同作用于 [本文结果空间]。
```

## 检查问题

- 综述线索是否是既有机制，而不是本文核心发现？
- 每段是否只有一个机制任务？
- 代表文献是否服务机制，而不是装饰性引用？
- 是否解释了已有文献的边界？
- 研究空白是否逐项承接前文综述？
- 理论假设是否从机制综述自然推出？
