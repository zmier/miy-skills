# 经济学论文审读清单

一个用于审读和审计经济学论文的结构化框架，灵感来自顶级期刊审稿中的多审稿人方法。

## 1. 快速审读模式（5 分钟扫描）

**标题**（每项 1-10 分）：

- 清晰度：非专业读者能理解主题吗？
- 长度：少于 12 个词吗？（越短越容易记住）
- 是否明确说出处理变量 + 结果变量？
- 可记忆性：你会在会议上记住这个标题吗？

**摘要**：

- 是否陈述了带量级的具体发现？（而不是“we find effects”）
- 是否少于 150 词？
- 是否遵循四部分公式：动机、方法、结果、含义？
- 开头是事实或谜题，而不是“This paper...”吗？

**引言**：

- 主要结果是否在前三段内出现？
- 文献是否被织入论证之中，而不是洗衣单式罗列？
- 长度是否在 3-5 页之间？
- 是否以路线图段落收尾？

**结论**：

- 是否少于 1 页？
- 是否遵循三部分公式：重述发现、含义、未来方向？
- 是否没有引入新结果或新论点？

## 2. 深度审读模式（模拟审稿人）

### 审稿人 1：方法论者

- [ ] 在公式之前用普通语言解释识别策略。
- [ ] 关键识别假设已经陈述并辩护。
- [ ] 有效性威胁已经列出并处理（选择、遗漏变量、反向因果）。
- [ ] 标准误按需要处理聚类、异方差或序列相关。
- [ ] 稳健性检验覆盖替代规格、样本和定义。
- [ ] 如适用：报告第一阶段 F 统计量（IV）、展示平行趋势（DiD）、报告带宽敏感性（RDD）。
- [ ] 披露预注册状态，或说明为什么没有预注册。
- [ ] 样本量足以支持声称的精度。

### 审稿人 2：领域专家

- [ ] 贡献相对于 3-5 篇最接近论文得到了清楚定位。
- [ ] 文献综述公平：引用不同意见的研究，而不只是支持性文献。
- [ ] 结果具有经济显著性，而不只是统计显著性（效应量有语境）。
- [ ] 制度细节准确，并且足以支持复现。
- [ ] 政策含义由证据支撑（没有过度声称）。
- [ ] 诚实讨论外部有效性。
- [ ] 数据来源描述足够详细，可以评估质量。

### 审稿人 3：写作批评者

- [ ] 全文使用主动语态（检查 “it was found”、“is shown”）。
- [ ] 使用带量级的具体语言（“a 10% increase”，而不是 “a substantial effect”）。
- [ ] 段落开头没有清嗓式表达（“It is important to note that...”）。
- [ ] 表格自成一体：标题、注释和单位使其可独立阅读。
- [ ] 图形有信息充分的标题和坐标轴标签。
- [ ] 每个词都有用；没有填充或跨章节重复。
- [ ] 段落以论断开头，而不是以引用开头。
- [ ] 章节之间的过渡有动机，而不是机械连接。

## 3. 反 AI 痕迹检查清单

以下迹象会让文本听起来像 AI 生成；全部避免：

**词语选择红旗**：过度使用 “delve”、“crucial”、“landscape”、“multifaceted”、“notably”、“furthermore”、“comprehensive”、“robust”（统计意义之外）、“utilize”（替代 “use”）、“leverage”（作为“使用”的动词）。

**句子层面的迹象**：

- 每个句子长度差不多（应在 8-25 词之间变化）。
- 每个列表都采用完美平行结构（真实学术写作更不整齐）。
- 没有限定性对冲表达（真实研究者会写 “This likely reflects...” 或 “One interpretation is...”）。
- 没有自然使用领域术语（例如劳动经济学中的 “extensive margin”，IO 中的 “pass-through”）。
- 没有括号补充或破折号；真实作者会使用这些。
- 过渡过于顺滑；真实论文在章节之间会有一点摩擦。

**结构层面的迹象**：

- 用泛泛占位表达替代具体制度细节。
- 本该用连贯 prose 的地方使用编号列表。
- 每个段落长度完全相同。
- 结论读起来像执行摘要，而不是反思。

**修复办法**：读两段同领域中你最喜欢的已发表论文。模仿那个节奏，而不是 ChatGPT 的节奏。

**评分档位**：

- 90-100：可以投稿 top-5。
- 80-89：强草稿，需要小修。
- 70-79：扎实的工作论文，还需要一轮。
- 60-69：存在重大结构或方法缺口。
- 低于 60：重写前先重新思考 framing 或识别。

## 5. 期刊匹配评估

**目标期刊问题**：

1. 问题是否具有广泛兴趣（top-5），还是主要与某个子领域相关（领域期刊）？
2. 论文是否有方法贡献，还是已知方法的应用？
3. 场景是否特定于一个国家，还是指向普遍机制？
4. 潜在读者有多大？你领域之外的研讨会听众会参与讨论吗？

**Top-5 预期**：

- *AER*：广泛兴趣、清晰识别、写得好、问题重要。通过 P&P 接收较短论文。
- *QJE*：强叙事、大问题，常有历史或制度深度。奖励雄心较大的研究范围。
- *Econometrica*：需要方法新意：新估计量、新理论结果，或结构模型。
- *REStud*：技术严谨，奖励理论或结构贡献与实证工作的结合。
- *JPE*：清晰实证设计、有趣问题、写作简洁。历史上偏好 Chicago 风格工作。

**领域期刊 vs. top-5 决策规则**：如果你的论文主要吸引力是“X 领域中的有趣结果”，而不是“关于经济如何运行的新洞见”，就投顶级领域期刊。这并不丢人；一篇被充分引用的领域期刊论文胜过一篇被 top-5 desk reject 的投稿。
