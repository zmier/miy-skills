# 修改检查清单

投稿前确认：

- [ ] 中心贡献在引言前 1-3 段具体陈述。
- [ ] 主结果在引言中出现并带量级。
- [ ] 正文没有被动语态（搜索 “is” 和 “are”；表注和方法中可接受）。
- [ ] 主点前没有清嗓子。
- [ ] 文献综述讲故事，而不是列表。
- [ ] 每张表都有自足标题和聚类/标准误说明。
- [ ] 表中的每个数字都在正文讨论。
- [ ] 每个重要数字都有标准误。
- [ ] 识别策略用经济语言清楚解释。
- [ ] 结论低于一页，没有单独 limitations/caveats 小节。
- [ ] 摘要低于 150 词且具体。
- [ ] 论文低于 40 页（检查目标期刊要求）。
- [ ] 所有希腊字母和符号都被定义。
- [ ] 没有“illustrative” empirical work。
- [ ] 没有缩写作者姓名。
- [ ] DiD 设计展示 pre-trends；RDD 设计展示 RD plot。
- [ ] 异质性结果已预设并意识到多重检验。
- [ ] 机制部分检验渠道，而不是猜测。
- [ ] 数据可得性和复制信息清楚说明。
- [ ] 附录项目都在主文引用。
- [ ] 标题低于 15 词，并包含 treatment 和 outcome（理论论文则包含关键机制）。
- [ ] 理论论文：主要命题在形式证明前有清楚经济直觉。
- [ ] 包含描述性统计表，表注定义变量。
- [ ] 每个公式在展示前用语言引入，公式后定义所有变量。
