# 中文期刊三段式引言

## 适用场景

适用于政策背景较强、现实事件明显、且正文另设“文献综述/理论假设”章节的中文经济学论文。

典型用途：

- 金融风险与宏观审慎监管。
- 产业链供应链安全。
- 房地产风险、地方债务风险、中小金融机构风险。
- 中国制度背景下的应用经济学研究。

## 结构模式

```text
Para 1：政策背景 + 正面进展 + 规模事实
Para 2：转折风险 + 现实事件 + 机制解释 + 审视反思
Para 3：研究问题 + 方法视角 + 学术价值 + 现实意义
```

## 段落功能

| 段落 | 主要任务 | 不应承担的任务 |
|---|---|---|
| Para 1 | 说明为什么重要 | 不展开完整机制，不堆概念 |
| Para 2 | 用现实事件引出核心机制问题 | 不写成新闻复述，不只制造危机感 |
| Para 3 | 提出本文研究问题和研究视角 | 不把第二章文献综述提前写完 |

## 来自中文论文的写法观察

以杨子晖等《中国金融机构的行业布局与系统性金融风险》为例，其引言三段的可迁移写法是：

1. 第一段从金融服务实体经济和风险防范的政策背景进入，并用金融机构对实体经济贷款余额这样的规模事实收束。
2. 第二段用硅谷银行和瑞士信贷风险事件说明行业布局可能影响金融机构风险。
3. 第三段提出需要测度金融机构行业布局并考察其风险影响，同时预告差异化、专业化、部门暴露等后文文献综述和模型设定的分类框架。

可迁移的不是具体事件或术语，而是这条功能链：

```text
政策重要性
-> 现实风险事件
-> 核心机制问题
-> 研究问题
-> 后文分类框架
```

## 句式骨架

### Para 1

```text
近年来，[政策主题/现实议题] 已成为 [宏观目标/治理目标] 的关键环节。[政策文件或制度安排] 明确提出 [相关要求]。在此背景下，[领域] 取得了 [进展]。[统计事实/规模事实] 显示，[与研究问题相关的事实]。
```

### Para 2

```text
然而，随着 [系统关系/市场环境/制度条件] 发生变化，[风险形态] 也呈现出新的特征。[现实事件] 不仅影响 [直接对象]，而且经由 [机制渠道] 波及 [间接对象]。究其原因，[核心主体或机制] 在 [系统 1] 和 [系统 2] 中均具有重要影响。由此，[局部冲击] 可能演化为 [本文研究的问题]。这一现象引起了 [学术界/监管部门] 对 [核心机制] 的审视。
```

### Para 3

```text
如何 [处理/解释/测度] [核心机制与结果]，是 [理论或政策领域] 的重要关切。正因如此，本文通过 [方法/模型/数据]，考察 [X] 对 [Y] 的影响，具有重要的学术价值与现实意义：它不仅有助于我们从 [机制线索 1] 和 [机制线索 2] 理解 [问题]，而且有助于揭示 [更深层机制]，为 [政策或治理目标] 提供参考。
```

## 使用注意

- 如果第二章按机制渠道综述，Para 3 应预告“机制渠道”，不是预告本文结果标签。
- 如果本文核心 X-Y 本身是研究空白，不能写“大量研究表明 X 会影响 Y”；应写“相关研究分别从 A 和 B 两方面提供了理解基础”。
- 现实事件要尽量短，事件后的机制解释比事件本身更重要。
- 政策文件和口号不要过多，最多服务一个清晰研究问题。

## 不建议写法

```text
近年来，[大政策] 十分重要。本文研究 [主题]，具有重要意义。
```

问题：只有重要性，没有机制问题。

```text
大量研究表明 [本文原创 X-Y 命题]。
```

问题：如果 X-Y 正是本文贡献，这会虚构文献共识并削弱创新性。
