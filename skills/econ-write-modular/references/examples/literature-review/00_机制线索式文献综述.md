# 机制线索式文献综述

## 适用场景

适用于中文经济学论文中独立的“文献综述”或“文献综述与理论假设”章节，尤其是研究问题需要从若干相邻文献线索拼接出来，而不是已有文献已经直接覆盖本文 X-Y 关系的情况。

典型用途：

- 风险传染、金融风险外溢、宏观审慎监管。
- 产业链供应链、银行信贷、资本约束、房地产冲击。
- 计算实验、结构模型、DSGE 或 ABM 类论文的理论机制铺垫。

## 样例来源

以杨子晖等《中国金融机构的行业布局与系统性金融风险》的第二章为抽象样例。可迁移的是段落功能和论证顺序，不是具体概念和结论。

该文第二章可概括为：

```text
Para 1：差异化与同质化/模仿策略
Para 2：专业化与分散化
Para 3：金融暴露与同业关联
Para 4：研究空白与本文设计
```

这是一种“三段机制综述 + 一段研究空白”的写法。

## 段落功能模板

| 段落 | 功能 | 段内推进 | 产出 |
|---|---|---|---|
| Para 1 | 第一条机制线索 | 总领句 -> 概念对 -> 观点 A -> 观点 B -> 回扣风险 | 说明第一条机制为什么重要、已有文献有何分歧 |
| Para 2 | 第二条机制线索 | 概念对 -> 经典理论 -> 经验文献 -> 机制边界 -> 反向机制 | 说明第二条机制的理论基础与边界 |
| Para 3 | 第三条机制线索 | 机制主题 -> 现实背景 -> 子渠道 1 -> 子渠道 2 -> 回扣风险 | 说明较有共识的机制如何通过多个渠道发挥作用 |
| Para 4 | 研究空白 | 纵观研究 -> 空白 1 -> 空白 2 -> 空白 3 -> 本文设计 | 从已有文献自然推出本文对象、方法和问题 |

## 争议型机制段骨架

```text
大量研究围绕 [机制线索] 与 [结果变量/风险结果] 的关系展开讨论。针对这一主题，现有文献主要形成两类观点。第一类观点认为，[机制方向 A]，其原因在于 [经济机制 A]。相关研究从 [文献场景/方法] 出发指出，[代表性结论 A]。然而，[机制 A 的边界或副作用]。因此，第二类观点强调，[机制方向 B]，即 [经济机制 B]。这表明，[机制线索] 对 [结果变量/风险结果] 的影响并不单一，仍需结合 [本文场景/约束条件] 进一步分析。
```

使用规则：

- “两类观点”必须是真实文献分歧，不能为了形式强造分歧。
- 观点 A 和观点 B 应围绕同一个机制概念。
- 段末要回到本文问题，而不是停在“文献尚未一致”。

## 单向机制段骨架

```text
除 [前一机制] 外，[机制线索] 也可能影响 [结果变量/风险结果]。已有研究通常从 [子渠道 1] 和 [子渠道 2] 解释这一机制。一方面，[子渠道 1] 会通过 [具体经济机制] 改变 [结果]。另一方面，[子渠道 2] 则可能经由 [具体经济机制] 进一步放大/削弱 [结果]。由此可见，[机制线索] 并非抽象背景，而是能够通过 [可观测关系/模型部件] 进入 [本文研究问题]。
```

使用规则：

- 如果文献没有明显争议，优先拆子渠道。
- 子渠道最好能对应后文模型部件、变量或结果分解。

## 研究空白段骨架

```text
纵观相关研究，现有文献已从 [机制线索 1] 和 [机制线索 2] 等方面解释了 [相关现象]，但仍存在进一步拓展空间。第一，已有研究多从 [已有视角] 出发，较少关注 [本文视角]；然而，[为什么该视角重要]。第二，现有文献通常分别讨论 [机制线索 1] 与 [机制线索 2]，较少考察二者在 [本文场景/约束] 下的交互作用；事实上，[交互为什么重要]。第三，针对 [中国现实情境/特定冲击/特定制度] 的讨论仍相对不足，而这一情境对于理解 [本文问题] 具有重要意义。有鉴于此，本文通过 [方法/模型/数据]，考察 [研究对象]，以揭示 [核心机制或预测]。
```

使用规则：

- 研究空白要接住前文机制综述，不要突然切换到新领域。
- 最后一句应交代对象、方法和解决的问题。
- 如果本文核心发现包括 A 和 B，研究空白段可以说“本文进一步考察是否出现 A 和 B”，但不要写“已有文献表明 A 和 B”。

## 当本文 X-Y 是空白时

如果本文的核心命题尚未被既有文献直接覆盖，应避免把文献综述写成虚假的 X-Y 共识。

不建议：

```text
大量研究表明，资本约束会导致尾部风险跨行业传染。
```

建议：

```text
现有文献虽尚未直接讨论资本约束如何影响尾部风险的跨行业传染，但已分别从实体供应链关联和金融信贷约束两个方面，为理解这一问题提供了重要基础。
```

## 可迁移到项目细纲

若项目已有 [[blueprint/07_逐段TopicSentence细纲]]，可以转化为：

| 段落 | 段落功能 | 对应概念/机制编号 | Topic Sentence | 支撑材料 |
|---|---|---|---|---|
| Para 1 | 第一条机制综述 | M1 | 现有研究从 [机制线索 1] 解释 [相关现象]。 | 机制文献、概念术语表 |
| Para 2 | 第二条机制综述 | M2 | 另一类研究强调 [机制线索 2] 也会改变 [相关现象]。 | 机制文献、模型设定 |
| Para 3 | 研究空白 | M1/M2/M3 | 既有研究较少在同一框架中考察 [机制线索 1] 与 [机制线索 2] 的交互。 | 文献边界、本文贡献 |
| Para 4 | 理论假设 | M3 | 基于上述机制，本文预期 [核心预测]。 | 机制链条、模型设定 |

## 常见错误

- 把本文核心发现当成已有文献综述主题。
- 每句话都引用文献，但段落没有机制主线。
- 只写“已有研究不足”，不说明不足为什么重要。
- 研究空白段和前文综述无关。
- 理论假设段重复研究空白，而没有形成可检验预测。
