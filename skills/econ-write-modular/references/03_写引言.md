# 写引言

引言决定一篇论文 75% 的接收或拒绝概率。（Bellemare）先写引言，并在每次处理论文时重写它。预期要修改数百次。

## 引言公式（Head / Evans / Bellemare）

### 第 1-2 段：Hook（1-2 段）

通过连接重要问题吸引读者。四种策略：

- **Y 很重要**：当 Y 上升/下降时，人们受到伤害或受益。
- **Y 令人困惑**：它违背直觉或标准理论。
- **Y 有争议**：经济学家对此意见不一。
- **Y 很大或很常见**：涉及巨大部门或广泛现象。

以一个醒目的事实、谜题或基于数据的强判断开头。不要以下列方式开头：

- 哲学式开场：“Financial economists have long wondered...”
- 文献式开场：“The literature has long been interested in...”
- 政策动机式开场：“Given the importance of X for society...”
- 可爱的引语。
- “The literature lacks a model of...” 理论论文也应从经济谜题开始，而不是从文献缺口开始。

这些都是“清嗓子”（Cochrane）。从你的贡献开始。

### 第 3 段：研究问题（1 段）

清楚说明本文做什么。加入类似句子：

> “This paper examines whether [X causes Y] using [method] and [data].”

理论论文可写：

> “This paper develops a model of [phenomenon] in which [mechanism] generates [key prediction].”

读者必须在这一段结束时明白本文要回答什么问题。在这里给出主结果，即真实系数、真实发现或主要理论洞见，而不是含糊预告。

### 第 4-6 段：主要结果（2-3 段）

具体陈述关键发现。顶级期刊论文引言中 25-30% 的篇幅用于结果（Evans）。包括：

- 中心发现及其量级和显著性（实证），或主要命题及其直觉（理论）。
- 关键稳健性结果或扩展。
- 经济显著性，而不仅是统计显著性。

### 第 7-9 段：文献综述与增量贡献（2-3 段）

文献综述应该在引言中，而不是作为独立章节（Cochrane, Bellemare）。它应占引言的 20-30%。

**写法：**

- 它是一个故事，不是带注释的书目。叙事应围绕一个 “however” 或 “although” 转折：别人做了什么，仍有什么不足，本文如何解决。（Dudenhefer）
- 只讨论最接近的 5-10 篇论文，越接近 5 越好。
- 对每篇论文，说明它做了什么以及仍有什么限制；不要只陈述其发现。
- 然后描述本文大约 3 个贡献：
  - 内部有效性贡献：更好的识别。
  - 外部有效性贡献：新情境、新人群。
  - 方法或理论贡献：新方法、新数据、新模型。
- 对前人要慷慨。你不必说别人都错了。不要贬低前人。
- 写全作者姓名。不要缩写（如不要把 Fama and French 写成 “FF”）。
- 可以引用工作论文，但如果关键结果即将发表或版本变化，要注明。
- 引用已发表论文时，优先引用期刊版本，而不是工作论文版本。

### 最后一段：路线图（1 个短段）

概述论文组织。要根据你的论文具体定制，不要写泛泛的 “Section 2 presents the model, Section 3 discusses data...”。提到具体路标：问题、解决方案、关键结果。保持简短，读者急着进入正文。

## 引言长度

最多 3-5 页。（Cochrane 和 Shapiro 都说应用论文 3 页是上限；理论和结构模型论文可能需要 4-5 页。）

## 避免的关键错误

1. **埋没重点**：把主结果放在第 20 页，而不是第 1 页。
2. **挂羊头卖狗肉**：承诺有趣问题，交付无聊内容。
3. **旅行日志**：叙述研究旅程，而不是呈现最终产品。
4. **清嗓子**：在说明自己做什么之前写好几页动机。
5. **平淡枚举**：只列论文，不讲故事（“Smith found X. Jones found Y.”）。
6. **引言没有结果**：让读者等到结果部分才看到任何发现。
