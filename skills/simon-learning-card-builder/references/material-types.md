# 材料类型路由

## 目录

1. 统一输入模型
2. 技术课程与视频
3. 书籍章节
4. 多篇论文主题集
5. 混合材料
6. 暂不承担的任务

## 1. 统一输入模型

把所有材料抽象为：

```text
source_collection  材料集合
learning_unit      学习单元
evidence_anchor    证据锚点
learning_goal      学习目标
knowledge_base     既有卡片库
```

`learning_unit` 可以是：

- Day 或课时；
- 视频章节；
- 书籍的一章或一组小节；
- 围绕同一研究问题的一组论文；
- 用户定义的任务模块。

不要强迫所有材料使用 Day 命名。

## 2. 技术课程与视频

### 推荐学习单元

- 一天课程；
- 一个完整案例；
- 一个可独立完成的技术目标。

### 主要证据

- Markdown 标题；
- 视频时间戳；
- 代码和运行输出；
- 抓包、截图、反编译和实验结果。

### 重点产物

- 按问题链组织首次学习指南；
- 区分静态推测、运行时观察和本地复现；
- 将通用技术从业务固定值中分离；
- 链接代码，但不把代码存在视为制卡前提。

### 无代码课程

若只有讲义或转录：

- 使用定义、推导、例子和反例作为证据；
- 把“能够解释和应用”作为掌握标准；
- 不虚构实验或代码验证环节。

## 3. 书籍章节

### 推荐学习单元

- 单章；
- 跨章的一个核心概念；
- 一组必须连续阅读的小节。

章节编号只是来源索引。永久卡片按概念体系组织。

### 主要证据

- 章节与小节标题；
- 页码；
- 图表、例题、定义、定理或作者论证；
- 稳定块引用。

### 学习指南差异

首次学习指南应强调：

```text
前置概念
→ 作者提出的问题
→ 概念或模型
→ 图形/例题
→ 适用条件与反例
→ 与后续章节的连接
```

例如《艾略特波浪理论》可把“第一章”作为学习单元，但永久卡片应围绕趋势、浪级、推动浪、调整浪等概念，而不是创建“第一章卡片”。

### 版权约束

- 不复制长段正文。
- 使用自己的概括。
- 只保留短引用和精确页码作为证据。

## 4. 多篇论文主题集

### 推荐学习单元

优先把“研究问题”作为学习单元，而不是把每篇论文当作一个 Day。

例如：

```text
信息如何影响股票市场散户交易行为
```

### 第一阶段：单篇证据索引

为每篇论文记录：

- 研究问题；
- 理论机制；
- 数据与样本；
- 识别或研究设计；
- 核心结果；
- 边界条件；
- 与主题的关系；
- 精确页码、表格或命题。

这些索引通常属于来源笔记，不自动成为永久卡片。

### 第二阶段：跨论文综合

构建矩阵：

| 论文 | 信息类型 | 散户行为 | 机制 | 研究设计 | 结论 | 边界/分歧 |
|---|---|---|---|---|---|---|

再提炼：

- 主题概念卡；
- 机制卡；
- 研究设计或测量方法卡；
- 一致证据卡；
- 分歧与边界条件卡。

### 知识地图差异

论文主题地图应展示：

```text
概念定义
→ 理论机制
→ 可观测行为
→ 证据类型
→ 一致结论与分歧
→ 尚未解决的问题
```

### 第一版边界

本 Skill 支持主题综合与知识卡片化，但不替代：

- 系统综述或元分析协议；
- 文献检索数据库工作流；
- 引用真实性核查；
- 完整 BibTeX 管理。

需要这些能力时，组合使用相应文献检索或引用审计 Skill。

## 5. 混合材料

同一主题包含课程、书籍和论文时：

1. 以学习目标定义学习单元。
2. 用课程建立操作情境。
3. 用书籍补充概念体系。
4. 用论文提供研究证据、边界与争议。
5. 永久卡片按知识问题合并来源，不按材料类型复制。

一张卡片可以同时引用多个来源，但应区分主要来源与补充证据。

## 6. 暂不承担的任务

以下任务可以组合其他 Skill，但不应由本 Skill 假装完成：

- 扫描版 PDF 的 OCR 与版面恢复；
- 自动下载付费书籍或论文；
- 学术引用真实性审计；
- 统计元分析；
- 执行未经授权的逆向或接口调用；
- 用卡片摘要替代原书、原论文或完整课程。
